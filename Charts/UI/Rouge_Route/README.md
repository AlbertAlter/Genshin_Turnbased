# 肉鸽路线美术参数

`Rouge_Route_styles.csv` 是路线节点和手绘虚线的参数定义。使用 Excel 编辑时只改 `Value`，保存为 UTF-8 CSV；`Key` 是程序标识，右侧五列用于解释，不参与绘制。数值使用小数点，比例填小数，例如 `0.1` 表示 10%，不要填写 `10%`。

当前状态：RouteTest 场景已接入此 CSV 的运行时读取。启动时加载节点图标与手绘虚线参数，默认使用纯程序圆头短笔触。表内初值是第一版建议值；本次仅进行非 Unity 检查，未启动场景实测。

修改参数后，在 Unity 执行 `Tools/UI/更新 UI 配置` 发布表格；如果场景正在运行，会自动重载路线美术。场景内的“刷新路线美术”按钮也可重新读取已发布表格，保留当前地图和滚动位置，不重新生成路线。更换图标或笔触路径时使用 `Tools/UI/导入美术资源`，该命令会先发布配表，再同步表中引用的图片。

## 尺寸和颜色

- 设计基准是当前路线场景的 1920×1080。所有设计像素跟随 Canvas 整体缩放，不是每台屏幕固定不变的物理像素。
- 深棕为 `#716758`，浅棕为 `#998F81`。颜色使用 `#RRGGBB`，透明度单独用 0～1。
- 图标保持等比；去除透明留白之后，较长边取 `Node.IconSize`。当前为 30，使用 30×30 外接框。连线退让按外接框最大边的一半计算，不穿入图标镂空区域。
- Boss 后续按各自身份单独配置，不用一张统一 Boss 图。当前 Boss 继续保留测试圆点。

## 虚线如何适应长度

先取得两端节点中心之间的距离，再分别扣除该端的节点半径与 `Line.NodeGap`，得到可绘制长度。若结果小于等于 0，该条连线不画笔触。

按 `DashLength + GapLength` 估算笔触数量。绘制长度增加时增加笔触数量，缩短时减少数量，不拉伸整张长虚线图片。单段长度、厚度、间隔、角度和垂直偏移分别受表内对应的 Variation 参数控制。

- `AdjustGap`：按目标段长和间隔选择段数；生成每笔长度后，将剩余空白按间隔权重分配，使首末笔落在两端退让边界内。若长度变化后放不下，减少笔触数量。只有一笔时居中显示。
- `CenterPattern`：按目标段长和间隔排布完整笔触，将多出的长度平均留在首尾；不为了铺满而增加段长或拉宽间隔。
- 可用长度不足一笔时，将该笔缩短至可用长度并居中；旋转和边缘起伏也须限制在可绘制边界内，不能侵入节点留白。
- `GapLength` 是目标间隔，不保证在 AdjustGap 中每条边都恰好等于该数值。`GapVariation` 改变的是间隔分配权重，分配后的空白总量保持不变。

## 手绘感分别由什么控制

- `LengthVariation`：不同笔触有长有短。
- `WidthVariation`：不同笔触有粗有细。
- `GapVariation`：笔触间的空白略有不同。
- `AngleVariation`：每笔相对连线方向略微旋转。
- `OffsetVariation`：每笔中心沿连线的垂直方向略微偏移。
- `EdgeRoughness`：单笔边缘相对平滑轮廓的起伏，与整笔偏移不同。
- `EndRoundness`：笔触两端是平头还是圆头。
- `EndTaper`：端帽之前的笔触是否逐渐收细，与圆头形状不同。

第一版建议保持轻微变化。需要更规整时，将所有 Variation 和 `EdgeRoughness` 设为 0；保留 `EndRoundness=1` 仍可得到圆头虚线。

## 两种绘制模式

`Procedural` 为纯程序绘制短笔触，不需要额外贴图。`BrushTexture` 使用 `Line.BrushTextures` 指定的透明笔触 PNG，程序负责旋转、尺寸、间隔和长度适配；笔触贴图只使用 Alpha，颜色仍以 `Line.Color` 为准。

贴图模式下 `EdgeRoughness`、`EndRoundness`、`EndTaper` 和 `SamplesPerDash` 不生效，这些细节以贴图自身为准。路径从 StreamingAssets 根目录开始，多个路径用英文分号分隔。未准备好贴图时先保留空值和纯程序模式；贴图模式缺图时按约定回退纯程序，并输出提示。

## 稳定性和既有规则

`PatternSeed` 只决定美术变化，结合边的两个节点 ID 和笔触序号得到稳定样式，不消耗业务用的 `BattleRandom`。滚动、重绘或分辨率变化不重新抽样。改变样式种子不重新生成节点和连线关系。

这些是显示参数，不替代 StageConfig / StageRule 中的节点数量、权重、岔路概率、坐标间隔、最小间距或夹角规则。不能为了手绘表现移动真实节点或更改真实连线。

程序只从 `Application.streamingAssetsPath/Charts/UI/Rouge_Route/Rouge_Route_styles.csv` 读取参数；美术从 `Application.streamingAssetsPath/art_assets/...` 读取。既有 UI 发布流程已支持 Rouge_Route 分组，保持 Battlefield1 原有发布路径和场景不变。表格读取失败会提示并使用默认样式；发布工具会拒绝缺项、重复键或非法参数。

每条边最多绘制 512 笔以限制网格规模；正常参数不会触及此上限。贴图模式按笔触种类合批，纯程序模式每条边使用一个 UI 网格，不为每一小段创建独立 GameObject。
