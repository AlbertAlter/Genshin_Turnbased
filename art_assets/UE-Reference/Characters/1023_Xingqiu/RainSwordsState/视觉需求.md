# 行秋 · 雨帘剑环绕持续状态

## 整体构图

每张实际持有雨帘剑的角色卡牌周围，分别悬浮与其**当前剩余数量一致**的水蓝幻剑。各卡独立显示，能够直接看出哪张卡还剩几柄；一张卡减少数量时，其余卡牌保持原状。

沿用原作雨帘剑的细长剑身、上端卷纹剑柄与向下剑尖。剑身为浅青白亮芯、清透水蓝外缘，保留剑柄卷纹和尖端形状，周围只有少量细水光与水珠。整体轻盈、清澈，明暗能读出独立剑形，不糊成几根粗亮管。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 单柄雨帘剑 | 细长水蓝剑身、卷曲剑柄纹样、向下尖端；薄透主体与局部亮边有层次 |
| 环绕分布 | 围绕单张卡牌竖轴分布的独立幻剑，有卡前、卡侧与卡后的深度关系 |
| 剑身细水光 | 少量沿剑身流动的细亮纹，错开明暗与相位，保持轮廓清楚 |
| 显形水丝与水珠 | 起手和数量补回时短暂聚起的细水丝与小水珠，迅速让位给剑身 |
| 退出水片与余光 | 剑身化开的薄水片、零星水珠与渐弱余光，可从当前环绕位置自然散尽 |

## 起手出现

卡牌周围先出现很薄的青蓝水光，细水丝沿各柄剑的位置勾出剑柄与剑身，剑尖随后变得清楚。几柄剑在短促、略有错开的显形中建立完整分布，轻轻浮起、稳定，进入持续环绕。

起手以实际数量建立，不先显出四柄再隐藏多余部分。多张卡同时获得雨帘剑时，各自围绕本卡显形，整体时机紧凑，微小水珠与明暗变化可以错开，卡面人物始终清楚。

## 持续循环与卡牌空间

幻剑以卡牌中下段为环绕中心，沿卡牌竖轴缓慢绕行，并有很轻的上下浮动。剑尖总体朝下，剑形稳定可辨；绕到侧面时有真实的方向变化与厚度，经过卡后时被卡牌合理遮挡，转回卡前时自然显露。

环绕靠近本卡，主要利用卡侧与下半部空间，给头像、卡绘面部、生命／能量、卡底四格对象和数量留出位置。卡前的剑身保持轻薄，幻剑与相邻卡牌之间有明确归属，不把四张卡包成一个大圈。

各柄剑的水纹、微小起伏和余光略错开，环绕主方向保持连贯。循环首尾自然，长时间维持时数量、亮度和水珠密度稳定。卡牌移动时，整圈跟随当前卡牌，局部环绕不跳回初始角度。

## 数量变化与爆发沿用

可见数量支持当前剩余的1、2、3、4柄。初始上限通常为3柄，获得相应命座后为4柄；最终显示以该张卡本次实际数量为准。每一柄有清楚间隔，可以通过剑本身读数，不额外堆一圈装饰剑。

减少时由本次参与[抵消动画](../RainSwordAbsorb/视觉需求.md)的那柄剑离开环绕并碎散，剩余剑保持当前相位，缓缓调整间隔。增加或补回时，只在空缺处凝成新增剑，现存剑继续绕行；续时或满数量刷新时，局部水纹轻轻呼应即可。

**爆发状态沿用这套雨帘剑主体、环绕和起退场。** 爆发期间的抵消与补回在局部完成，整圈继续运行，不另外叠一套同形剑圈。爆发触发的[剑雨](../SwordRainVolley/视觉需求.md)是独立发射的幻剑，环绕剑保持可见，不因为每次协同攻击而全部离轨、消失、重新出现。

## 消失收尾

实际状态结束时，剩余幻剑从当前环绕位置依次收住，剑身边缘向薄水片与细水丝化开，卷纹和剑尖稍后淡去。少量水珠沿短小弧线散开并落尽，最后清除细余光。退出可以从循环的任意位置开始，环绕方向和前后关系连续。

最后一柄已在抵消中耗尽时，沿那次碎散直接收尾，不凭空补出整圈再退场。普通到期则让现存剑一起轻柔化开，节奏比受击破碎舒缓。
