# 行秋 · 雨帘剑抵消与破碎

## 整体观感

受保护的角色卡牌遭到攻击时，本卡的一柄雨帘剑短促响应，在接触方向形成薄水光，随后剑身碎散为水片和水珠。动作紧凑，有“水剑接住冲击、失去一柄”的可读变化，剩余剑继续环绕。

沿用[雨帘剑持续状态](../RainSwordsState/视觉需求.md)的清透青蓝材质和实际环绕位置。抵消发生在受击的那张卡旁，范围紧贴本卡，既看得出挡住冲击，也保留敌方攻击和卡面受击动作的可读性。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 响应雨帘剑 | 从当前环绕位置短促提亮并略向接触方向倾动，保留原剑形 |
| 局部抵挡水光 | 在受击方向展开的一小片青白水光与薄弧面，有受压、扩散、快速回收的变化 |
| 剑身碎散 | 长剑形从接触处化成少量薄水片与较细水丝，先保留破开的剑形轮廓，再散成水珠 |
| 飞散水珠 | 沿接触方向与两侧短距离散开，大小、速度和消失时机错开 |
| 补回凝形 | 爆发期间在本次空缺处短促回流、凝成一柄剑，与破碎余光相接 |

## 抵挡、耗剑与余势

一柄剑从当前相位就近响应，向受击方向短促偏移，亮度迅速冲高，接触处压出一片薄水光。剑身紧接着破开，碎成清透水片与水珠；水片边缘迅速软化，细水丝被带出很短的余势，随后散尽。

破碎有清楚的接触瞬间，前后速度有变化，保持水体的流动感。不要把薄水片做成硬冰碎块或金属碎剑，也不产生大范围爆炸、整张卡的球形护盾或覆盖全队的蓝幕。

同一攻击行为的连续命中可以先有轻微局部水光呼应，最终扣除一次雨帘剑时，完整表现一次耗剑。不能因为同一行为含多段hit就逐段把整圈剑消耗完；具体破碎数量与这次实际扣除一致。多张卡分别受到攻击时，各自本地响应，其他卡的剑圈继续维持。

## 数量减少与爆发补回

普通抵消后，参与破碎的剑从这张卡的环绕中消失，其他剑保持原来的连续运动，间隔自然舒展。最后一柄耗尽时，破碎余效就是本次状态显示的收尾，不再重播一遍完整退场。

爆发期间仍有清楚的抵挡响应；本次耗剑碎散后，水丝在同一圈的空缺处迅速回流、重新凝成一柄剑，回到当前环绕节奏。补回与破碎尾效稍有交叠，观感为局部水剑再生，整圈没有长时间缺口，也不整组闪灭重启。

普通的数量刷新采用柔和凝形，不附带受击闪光。状态到期采用持续状态的轻柔化开，不把所有剑都演成遭到一次攻击。治疗若同时发生，沿用实际治疗表现，水剑破碎本身不新增绿色数字或额外治疗符号。

## 高频响应与收尾

后续抵消发生时，从仍在运行的环绕中接续；前一次余水可以尚未完全消失，但各次接触亮核短促可辨。水珠数量与亮度不会随触发次数永久积累，已经碎散的剑不会继续参与下一次抵挡。

碎片、细水丝与水珠各自收尽，最后只保留当前真实剩余或补回后的雨帘剑。局部水光尺度、响应偏移、破碎力度、水珠短距、余效时长与补回速度可分别调整，保持整张卡周围的轻盈感。
