# 优菈 · 冰潮的涡漩长按主斩

## 整体效果

长按以更充分的蓄势和更强的冰色大剑挥斩覆盖本轮全部实际敌人。剑路、冰霜展开与接触质感参考原作，主斩与短按清楚区分：更完整的扫面、更沉的接触与更充分的余势。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 长按蓄势 | 大剑动作前寒光短暂集中，速度收紧 |
| 全体冰色主斩 | 一道连续大斩弧，覆盖本次真实敌方区域 |
| 霜面与拖尾 | 贴随主斩的冰霜扫面，有厚薄和透明层次 |
| 接触碎冰 | 与同一次全体接触一致的局部碎冰、薄霜 |
| 收势余霜 | 主斩先变薄，冰屑与细霜稍后散尽 |

## 全体主斩与分段衔接

蓄势后明显加速，主刀光抵达时整组实际目标统一接触；接触短促有阻力，随后借余势收住。按本段真实目标合并范围调整弧长、朝向和扫面，各目标只补局部接触，主挥击保持一次。

本项只负责长按主斩。消耗冷酷之心后的[冰涡之剑](../IcewhirlBrand/视觉需求.md)是独立的一段演出，具有自己的凝形、出射与接触。消耗两层且天赋有效时，再衔接[残缺光降之剑](../ShatteredLightfallSword/视觉需求.md)的额外物理爆发。

冷酷之心实际消耗后卡底数字更新，后续剑数使用本次真实消费结果；主斩和已发出的冰剑继续完成自己的尾效。减物抗、减冰抗、一命增伤、二命冷却与等级变化沿公共显示。
