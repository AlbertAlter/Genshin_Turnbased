# 优菈 · 冰涡之剑独立演出

## 整体效果

冰涡之剑按原作单独制作完整一段，包含原作式剑形凝聚、旋转／出射运动、命中和冰碎收尾。剑体轮廓、冰晶结构、冷色层次与准确运动方式以原作对应片段为准，保留其专属识别点。

本段与[长按主斩](../IcetideVortexHold/视觉需求.md)分别组织，使用消费冷酷之心后的真实剑数与目标，不以主斩扫光代替冰剑本体。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 冰涡剑体 | 原作式独立冰剑，剑形与切面清楚，冰白亮缘和较深冰蓝主体有体积 |
| 凝形寒光 | 剑体出现时聚起的短寒光与少量细晶 |
| 旋转／出射运动 | 对照原作的完整运动，剑身方向、轨迹与尾迹一致 |
| 短冰色尾迹 | 紧跟剑体已经走过的路径，收尖和渐隐自然 |
| 命中冰碎 | 实际目标处的一次短促冰光与剑体碎散 |
| 消散余霜 | 剑体接触后少量细霜继续漂散，完整收尽 |

## 出现、命中与真实剑数

先保留长按的整组主斩接触，再在后续阶段显出本次实际冰涡之剑。每消耗一层冷酷之心释放一柄，当前最多两柄；0层时不生成冰剑。

每柄各自完成原作式凝形、运动和命中，使用该次业务已经选择的随机单体目标。两柄可以按实际结果命中同一敌人，保留两柄与两次真实接触，不强制分配给不同卡牌，也不按敌人人数复制更多冰剑。

具体出现位置、旋转、出射与节奏制作时对照原作完整片段。后续正式播放使用每柄的实际源位置、目标与接触时点，保持视觉连续；尾迹与冰屑不增加hit。所有主体与尾效收尽后本段结束。

## 与残缺光剑的关系

消耗两层并满足潮卷冰削时，后续[残缺光降之剑](../ShatteredLightfallSword/视觉需求.md)形成自己的额外爆发。冰涡之剑仍是本段独立冰伤，残缺光剑使用另一套物理光爆，两者有清楚先后与形态区别。
