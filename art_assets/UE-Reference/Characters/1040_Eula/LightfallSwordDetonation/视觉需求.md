# 优菈 · 光降之剑原作引爆

## 整体效果

光降之剑的实际引爆沿用原作完整触发演出：剑体进入原作引爆姿态，接着出现相应的主闪光、物理光爆、碎光与余波，最后剑体和光效完整收尽。具体剑体变化、运动和展开方向制作时逐帧对照原作。

整体保留原作浅色／白金物理光爆气质，与施放时的冰元素斩击分清。引爆强度沿该把剑最终真实层数组织明暗与力量层次，范围始终按本轮实际敌方全体。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 原作剑体触发变化 | 从右上角前方当前剑姿态进入原作引爆过程，形态与运动对照实机 |
| 主引爆光 | 原作式的集中亮部与光爆轮廓，高潮短而清楚 |
| 全体接触与余波 | 按真实敌方范围展开的一轮物理光爆，各目标只补局部接触 |
| 剑体碎光 | 与原作剑体消散一致的光片和细碎亮点 |
| 消散尾光 | 主光先退，少量碎光和余波稍后收尽 |

## 从实际剑体衔接

引爆从[右上角前方的那一把剑](../LightfallSwordState/视觉需求.md)当前姿态开始，增层脉冲或满层光晕自然衔接，不先清空本剑再在无关位置重播一把。主体的原作触发、光爆和收尾保持完整。

每把剑使用自己的最终真实层数。0层仍有该剑实际基础引爆；层数越高，可加强原作主光的完整度、亮度层次和接触力量感，保持实际攻击段数。30层的满层气息与原作引爆共同收束，避免额外添加一轮满层爆炸。

## 全体命中、多把剑与退出

每把剑引爆是一段对实际敌方全体的独立物理伤害，整组共用一轮主光爆。覆盖按真实目标合并区域调整，兼容一至五人、上下错排与空档，各目标只补局部接触。

多把剑分别按实际状态与伤害执行各自的引爆，不能按合并层数只播一次，也不因为人数增加重播整组光爆。实际到期、切后台和其他生命周期以真实业务结果为准，显示不主动结算或改变引爆顺序。
