# 优菈 · 凝浪之光剑施放

## 整体效果

爆发施放先使用参考原作的冰色大剑挥击，对本轮实际敌方全体形成一次清楚接触；随后在优菈卡牌的右上角前方显现一把原作式光降之剑，连贯进入持续状态。

冰色主斩与后续光剑各有自己的主体：前者承担本次施放的冰伤，后者是等待积攒与引爆的剑体。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 爆发起势 | 短促集中、具有优菈原作气质的寒光与大剑发力 |
| 全体冰色斩光 | 一道完整主刃与冰霜扫面，覆盖本次真实敌方区域 |
| 局部接触冰屑 | 同段目标处克制的冰光、碎冰与薄霜 |
| 光降之剑显现 | 原作剑形从淡光中清楚形成，稳定到卡牌右上角前方 |
| 过渡余光 | 主斩余霜消散，剑体转入自身持续冷光与微光 |

## 主斩与光剑出现

优菈实际登场后完成起势，主冰色斩光迅速展开，在同一主要时点接触本轮全部实际敌人。范围按真实卡位合并区域组织，各目标只补局部接触。

主斩完成后，[光降之剑](../LightfallSwordState/视觉需求.md)在自身卡牌局部右上角、卡面前方建立。剑体保持原作轮廓与比例，短暂亮光和凝形后进入稳定悬浮，后续位置与增层反馈由持续展示承担。

天赋重置战技冷却和获得冷酷之心沿公共冷却与[卡底计数](../GrimheartBottomStatus/视觉需求.md)显示。六命新剑直接按初始5层出现，普通新剑为0层，均不在施放阶段提前引爆。
