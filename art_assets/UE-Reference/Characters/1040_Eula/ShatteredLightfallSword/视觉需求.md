# 优菈 · 潮卷冰削残缺光降之剑

## 整体效果

长按战技实际消耗两层冷酷之心且潮卷冰削生效时，额外形成原作式残缺光降之剑，并立即引发一次物理光爆。残缺剑形和爆发质感参考原作，整体较普通蓄能光剑引爆更短、更轻，仍有清楚剑体与接触。

本项与[冰涡之剑](../IcewhirlBrand/视觉需求.md)分别制作。它是即时追加攻击，没有独立积攒0～30层的持续阶段。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 残缺剑体 | 原作残缺光剑的轮廓、护手与缺损识别点，细部制作时核对 |
| 短促凝光 | 从局部亮光快速显出剑形，时间短而可辨 |
| 即时物理光爆 | 与完整光降引爆同系的浅色／白金光爆，规模和余波克制 |
| 接触与尾光 | 全体实际目标同次接触的局部亮点，碎光随后收尽 |

## 条件、衔接与一次引爆

长按主斩及本次冰涡之剑的实际后续阶段完成后，按真实追加伤害衔接残缺剑形与即时光爆。两层冷酷之心的消费结果决定是否出现，卡底已经归零也不丢失这次已实际触发的演出。

整组实际目标共用这一把残缺剑和一次主光爆，覆盖按实际范围展开，各目标只补局部接触。其50%基础伤害是业务倍率，不直接换算为模型一半尺寸；视觉以原作残缺版本的比例和力量感为准。

该追加爆发保留自己的真实接触，剑体和碎光收尽后结束。不因此创建一把持续光降之剑，也不显示30层循环。
