# 优菈 · 右上角前方光降之剑与30层反馈

## 原作剑形与位置

光降之剑使用原作完整剑形、剑身细部、护手／翼饰及光色，保留浅色剑体与有层次的亮边。准确轮廓和比例制作时对照实机。

剑位于实际宿主卡牌的局部右上角，并处在卡面前方。挂点随卡牌位置、尺寸、旋转和展示缩放移动，不使用全屏右上角。位置、剑体尺寸与距卡面的前后关系可以调整，保持剑形清楚，同时留出生命、元素、状态和操作信息的可读性。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 原作光剑本体 | 完整可辨的剑身、剑尖、护手与原作细节，保持稳定比例 |
| 出现凝光 | 从淡光勾出剑体、逐渐建立亮边的短过程 |
| 持续微光 | 围绕剑体的克制流光与少量细碎光点，首尾连续 |
| 增层闪光 | 每次真实增层时短促增强剑刃与护手亮边，再回到持续亮度 |
| 增层缩放 | 剑体轻快放大、带小幅回弹后恢复基准尺寸 |
| 满层流光与轮廓光 | 首次到30层的一次流光扫剑，以及更清楚的白金外缘和少量环绕粒子 |
| 引爆过渡 | 从当前循环相位平顺衔接原作引爆动作 |

## 出现与0～30层维持

[爆发](../GlacialIlluminationCast/视觉需求.md)建立真实光剑后，淡光先勾出轮廓，剑身与护手随后清楚出现，在卡牌右上角前方稳定悬浮。0层也是有效光降之剑，剑体持续存在；普通状态层数数字与本剑存在分别处理。

每把实际光降之剑都有自己的0～30层和生命周期。六命新剑以初始5层出现，初始显示不伪造连续五次增层。多把同时存在时，仍在该卡右上角前方小幅错位并保留各自剑体、亮度与反馈，不把层数合并给一把剑。

## 每次真实增层的闪光与缩放

每次有效层数上升，都在对应那一把剑上做一次短促闪光和缩放反馈：剑刃、护手亮边迅速增强，剑体轻快放大，随后减速、轻微回弹并回到基准尺寸。光点沿剑身掠过，方向连续，反馈清楚而短。

短时间连续增层时，从当前姿态顺接下一次反馈，平滑增强或续接脉冲，保持每次增层可感知，收尾始终回到基准尺寸。反馈不因高频事件积累成持续巨剑或长时间排队播放。

相同层数的重复刷新、达到30后的未增加请求及普通状态续时保持当前循环。六命概率追加的一层，只在业务实际增加后反馈，表现不重新判随机。

## 30层特殊效果

首次从不足30进入30层时，在本次增层闪光与缩放上，增加一次由剑身一端沿刃锋扫过的明亮流光，护手／翼饰轮廓短暂展开柔薄光晕，少量白金碎光向外散开。

随后进入满层循环：原作剑形保持不变，白金轮廓光比普通层数更完整，剑锋流光更清楚，稀疏粒子沿前后层次缓慢绕行。亮度有平滑呼吸，保留剑体细节和卡面，满层起势只播放一次。

达到30层只强化持续展示，光剑仍等待实际到期或切换后台等真实引爆条件，不因满层自行增加一次伤害或提前结束。

## 引爆与其他退出

实际引爆时，从当前悬浮或满层相位进入[原作引爆](../LightfallSwordDetonation/视觉需求.md)，剑体、闪光、缩放和满层粒子完整衔接该次收尾。该把剑结束后，其余仍有效实例继续自己的展示。

未发生实际伤害的显示会话取消只清理本剑与粒子；视觉不能把所有隐藏或清理都当作引爆。数值归零本身也不等于状态消失。

## 当前源工程边界

首版以浅色剑刃、立体中央刃脊、分层翼饰与细流光自行制作，没有提取或精确复制原作模型。原爆发动图在限定下载时间内未取全，完整剑形细部与原作引爆运动仍待进一步核对；不把这一版称为原作精确还原。

独立示例包括零层、初始5层、30层、两把剑和增层反馈。零层不隐藏剑体，两剑分别提供Count与SecondCount；SwordSize、SwordOffsetX/Z、ParticleSize分别控制剑体尺寸、宿主局部位置和小光点尺寸。增层示例为0→1→2→29→30，之后重复30不重播缩放；首次进入30时额外扫光。以上只展示制作样本，不改变真实Count，也未接入显示脚本。
