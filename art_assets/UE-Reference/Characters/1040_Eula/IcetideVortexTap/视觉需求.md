# 优菈 · 冰潮的涡漩短按

## 整体效果

一次短促、利落的冰色挥斩覆盖实际相邻三名敌人。参考原作冰潮的涡漩的剑路与冰霜质感，以清楚冰白刃沿、淡蓝扫面和少量冰屑体现挥动大剑的力量。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 挥斩起势 | 短促收束的寒光，方向与剑路一致 |
| 主冰色刀光 | 一道贯通整组目标的完整斩弧，前沿锐利，尾部拉薄 |
| 随行霜迹 | 紧贴刀光已经走过的路径，边缘连续渐隐 |
| 局部接触 | 实际受击位置的短冰光、细霜与冰屑 |
| 收势余光 | 沿挥斩方向滑出少量余势后收尽 |

## 一次挥斩与真实范围

起势紧凑，出刃加速，接触一刻斩弧最完整，随后顺势拉薄。整组三人共用一道主刀光，朝向、弧长与扫面按本轮真实目标合并范围调整；上下错排或不足三人时保持完整覆盖，各目标只补局部接触。

当前短按只有一段主伤害，装饰冰屑与尾迹不增加命中。取得冷酷之心与能量后，分别沿[卡底数字](../GrimheartBottomStatus/视觉需求.md)和公共资源显示更新。普通增伤、冷却与等级变化沿公共显示。
