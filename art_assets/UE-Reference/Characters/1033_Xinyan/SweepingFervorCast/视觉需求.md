# 辛焱 · 热情拂扫施放

## 整体效果

按原作热情拂扫制作挥动乐器时的火焰扫击。保留原作扫击火形、运动方向、前沿与拖尾的厚薄、橙红火体和明亮亮芯，以及扫出后迅速收势的节奏。提炼乐器挥动带出的特效，不额外增加人物模型或整段身体表演。

本项目战技作用于实际敌方全体，整组目标共用一轮完整火焰扫击。实际范围、接触与后续护盾建立沿项目安排，原作火形仍是视觉依据。

这一轮维持一个连续的火焰扫面，按本段真实目标的合并范围统一调整弧长、方向和覆盖，各敌人只补局部火花。主扫击读作一次完整挥动，不因人数增加分成多套逐卡火弧。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 起势火光 | 从施放者附近短促聚起、顺挥扫方向集中，亮度有先后 |
| 火焰扫击主体 | 对照原作的宽窄、弯曲轮廓与推进方向，亮芯清楚、外缘柔和 |
| 挥扫尾焰 | 随已经走过的路径拉开，端部与两侧渐隐，有速度和收尖 |
| 接触火花 | 实际受击位置的短促火星、薄火片，与主扫击同轮接触 |
| 收势余焰 | 主体先拉薄，较淡火片与火星稍后散尽 |

## 起势、扫出与收尾

火光先集中，火焰主体随后快速扫出，前沿和尾焰有清楚主次，不能全程等速平移一块火焰贴片。具体挥扫方向、展开形状与持续在制作时对照原作实机。

按实际敌方卡位合并范围组织扫击，兼容一至五人及上下错排。全体主伤害只有一段统一接触，不为每个敌人各重播一套完整扫击；面积扩大以覆盖和火片分布调整，局部火星尺寸保持合理。

主扫击结束后，完整火焰迅速收势，短尾焰和细火星依次消散，衔接[热情拂扫护盾](../SweepingFervorShield/视觉需求.md)。不在每次护盾喷火时重新播放本次战技施放。
