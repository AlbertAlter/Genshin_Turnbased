# 北斗 · 斫雷持续状态

## 整体观感

参考原作斫雷绕身游走的紫色雷兽电纹，在实际状态持有者的卡牌周围形成持续环绕的雷光。主体为**两道细长、带雷兽首部与曲折纹理的电光轮廓**，前后错开绕行，尾部逐渐变细、化为断续电丝。保持原作雷兽之盾的识别点与通透感，卡面仍清楚可见。

主色为紫罗兰与偏冷的亮紫，最亮的电芯接近淡紫白，外侧只有适量紫色柔光。雷兽具有清楚的首部、细长身段和收窄尾部，不做厚重实体龙，也不把整圈画成等宽、匀亮的霓虹管。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 雷兽环绕主体 | 两道细长的雷兽形电纹，首部可辨，身段带少量折线、尖角与亮暗变化，尾部自然收窄 |
| 随行电丝 | 沿雷兽已经经过的路径留下少量紫白细丝，短暂断续后消散，不累积成厚实光圈 |
| 游走小电弧 | 在环绕主体附近偶尔出现的细小分叉电弧，各自闪现与熄灭，亮度低于触发雷击 |
| 起手雷光 | 短促聚起并向外舒展的紫色电光，带出雷兽轮廓的建立，然后让位给持续主体 |
| 消散余电 | 退出时逐渐破开的细电丝、零星光点和末端余辉，密度与亮度依次减弱 |

## 起手出现

卡牌周围先聚起少量紫白电丝，随后一次短促的雷光舒展，带出两道雷兽首部和延伸的身段。雷兽沿绕行方向逐步显形，尾部稍晚接上，顺势进入持续环绕。起手具有清楚的起势与展开，高潮短促，不把完整循环突然打开。

环绕集中在卡牌中下部与两侧，路径略带高低起伏。建立时保留卡面中央与角色面部的可读性，不用覆盖全卡的白闪或厚紫雾遮住造型。

## 持续循环

两道雷兽持续绕同一张卡牌游走，有卡前与卡后两部分：经过卡后时由卡牌自然遮住，经过卡前时以细长电纹短暂掠过，不整片盖住卡绘。头部运动带出身段，尾丝稍有滞后；环绕速度有轻微起伏，避免机械匀速转盘的感觉。

主体轮廓持续存在，细电丝与短小分叉各自错开闪动；不让整组效果同步明灭，也不把循环的首尾做成重新聚气。没有攻击触发时维持克制的护身雷光，不自行向敌方发射雷击。

一次连锁雷击触发时，靠近本次触发位置的雷纹短促提亮，随后自然回到平时亮度；两道雷兽继续沿当前相位运行，不重播起手、不停止环绕。对应的一次性雷击见 [斫雷触发与连锁闪雷](../StormbreakerDischarge/视觉需求.md)。

环绕半径、中心高度、路径起伏、卡前后距离、雷兽粗细、速度与电丝密度需要能够分别调整。扩大环绕范围时保持细节尺度合理，不连同雷兽头部、光点和柔光一起变成遮挡卡面的巨大光团。

## 消失收尾

从当前环绕相位自然退出：不再补入新电丝，雷兽身段逐渐收细并断开，首部亮度减弱，尾端与零星余电稍晚消散。各部分依次收完，不要求转回固定起始角后才能消失，也不突然切掉整圈。

收尾克制、轻快，避免再演一次攻击爆炸。起手、循环、消失三段衔接完整；本项实机动图没有完整展示自然到期，消失段按本项目持续状态的视觉需求补足。
