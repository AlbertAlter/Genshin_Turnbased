# 北斗 · 斫雷触发与连锁闪雷

## 整体观感

参考原作斫雷触发时在敌人之间跃动的紫白闪雷。一次触发具有清楚的**首个目标接触、向后续目标依次传导、余电收尽**：电光尖锐、短促、有爆发力，能够看清相邻两次接触之间的连接，不演成缓慢飞行的电球。

雷电主干偏淡紫白，外围为亮紫与克制的紫罗兰柔光；粗细不均、有少量折转和短分支，主路径与接触点最亮。保留原作利落的放电感，不做等宽直激光、火焰爆炸或长时间遮住整排敌人的紫色光幕。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 触发呼应 | 实际状态持有者的护身雷纹局部短促提亮，表示一次放电已发生，原环绕继续运行 |
| 首次接触电核 | 首个实际命中目标处的短促紫白亮核，向外散出少量尖锐电丝 |
| 目标间主闪雷 | 从前一个目标接触位置连向下一个目标的曲折电光，亮芯、较薄紫色外层与端部渐隐有层次 |
| 次级分叉 | 主闪雷侧面少量更细、更短的电丝，不伸向无关卡牌，不抢过主链亮度 |
| 各次接触闪光 | 每次抵达目标时局部亮起的电核与短电弧，轻快明确，随后让位给下一段传导 |
| 断续余电 | 已经过的路径短暂留下一点细丝，迅速收窄、断开并淡去，不留下常驻连线 |

## 触发与首个目标

触发时，护身雷纹短促提亮，首个实际命中目标处紧接着闪出紫白电核与局部电弧。两处呼应要紧凑，第一接触不额外等待一个缓慢跨场飞行的弹体，也不强加一根从画面顶端落下的巨大天雷。

普通攻击自身的刀光、物理接触与这次附加闪雷能够区分。闪雷从本次实际接触位置展开，局部亮核足以读清命中，不需要额外的全屏白闪、镜头切换或伤害跳字。

## 连锁跃动

首个目标接触后，亮起的电路从该目标向下一个实际目标快速贯通，随后再从新的接触位置向后续目标跃动。保留很短的先后与亮度接力，形成“击中、传导、再击中”的连续感；不让所有目标同时各自从北斗处拉出一条放射线。

主干大方向由两个真实接触位置决定，小范围折转、分叉与粗细变化带出电流感。路径几乎瞬间贯通，亮度迅速冲高再衰减，不用匀速光点沿整条曲线慢慢爬行。连接在空间中有轻微起伏，经过卡牌时保持合理前后关系，不为装饰绕场一大圈。

显示本次实际发生的目标顺序与接触次数。目标可以重复，回到先前目标时能够看出新的传导方向与接触闪光；不能仅因那张卡已亮过而漏掉这次接触。实际只有一个命中目标时，以该处局部闪雷完整收尾，不补出虚构目标或额外弹跳。

前一段路径尚有细弱余电时，后一段主闪雷已经开始，传导紧凑而不糊成常驻网。新的触发可以接在旧余电消散期间发生，各次主链仍可辨认；亮度不会因为触发次数增加而一直累积。

## 收尾与持续状态

每次接触后，亮核迅速缩小，周围短电弧先后熄灭；路径主干变细并分成少量不连续余丝，最后散尽。最后一次接触与尾效全部收完后，这次连锁结束，不残留连接线或悬空电球。

[斫雷持续状态](../StormbreakerState/视觉需求.md) 在整次触发期间保持原相位环绕，触发结束后回到平时亮度；不因链条收尾而消失，也不重新从零出现。主干粗细、折转幅度、分叉密度、接触闪光尺度、传导间隔和余电时长应能分别调整，长距离连接不直接放大接触光团。
