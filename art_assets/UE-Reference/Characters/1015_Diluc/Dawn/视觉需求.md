# 迪卢克 · 黎明爆发火鸟

## 整体观感

以一只由烈焰构成的大火鸟作为主体，保留清楚的鸟首、向两侧展开的羽翼和拖曳的长尾。核心为亮黄至浅黄白，主体橙金，外沿过渡到橙红；羽翼由有厚薄差异的火焰羽片组成，羽片之间透气，不能糊成一整块椭圆火团。火焰、拖尾与飞散火星的层次沿用之前的火系特效。

完整演出按“从右向左冲出屏幕—从敌方全体上方落下—命中后一次爆炸”的顺序进行，三段分别对应三次hit。前两段是同一只火鸟的连续行动，落下后才发生最后一次爆炸，阶段之间要看得出先后。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 火鸟主体 | 有可辨的头部、躯干和张开的双翼；中心明亮，外沿保留红橙火焰，飞行时形体保持完整 |
| 火焰羽片与长尾 | 组成羽翼外轮廓与尾羽，前端相对集中，后缘撕出细长火舌；随冲刺方向后拖，减弱时逐渐收窄 |
| 飞行拖尾与火星 | 沿火鸟已经飞过的路线留下有明暗、粗细变化的火迹，火星错开脱离并减速熄灭，不排成匀速光点队列 |
| 命中闪光与冲击火纹 | 俯冲接触时出现短促、清楚的黄白亮部与横向舒展的火纹，标出第二次hit，与随后爆炸分清 |
| 爆炸火团与外扩火环 | 落点处产生一次覆盖敌方整体范围的爆炸；中心先亮，火团外翻，断续火环与碎焰向外扩散 |
| 余焰、火星与轻烟 | 爆炸主体减弱后继续散开，明暗和消失时间错开；烟保持轻薄，完整收尾后不留下常驻火场 |

## 第一段：右向左冲出屏幕，对应第1次hit

火鸟从画面右侧出现并朝左展开冲刺，带着张开的火翼横向掠过，快速越过画面左边缘，直至主体与尾羽完全出画。冲出的过程有明显加速与拖曳感，由鸟首带领方向，双翼与长尾依次掠过，让冲刺方向一眼可读，不能以整张静态火鸟贴片恒速平移代替。

横向火焰冲击形成第一次hit的视觉节点，只出现一次明确的冲击亮度变化；飞散的羽片、拖尾和火星属于同一段余势，不再逐个形成额外hit。鸟身冲出后只留很短的衔接余焰，避免与下一段落下重叠成两只火鸟。

## 第二段：从敌方全体上方落下，对应第2次hit

火鸟出画后，重新从画面内敌方整体区域的上方出现，转为向下俯冲。鸟首朝向落点，火翼仍能看出展开的轮廓，尾羽与火星向上后方拉长。接近敌方时加速，落下的方向与先前横向冲出明确区分。

这一段的“上方”是敌方卡牌区域在画面中的上方，俯冲覆盖敌方全体的整体范围，兼顾上下错排的卡位。使用同一只火鸟形成一次群体落下的观感，不把每张敌人卡都变成一只互相重叠的火鸟。到达敌方卡牌区域时出现一次清楚的接触闪光和冲击火纹，作为第二次hit，火鸟轮廓开始散成碎焰。

## 第三段：命中后产生一次爆炸，对应第3次hit

第二段接触后紧接一次火焰爆炸，视觉顺序是先撞击、再爆开。爆炸围绕敌方整体落点范围展开：中心短促增亮，橙金火团向四周翻卷，夹带断续火环、碎焰和飞散火星，形成比接触闪光更强、更宽的一次高潮。

全体敌人处于同一次爆炸的覆盖中，不沿卡位逐个连爆，也不追加第二轮爆炸。高潮后火团快速衰减，外沿火舌收窄，余烬和轻烟稍晚散尽；不遗留持续燃烧区域。

## 三次hit的视觉对应

| hit | 对应画面 | 识别重点 |
|---|---|---|
| 第1次 | 火鸟由右向左横向冲出阶段的火焰冲击 | 横向速度、火翼扫过和一次冲击变化 |
| 第2次 | 火鸟从敌方全体上方向下落到目标区域 | 俯冲接触的短促闪光与冲击火纹 |
| 第3次 | 俯冲命中后覆盖敌方整体的一次爆炸 | 火团外翻、外扩火环及最后的余焰收尾 |

三次是三个先后可读的节点，装饰火星与羽片不增加hit；没有命中的飞行过渡也不额外补一次冲击。
