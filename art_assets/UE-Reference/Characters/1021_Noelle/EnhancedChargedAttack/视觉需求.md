# 诺艾尔 · 强化重击的纵深旋劈

## 整体观感

强化重击使用金色岩剑做**垂直于屏幕平面的旋转劈下**。巨剑先向上与后方蓄势，再沿包含竖直和前后纵深的平面加速翻转，携带整片岩光向下劈落。正面能看清明显的近远变化、剑身透视和由上向下的压迫感。

重击比强化普攻有更充分的蓄势、更强的接触顿挫和更沉的收势。金色剑身有明确棱面与厚度，刃口浅金白，后随岩光偏金黄与琥珀，剑尖与接触区域形成最强亮度。

## 视觉部件

| 部件 | 视觉要求 |

| 上举蓄势 | 岩剑抬向上方与纵深后侧，握持端和剑尖有重量传递，亮度短暂收束 |
| 纵深下劈轨迹 | 随剑身沿竖直与前后方向翻转的金色光带，迎面段变宽、远侧段收窄，端部连续渐隐 |
| 全体岩光接触面 | 下劈时向敌方整组横向展开的一片低而厚实的岩光切面，与主剑同刻接触全体 |
| 接触岩屑与余震光 | 命中处短促飞出的岩屑、碎晶与向外推开的浅金余光，顺受力方向散开 |
| 剑尾与收势 | 主剑劈落后的短距离余势，拖尾、岩屑与余光依次收完 |

## 旋转平面与蓄势下劈

**旋转平面垂直于屏幕，包含上下方向与前后纵深；旋转轴沿画面左右方向。** 岩剑由上方和后侧翻向前下方，利用透视、遮挡和剑尖轨迹清楚表现纵深中的旋劈。

蓄势时先压住速度，剑尖略晚跟上握持端，表现巨剑被提起的分量；出手后迅速加速，靠近接触时将力量集中向下。接触瞬间极短地压住动作，之后继续少量下沉，带出阻力与回弹，再缓慢收住余势。

剑光来自实际经过的弧线，迎面部分有宽度与压迫感，侧边和尾端保持柔和渐隐。岩屑在接触一刻顺力散开，细碎余光稍晚出现，形成由主剑到接触面、再到碎屑的层次。

## 覆盖并命中全部敌人

主岩剑与同一次下劈的接触岩光按**当前全部敌人的合并范围**展开。岩剑的纵深旋劈保持整体方向，接触时岩光切面横向贯通整组敌人，兼容上下错排、两端目标和不连续卡位。

每段实际hit共用一把主岩剑、一道纵深刀光与同一次接触切面，保持连贯的下劈。各目标的亮点和岩屑来自这个共同切面，范围变化时调整其整体覆盖，不逐卡增加一把剑或一轮旋劈。

全部实际敌人在本次hit的同一个时刻接触，局部岩光、受击和数值同步开始。横向展开的接触面是主剑这一劈的延伸，接触高潮统一，余波随后散开，不将横向覆盖变成第二轮攻击。

## 收势与力量感

命中后岩剑有少量继续向下的余势，随后受阻停稳并收回；接触面变薄，岩屑与碎晶沿各自轨迹飞散、回落和淡去。主轨迹先收完，少量余辉稍晚结束，卡面重新清楚。

蓄势、加速、顿挫与收势之间要有明显速度差。力量来自大剑体积、纵深透视、接触阻滞和碎岩受力的一致性，主亮度只在接触附近短促冲高。重击接触覆盖、剑身宽厚、轨迹厚度、岩屑大小与数量分别调整。

## 后续 timeline 配合备注

后续 timeline 将下劈接触、全体接触岩光、受击、跳字与震动统一对齐每个实际hit。震动以**下劈方向的短促向下冲量**为主，随后一次较小的向上回弹并迅速衰减，配合接触顿挫与岩屑推出；纵深压迫感主要由岩剑与轨迹承担。

重击的震动强于强化普攻，并与实际劈下方向一致。一个群体hit共用一次整体震动，尾效不重复产生强震。此处为后续 timeline 的制作备注，当前只记录视觉需求。
