# 魈 · 风轮两立

## 整体效果

提炼原作风轮两立的高速穿刺感：短促蓄势后，一束锐利的青绿风光迅速掠向本次受击区域，带出收束的长条风痕与细碎风丝。前端亮而集中，后方逐渐拉薄，速度有明显爆发与余势。

卡牌保留当前站位与既有施法动作，由穿刺风光、拖尾和目标处接触承担冲刺感。范围按本次实际相邻三名敌人的位置展开，保持一轮连贯攻击的观感。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 起势风光 | 在魈卡牌附近短促聚拢，轮廓向攻击方向收紧，快速进入发出阶段 |
| 穿刺主体 | 青绿明亮前锋，带有原作风轮两立的利落形状和深浅层次；沿前进方向拉长 |
| 主拖尾 | 跟随前锋留下的风痕，前段较实，后段散成细丝，端部连续渐隐 |
| 外围风丝 | 少量弯曲风线沿主体方向拖出，长短与消失时机错开 |
| 接触与尾效 | 实际受击处出现短促风刃与碎光，随后顺运动方向散开 |

## 起势、穿行与消散

起势短而紧，主体随即明显加速；抵达目标区域时形成清楚的穿刺接触，余风继续向前滑出少许距离后收尽。避免全程匀速滑行，保持魈快速、锋利的攻击气质。

风痕的展开适应这一次选定的相邻受击位置，接触落在实际被命中的卡牌范围。三人共用这一轮主体动势，各自接触清楚；缺少目标时随实际范围收窄。装饰风丝可以交叠，实际每名目标仍只有本次战技的一次命中。

主体在接触附近短暂越过卡绘，随后迅速变薄，保留卡面、血条与命中数字的可读性。整体色彩与[靖妖傩舞](../BaneOfAllEvilState/视觉需求.md)协调，风轮两立本身始终保留清晰、集中的高速风光。

## 连续施放与共用

连续使用战技时，每次各有独立起势、穿行和收尾，上一道尾迹可短暂留存，亮度与规模保持稳定。天赋叠加的战技增伤、一命增加使用次数、三命等级变化均沿用同一套表现。

六命由强化重击实际命中至少两名敌人后恢复战技使用机会，并使下一次战技免AP；该次战技仍由实际施放触发，继续使用本套效果。次数、免AP、冷却与回能沿公共显示。
