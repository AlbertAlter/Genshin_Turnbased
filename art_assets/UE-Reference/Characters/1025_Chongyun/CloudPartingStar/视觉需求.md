# 重云 · 灵刃云开星落

## 整体效果

以原作元素爆发为视觉参考：施放短促结印般的冰蓝凝光，在前方半空连续召出三柄巨大灵刃，随后短时间内依次落下并爆裂。保留原作灵刃的修长轮廓、剑格、符纹、冰白内芯与冰蓝半透明棱面，不改成纯光柱或普通冰锥。

卡牌适配时，整组灵刃组织在本次实际相邻目标区域前上方。每柄剑分别完成显形、下落、接触和碎裂，同一柄剑的范围接触覆盖该轮真实目标；不按每名敌人额外复制三柄剑。主体和冰爆保留前后景深，卡绘与生命数字保持可读。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 凝形符光 | 短促冰蓝符纹与聚起的亮点，为巨剑出现提供起势 |
| 巨型灵刃 | 可复用的独立剑体，冰白剑脊、浅蓝棱面和清楚剑格，具有厚度 |
| 剑身寒光与拖尾 | 刃缘薄光，下落时留下方向一致、末端柔和收尽的寒光 |
| 地面冰爆 | 每柄接触时一次短促亮芯、外散冰片与低矮霜气 |
| 消散碎冰 | 少量有体积冰片与细霜晶，分先后收尾，避免长时间遮卡 |

## 连续召出与落剑

原作实机中的灵刃以相近但有先后的节奏凝形。巨剑短暂可辨，随即沿原作落剑动势加速下冲；几柄剑的出现、下冲与尾效可以交叠，但每次接触都能分辨。

具体剑体朝向、分布与相继落下的节奏结合原作动图制作，保留原作整体识别度。角色身体动作与镜头不纳入此特效，不为演出增加人物模型或切镜头。

每一柄剑抵达时形成自己的冰爆，剑身随接触碎裂或化开。接触之间可以保留前一次较弱的余雾，不让后一次闪光与旧尾效叠成不透明白幕。最后一柄结束后，所有冰片、符光和霜气自然收尽。

## 数量与范围

基础表现为三柄连续灵刃，对应三次实际接触；六命直接由同一套效果适配为四柄、四次实际接触。第四柄沿用同样的凝形、下落、接触与尾效，不另做一套固定四柄的完整效果。

主体按可复用单柄组织，灵刃数量、落点和接触间隔跟随本次实际演出；不把三柄固化成一张整体贴片。三柄与四柄都保持连贯、紧凑的原作动势，末柄结束后统一收尽剩余薄霜。六命的条件增伤不额外增加灵刃、接触次数或另一种爆炸。

卡牌受击、击飞或震动由对应实际命中演出配合，模型里不捆绑固定卡牌动作。冰片数量和装饰亮点不增加攻击次数。

## 本次实机参考观察

已实际查看云开星落62帧／2.48秒中的24张标时截帧，可辨三柄修长蓝白灵刃、较暗棱面及相继接触。开片已有的领域和后段青绿风效未并入本爆发；当前剑体、符纹自行建模，三柄／四柄均复用单柄部件，逐柄加速下落并各自一次群体接触，局部冰屑不表示额外hit。
