# 雷泽 · 雷牙期间附加狼爪攻击

## 整体观感

大招期间出现附加攻击时，卡后狼魂随当前攻击动作向前挥动雷电利爪，带出几道方向统一、略有间距的紫白爪痕，在本次实际目标处形成清楚的撕裂式接触电光，再快速收势。重点是**狼臂挥击、爪痕经过、目标接触**的连续关系。

沿用雷牙狼魂的冷紫与淡紫白，爪尖、爪痕前缘及接触处最亮，后随轨迹逐渐变细、变暗。爪击有爆发力与利落的切割感，狼魂躯干仍守在持有者卡后。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 狼臂挥击 | 从持续状态当前姿态衔接的前臂与利爪动作，肩、臂、掌部有自然先后，爪尖带动轨迹 |
| 紫白主爪痕 | 数道略弯曲、尖锐收尾的细长爪痕，间距与朝向协调，亮前缘和渐隐尾迹清楚 |
| 随行细电丝 | 附着在爪尖与主轨迹附近的少量短电弧，顺挥击方向散开 |
| 目标接触电光 | 实际命中位置短促绽开的紫白亮核与划过的爪痕，局部清楚、面积克制 |
| 收势余电 | 主轨迹之后逐渐收窄、断开的细电丝，随爪臂回收自然消失 |

## 挥击与目标接触

每次附加攻击开始时，狼魂从当前守护或前一次收势姿态进入新的挥爪。肩臂短促带动，利爪加速掠出，接触时最有力量，之后减速收回。连续触发时动作之间自然接续，狼魂形体的位置和朝向保持连贯。

挥爪方向配合本次角色攻击的运动，狼臂、爪尖和轨迹方向一致。爪痕从爪尖已经经过的路径拉出，头部较锐、尾部柔和收窄，各条有少量长短和弯曲差异，组合成一次完整爪击。

在目标卡牌附近，以短距离清楚的爪痕掠过表现雷狼的附加接触；源端狼臂的发力与目标端爪痕在节奏上紧密呼应。跨越战场的距离通过短促的雷光拖迹带出，主要亮度集中在挥击与实际命中位置，保留双方卡面可读性。

同一段附加攻击如有多个实际目标，由一次狼臂挥击带出同一组连续主爪痕，覆盖该段真实目标的合并区域；各目标只补局部接触电光。主爪痕的几条细线共同表达这次完整爪击，线条数量不作为额外攻击次数。后续真实附加攻击再衔接下一轮挥爪。

## 与持续狼魂的衔接

[雷牙狼魂持续状态](../LightningFangState/视觉需求.md) 在整次挥爪期间维持存在，头肩与躯干继续守护在原卡后，只有参与挥击的部位进入攻击与收势。一次爪击结束后回到当前循环，下一次触发直接衔接，不重新播放大招显形。

角色原本的攻击动作与紫色附加爪击在形态和亮度上可区分。狼爪短暂加强接触，不长时间盖住卡面、数值或其他效果。待机时没有挥击爪痕，雷狼的少量游走电弧继续保持状态感。

## 收势与消散

接触亮核短促缩小，主爪痕沿挥击方向继续极短距离，随后收窄淡去；少量分叉电丝稍晚断开，狼臂自然回收。最后余电全部消失，这次附加攻击结束，持续狼魂仍保持正常亮度。

爪痕长度、宽度、弧度、各线间距、接触亮度、残留时长与挥臂幅度可分别调整。连续攻击时前一击尾迹快速退出，后一击主体仍清楚，不让亮度不断叠高。
