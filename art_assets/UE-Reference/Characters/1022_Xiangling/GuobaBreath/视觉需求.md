# 香菱 · 锅巴喷火触发

## 整体观感

锅巴从持续坐姿进入短促准备，嘴部张开、身体微向前探，从**锅巴实际口部**喷出一股有体积的橙黄火焰。前缘迅速涌向本次目标，沿途有卷曲火舌，接触时局部舒展，再随着吐气结束收窄消散。喷火有一口气推出去的力量与节奏。

火焰内芯偏亮黄，主体橙黄，外层带少量橙红与暗红转折，保留卷动、厚薄与透明边缘。口部、小段喷流、目标接触与散开的余焰有清楚先后。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 锅巴准备与吐气 | 小爪、头口、身体的短促准备，随后前倾吐火，最后回坐 |
| 口前火焰 | 从嘴部聚起并喷出的短而有力的火焰根部，随头部朝向一致变化 |
| 主喷流与前缘火团 | 锥形、略卷曲的橙黄喷流，前缘快速推进，火舌有独立明暗和生灭 |
| 目标接触火焰 | 本次实际目标处短促舒展的火舌与少量亮火星，方向继承喷流 |
| 余焰与少量淡烟 | 停止吐火后逐渐变细、断开的尾焰，少量烟气稍晚散尽 |

## 准备、转向与喷出

锅巴从当前 [持续状态](../GuobaState/视觉需求.md) 姿态自然衔接准备，头部先朝向本次真实目标组，小爪与身体稍作蓄势，随后前倾、张口并快速吐出火焰。

火焰根部始终跟随锅巴口部，前缘带卷曲的火舌快速抵达目标，后方喷流接续，最后根部停止补入，现有火焰继续向前并散尽。喷出有明显加速与吐气后的衰减，口部尺度保持适合小锅巴的比例。

本次只有一个目标时，喷流朝向该实际卡位；有多个实际目标时，用同一口喷火的扇面或分开的前缘火舌覆盖相应位置，锅巴只完成这一轮准备与吐气。目标范围与单条火舌、火星大小分别调整，较远或错排的卡位仍有明确来源和接触关系。

## 接触与恢复

对应本次hit的实际目标在正式接触时刻出现火舌舒展、局部亮芯和少量火星。火焰沿原喷出方向继续很短距离，随后变薄、断开，尾焰稍晚消失。

锅巴在喷流收完时自然闭口、收回前倾，恢复持续坐姿，主体始终存在。后一次喷火从当前姿态进入，前一次残焰迅速退出，主喷流仍可辨认。

## 本次实机参考观察

已实际查看同一锅巴动图跨全片24张标时截帧及2.8／3.3秒原始截帧，可见口部向前推出橙黄火团、接触后余焰；草燃烧、史莱姆与伤害数字排除。当前实际口部挂点驱动喷流，向单卡或不连续三卡一轮同时接触，结束吐气后先停根部补入，已有卷焰继续向前收尽，本体仍留在原处。已看过加厚卷焰与错落火舌后的原生整体图和组合动作表，口部来源清楚，本体在两次喷火间继续存在。
