# 香菱 · 风火轮触发与内部长枪自转

## 整体观感

风火轮在本次触发时形成一组火焰包裹的旋转长枪，**整体在平行于屏幕的平面内旋扫，同时风火轮本体绕自身中心自转**。画面要能清楚分辨目标范围内的整体旋转与轮体自己的转动，两层运动同时存在。

轮体内部实际是一把长枪：枪杆、握持段、枪头和尾端有完整结构，火焰沿枪体与旋转方向形成卷曲火舌和短尾迹。主色橙红、金黄，枪体以较深的暖色和明亮刃口与周围火焰区分；正常战斗画幅也能看出一把枪在转。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 内部长枪 | 单独可辨的完整枪体，直枪杆、尖锐枪头与尾端结构，转动时轮廓清楚 |
| 本体自转 | 长枪围绕自身轮心旋转，枪头与枪尾先后经过，火舌随后带出轮廓 |
| 整体旋扫轨道 | 风火轮整体在平行屏幕的平面内围绕本次目标范围旋转，中心位置与内部自转各有独立运动 |
| 火轮主体 | 沿旋转长枪形成的橙黄卷焰，亮芯与橙红外层分明，保留观察枪体的清楚间隙 |
| 短火焰拖尾 | 轮体已经经过的路径上留下的薄火带，顺行进方向拉出、收窄并淡去 |
| 接触与火星 | 本次实际命中处短促推出的火舌、亮点与少量火星，强化旋转掠过的打击 |

## 出现与两层旋转

触发时，枪体先从局部暖光中清楚显现，随快速起转卷起火轮主体，接着进入覆盖本次实际目标组的旋扫。

**整体运动的旋转平面与屏幕平行，轴朝向观察者。** 从正面可以读出轮心在目标范围内经过的弧线。与此同时，长枪围绕风火轮自身轮心持续自转，枪头、枪杆与尾端朝向随自身相位改变，不能只让整块火轮图形沿圆路平移。

两层运动有不同速度与相位：整体快速掠过目标范围，本体转动更利落；自转略有平滑速度起伏，火舌和火星各自错开，外缘短尾迹稍落后于实体。运动从起转、加速旋扫到收势衰减连续，保留清楚方向和惯性。

## 长枪可见性与打击

火轮正面以分开的卷焰和局部尾火组织轮廓，内部枪杆与枪头始终有机会清楚露出。最高亮度集中在枪刃及接触处短暂出现，枪体主形不被一整块过曝光团盖住。

整体范围按本次实际敌方卡位组织，火焰扫面与轮体轨道一起覆盖实际目标。每个真实hit的全部目标按同一接触cue呼应，局部火舌和火星由同一轮旋扫带出；装饰自转的圈数不增加攻击次数。

同一段群体hit共用一把内部长枪、一个风火轮主体与一片连续旋扫火痕，按真实目标合并范围统一展开。每名目标只增加局部接触，轮体数量保持一致；下一次真实状态触发再形成下一轮完整旋扫。

火轮轨道半径与范围、轮体尺寸、长枪长度、整体旋扫速度、本体自转速度、火焰厚度和亮度分别调整。目标范围扩大时主要调整分布与覆盖，仍保留单把长枪和火轮的辨识度。

## 收势与底部图标

本次触发结束后，轮体保留当前自转相位继续短暂衰减，火舌沿旋转方向收细并分散，枪体随暖光淡出，最后少量火星与尾迹散尽。下一次触发是一次新的旋扫，待机时由持有者卡底图标表示状态仍在。

本次已制作的 [风火轮底部图标](../../../../UI/CardBottomStatus/Pyronado.png) 以橙金火轮和清楚长枪为主体，透明外部、彩色实心内部，使用现有卡底图标画风；右下数字由界面读取实际剩余次数，数字不画进图片。该静态图标和本项3D触发效果分别承担状态提示与单次行动展示。
