# 香菱 · 自身锅巴持续状态

## 整体构图

锅巴作为**实际状态持有者自身的持续展示**，一只小锅巴坐在持有者卡牌旁靠下的位置，跟随这张卡牌的空间关系。原作的圆耳、黄褐色身体、深色面纹、浅色口鼻与肚皮、圆爪和脚掌清楚可辨，保持憨厚、温暖的原作形象。

锅巴有可辨体积与柔和明暗，主体尺度小于卡牌，留出卡绘面部、卡底图标与数字的位置。模型在卡牌两侧或下缘的空隙中可见，前后遮挡合理，作为这张卡旁的一只实体存在。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 锅巴主体 | 圆耳、头身、面纹、浅色口鼻与肚皮，暖黄褐主色，柔和阴影与少量高光 |
| 四肢与坐姿 | 圆爪、脚掌和坐稳的姿态，身体轻微起伏时有重量 |
| 头口与准备动作 | 头部、嘴部与双爪能衔接吃辣椒、吸气、前倾喷火和恢复坐姿 |
| 出现的淡烟与暖光 | 少量轻薄烟气与暖色光，配合落稳，迅速散去 |
| 退出余烟 | 锅巴消失时的少量柔和烟气与暖色细光，保留自然收尾 |

## 起手出现

锅巴在持有者卡旁从少量暖光与淡烟中显现，轻轻落稳，身体有一次短促压缩和回弹，再进入坐姿。头部和小爪稍晚稳定，形体从出现到坐稳连贯，卡牌主体保持清楚。

出现只建立这一只锅巴与当前持有者的关系，不额外重演一轮喷火。

## 持续循环

锅巴维持坐姿，身体有缓慢呼吸式起伏，头部、小爪与耳朵有轻微错开的变化。整体安稳、可爱，循环首尾自然，主体一直清楚可见。

需要触发 [锅巴喷火](../GuobaBreath/视觉需求.md) 时，从当前坐姿自然进入准备与吐火，喷火结束后回到当前持续姿态。过程中锅巴本体一直存在，普通触发与状态续时保持位置和动作衔接。

锅巴只在本次真实触发时转向相应目标，待机时保持克制动作。主体大小、卡旁偏移、前后距离、呼吸幅度与明暗可分别调整，给卡底四格图标保留清楚空间。

## 消失收尾

状态结束时，从当前姿态收住动作，锅巴身体轻轻收拢，伴随少量淡烟与暖色细光自然隐去。烟气稍晚散尽，最后卡旁恢复清楚。起手、持续和消失三段完整，持续段可以自然延长。
