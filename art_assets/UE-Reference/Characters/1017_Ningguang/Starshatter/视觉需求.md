# 凝光 · 天权崩玉多宝石飞行

## 整体观感

遵循原作多个金色宝石飞射的识别点：凝光卡牌周围先浮起一组有实体切面的金琥珀晶体，略向外展开后，各自转向实际敌方目标并快速飞去。能够看清多枚宝石、分开的出发位置与不同飞行路线，不能合成一颗大火球、一条粗激光或没有飞行过程的全体爆闪。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 爆发宝石群 | 多枚独立金色／琥珀色切面晶体，棱面和浅金亮核清楚，起势时围绕凝光展开 |
| 凝聚与起势岩光 | 稍强于普攻、但短促通透的金色光点与细碎晶体，带出一次明确的爆发起势 |
| 各枚飞行尾迹 | 宝石各有细而柔的浅金光轨，经过的弯曲路线可辨，出发时稍错开而不拖成散乱长队 |
| 追加宝石 | 若本次有璇玑屏等来源的额外宝石，从对应实际来源位置进入飞行，与凝光周围的第一组区分 |
| 命中与碎晶收尾 | 各枚接触目标时短促碎亮，散出岩晶与细金屑，尾迹收完，不使用火焰爆炸 |

## 展开、转向与命中

宝石先从凝光卡牌周围略向外张开，随后平滑转向目标并加速，带出原作多方向发射后汇向敌人的感觉。每枚晶体朝向随路线变化，尾迹来自其实际已经经过的路径；不让所有宝石完全重叠在同一条直线上，也不在转向处突变或瞬移。

各枚跟随本次实际目标与实际宝石数量飞行，保留连续发射和多次接触的节奏。若存在追加宝石，它们的出现位置与相应来源对应；已经发出的宝石继续飞行，不因下一批出现而全部重播起势。身后原有星璇圈是否变化，也以这次实际可见数量为准，不把爆发临时宝石群当成同一圈常驻星璇。

每次接触在目标位置出现相称的亮核、切面碎晶和金色细屑，完整宝石随命中碎开消失。最后一批命中与尾迹全部收完后结束，避免宝石群永久留在半空或留下常驻亮幕。
