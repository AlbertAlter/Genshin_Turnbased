# 凝光 · 重击主宝石与额外星璇

## 整体观感

重击由一枚更大、更明亮、切面更明确的主宝石领衔，附带本次实际释放的额外星璇宝石一起飞向目标。主宝石与追加小宝石在大小、亮度和出发位置上能区分，保持原作集中、锐利的金色晶体攻击感，不把重击做成单独一团爆炸。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 重击主宝石 | 比普攻更有体积和分量的金琥珀晶体，聚起时棱面增亮，发射后仍有完整轮廓 |
| 追加星璇宝石 | 从卡牌后方宝石圈的当前可见位置离轨，体积小于主宝石，数量与本次实际释放一致 |
| 聚起与发射亮部 | 主宝石短促聚亮，追加宝石依次转向目标，形成一次有先后的集中发射 |
| 各枚尾光 | 每枚保留自己的细金尾迹，方向随各自路线变化，合流时仍能读出多枚宝石 |
| 命中碎晶与余光 | 主宝石的接触更有分量，追加小宝石各自留下适量晶屑与亮点，完整实体在接触时消失 |

## 主宝石与额外宝石的衔接

主宝石先短促聚起，再加速飞向这次重击的实际目标。它的飞行应明显可见，不直接在敌人卡面上刷一个命中光效了事。

有星璇时，追加宝石从**星璇圈当前环绕位置**转向、离轨并加入本次攻击，路线自然接上各自出发位置。不能先让身后的宝石全部凭空消失，再从固定点重新生成一组追加宝石。没有星璇时，主宝石仍完整完成重击，不额外生成装饰宝石冒充追加攻击。

各枚可有小幅错开和轻微弧线，但保持这一次集中重击的节奏。已经飞出的宝石与随后新补入宝石圈的星璇分清，不把新补入的宝石误消掉。命中处使用岩晶碎裂、短亮核与细碎岩光收尾，余光散尽后不留完整宝石。
