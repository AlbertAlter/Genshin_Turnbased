# 凝光 · 璇玑屏

## 正面构图与实际覆盖范围

璇玑屏是一整面具有**左右两根柱子**、金色装饰横梁和透明玉质屏面的屏障。按本次实际覆盖场地的左右边界横向展开，左柱和右柱分别位于整体覆盖范围两端，中央由一整面屏联系；不能按每张卡牌复制一面小屏，也不能永远使用固定的整排宽度。

屏面**平行于屏幕、正面朝向玩家**，能看清两柱、装饰框架和屏面纹样。范围组织从画面左端到右端，兼顾实际场地的上下错排；不要将屏侧转成细边，或放成卡牌脚下的一张水平光圈。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 左柱与右柱 | 两根独立可辨的金玉柱体，带原作阶梯、回纹与垂坠装饰，位于实际范围两端，保持各自比例 |
| 上横梁与边饰 | 联系两柱的金色框架与卷曲纹样，横向可读，范围变宽时柱体不被拉扁拉长 |
| 中央透明屏面 | 轻薄玉色／浅暖白屏面，局部有柔和纹理，透出后方内容，保留中央大面积通透 |
| 云纹与中心纹样 | 借原作云纹、环形中心装饰表达屏的身份，边缘稍明确，中央线条克制 |
| 起手岩光与退出玉屑 | 建立屏时短促的金色勾边与岩光；结束时碎成少量玉屑、金色亮点和消退纹样 |

## 不影响卡面观感的摆法

整面屏放在覆盖区域的**卡牌后方、战斗背景前方**，不以一层半透明亮幕压在全部卡绘上。两柱尽量落在覆盖组的外侧边缘或已有留白，横梁与醒目的边饰避开脸部、名字和关键卡框；中央屏面与纹样保持通透、低对比，卡牌自然挡住其经过中央的部分。

正常视角先看见完整的卡牌，再从左右柱、外露横梁和边缘云纹读出一面连贯屏障。中央少用大面积乳白填充和高亮扫光，不为了展示纹样而降低卡牌透明度、移动卡位或缩小卡面。屏的覆盖可以很宽，柱体厚度和装饰细节仍保持合适尺度。

## 起手、持续与消失

起手从实际覆盖范围左端建立左柱，金色框架与轻薄屏面向右展开，右端到位后右柱成形，形成一整面正对玩家的屏。展开过程短促、有层次，不是把完整屏从左向右整块推过卡牌。

持续时柱体和框架稳定，中央纹样只有轻微、缓慢的明暗流动，零星岩光错落闪过，不反复重建，也不在卡后持续强闪。实际覆盖范围变化时，两柱、横梁和屏面随这次范围协调改变，保留整面屏的连续感与两柱比例。

正常退出时，屏面纹样先逐渐淡去，框架与两柱随后解体成少量金玉碎光，最后余屑散尽。若实际演出需要屏化为爆发追加宝石，宝石从这面屏当前所在的位置离屏飞出，屏体的变化与追加宝石的来源能对应，不把原本的屏瞬间搬到凝光身边。
