# 阿贝多 · 阳华与全场外圈

## 整体构图

按用户要求，阳华的持续花盘放在敌我双方卡组正中间，采用原作从上方俯视所见的花盘形态。花盘正面朝向玩家，清楚看见原作花瓣、中心与岩纹的整体关系，避免过度倾斜后只剩一条窄边。

阳华外圈覆盖敌我全体卡牌，以当前双方全部实际卡位的范围组织一片完整领域。中央花盘保持合适大小，外圈独立延展，不为包住全场而把花盘本体也等比放到巨大。外圈与主要地面纹理在卡牌后层，兼容最多五敌四友及上下错排，卡绘和界面数字保持可读。

中央只是视觉展示位置。真实阳华仍按原场地状态维持，显示不改变它的宿主、共鸣位置或攻击规则。外圈覆盖我方表示用户指定的全场构图，不额外给我方施加伤害或改变受益条件。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 中央阳华花盘 | 原作俯视轮廓、花瓣与中心结构，岩金、赭金与明亮浅金层次清楚 |
| 全场领域外圈 | 一条可辨的原作风格岩光边界，覆盖双方全体，粗细和亮度克制 |
| 地面岩纹与细光 | 对照原作纹理与图形，结构稳定，局部缓慢游动 |
| 细碎岩光 | 少量错落生灭的浅金光屑，辅以轻微明暗起伏 |
| 建立与退出余光 | 花盘凝形、外圈铺展及消散时的短光痕和细碎余光 |

## 起手出现

双方中央先凝起短促岩光，原作阳华花盘逐渐建立，外圈与地面纹理随后铺向包含敌我全体的范围。花盘与外圈有先后和交叠，形态稳定后接入循环，不将完整静止图案直接打开。

战技施放时原有的一次敌方全体岩伤使用原作阳华建立时的岩晶接触与地面冲击衔接，只有一轮主接触，不把外圈经过的每张卡牌都当作新一段攻击。

## 持续循环与触发

花盘轮廓保持稳定，局部岩光轻微流动，外圈缓慢呼吸，光屑独立错落生灭。连续循环不逐轮重铺、不增亮或扩大；全场外圈始终低于一次绽放的高潮。

实际协同攻击在[目标位置的小规模绽放](../TransientBlossom/视觉需求.md)中独立完成。中央花盘与全场外圈继续维持，不在每次攻击时重新召唤整片领域。

个别敌人死亡或原场地暂空不让仍有效的阳华显示提前消失。重新建立或替换阳华时，沿实际状态交接保持画面连贯，不把两轮完整外圈叠成高亮白幕。

## 消失收尾

阳华实际结束时停止补入光屑，外圈与地面岩纹逐渐拉薄，中央花盘最后化为少量岩光收尽。能够从循环任意相位退出；已经触发的小绽放独立收完尾效，不因花盘消失而被全部截断。
