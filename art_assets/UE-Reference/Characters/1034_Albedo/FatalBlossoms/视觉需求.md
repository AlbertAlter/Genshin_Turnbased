# 阿贝多 · 爆发生灭之花七次绽放

## 整体效果

每次生灭之花都参考原作爆发中的绽放特效，保留花形岩晶展开、明亮岩金接触、向外散开的岩光和短促尾效。与普通协同小绽放保持同一岩元素色系，主体造型和力度对照原作爆发生灭之花，避免直接放大普通小花代替原作特征。

本项目在阳华实际存在时额外绽放七次。每次围绕该轮实际选中的三个相邻位置组织一朵范围绽放，边缘或人数不足时沿真实可受击范围表现。七次各有自己的中心与接触，不固定摆成七个与实际目标无关的装饰点。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 生灭花芯 | 实际绽放中心短促亮起的岩金光，亮度集中 |
| 花形岩晶主体 | 对照原作的花瓣／岩晶结构、棱面与展开顺序，形态可辨 |
| 范围岩光 | 随花展开覆盖本轮相邻目标区域，前后与明暗有层次 |
| 外散碎屑 | 少量岩晶碎片与细光，不同速度和寿命错开 |
| 收尾余光 | 主体收尽后较淡的光痕和细屑，保持下一次接触清楚 |

## 七次实际接触

七次绽放的发起、目标中心与接触服从各次真实攻击。一次三目标范围共用一套绽放主体，不在三人身上各复制一遍完整花，也不把七次合成一个大爆炸。每次的局部花瓣与岩光数量不产生新hit。

原作展开、短促爆开与消散的节奏用于单次绽放，七次之间的安排配合本项目实际行动。近时间重叠的尾效保持较低亮度，新一朵主体清楚可辨，不能累积成金白色光墙。

一至五人、上下错排和连续多次命中同一组时，都准确围绕本轮真实卡位构图。扩大范围主要调整花瓣与岩光分布，单片岩晶、细碎岩光和亮芯尺寸独立控制。

## 中央阳华与独立协同攻击

七次绽放期间中央阳华与覆盖敌我全体的外圈继续自己的循环，不把中央花盘搬到每个爆心，也不每次重播领域建立。

若本项目业务另产生阳华或瑰银的独立协同攻击，按其真实结果使用[小规模绽放](../TransientBlossom/视觉需求.md)另外表现，不把它吞入七次生灭之花，也不由装饰花互相触发更多攻击。

## 本次实机参考观察

已实际查看爆发动图的24张标时截帧，后段可见独立金色花芯、花形棱晶和各处依次展开的余光。工程采用与持续阳华不同的四向透亮晶冠和亮花芯；实际查看首版样片后收窄了晶体、降低实心感并加快收尾。七次真实相邻范围各一次，局部尾效可交叠，不让装饰花瓣产生额外hit。每次目标仍为明确的美术示例，未执行随机选敌。
