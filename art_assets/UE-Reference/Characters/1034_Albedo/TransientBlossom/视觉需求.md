# 阿贝多 · 阳华与瑰银协同绽放

## 整体效果

阳华触发攻击时，在该次实际目标的位置绽放一次小规模岩元素花。花瓣／岩晶从目标地面短促展开，浅金亮芯、岩金至赭金主体、细碎岩光和收尾层次参考原作刹那之花。

每次绽放轮廓清楚、规模克制，起势短，展开迅速，有明确接触，随后花瓣状岩光和细屑散尽。视觉集中在当前目标卡位，不把中央持续花盘移动到敌人处，也不复制一个覆盖全场的大领域。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 目标凝岩亮点 | 真实目标位置短促聚起的岩光，面积克制 |
| 小规模绽放主体 | 参考原作刹那之花的花形岩晶与展开轮廓，亮暗分层 |
| 接触岩光 | 与该次真实hit对应的短光痕和清楚亮芯 |
| 岩屑与余光 | 不同大小和速度的细岩光，主体先收、细屑稍后散尽 |

## 独立接触与中央领域

只在业务已经确定的真实目标位置绽放。位置与接触沿该次攻击，不自行重选随机目标、不向相邻卡位补不存在的攻击，也不从中央花盘额外发射一个未要求的弹体。

同一目标连续出现多次实际触发时，各次接触仍清楚可辨，尾效可以短暂交叠，亮度不积累成遮住卡绘的光块。中央阳华与全场外圈保持原循环。

## 瑰银追加次数与卡底显示

瑰银使用[阳华图案的卡底图标](../../../../UI/CardBottomStatus/SolarIsotoma.png)显示真实份数，不另加第二套常驻花盘或两只环绕模型。每份瑰银有独立触发与计时，协同攻击共用本套小绽放；该份实际产生一次攻击，就在该次真实目标位置增加一次完整绽放。

显示次数跟随实际发生的阳华及各份瑰银攻击，不按卡底数字直接复制固定数量。某份因触发限次、消耗或失效没有行动时，不补出装饰攻击；瑰银与瑰银不靠动画互相触发。四命消耗及六命清除沿真实实例更新卡底数字。

## 四命强化普攻与其他增益

四命强化普攻使用[半规模绽放](../C4NormalBloom/视觉需求.md)作为原普攻的一部分，与这里独立造成伤害的协同攻击分开。二命生灭计数以及其余防御、精通、增伤与回能均沿公共显示，不因数值变化自动增添花的次数。
