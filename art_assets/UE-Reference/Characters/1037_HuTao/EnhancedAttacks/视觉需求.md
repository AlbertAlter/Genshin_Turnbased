# 胡桃 · 强化普攻与重击的新刀光

## 整体效果

为胡桃重新设计符合原作火蝶气质的火焰刀光：明亮橙金刃沿、半透明朱红火体和少量蝶形余火共同组成锋利、流动的枪势。普攻与重击分别有清楚轮廓、起势和收势，保留胡桃自己的识别点。

普攻使用较短、利落的火弧；重击先收紧火光，再快速拉出更有冲势的主刃和扇形尾焰。卡牌沿用现有动作与站位，由新刀光承担攻击方向和冲刺般的速度感。

| 部件 | 视觉要求 |

| 重击主刀光 | 起势收束、前锋更集中、尾焰更饱满，曲线与普攻清楚区分 |

| 局部接触 | 实际受击位置的短促火星与薄火片，方向与主刃一致 |
| 收势短迹 | 沿主刃已走过的路径拉薄，最后少量余火收尽 |

## 按实际命中范围组织一次刀光

同一段实际命中的全部目标共用一次完整刀光。单体时火刃紧凑；真实目标为多人时，统一改变该道刀光的弧长、扫面、朝向和覆盖，使主刃在接触姿态贯通实际目标的合并区域，兼容上下错排和不连续卡位。卡牌之间可以有连续尾焰，各目标只补自己的局部接触亮点。

主刀光始终读作同一次挥击，不能在每张目标卡上分别播放一套小刀光。扩大范围主要改变覆盖，蝶形大小、火星尺寸和刃口厚度保持合理。当前项目普攻与重击均为单体一段；多人适配遵循届时真实目标集合，不为展示自行增加命中目标。

## 发力与蝴蝶尾迹

普攻短促起势后迅速掠出，接触附近火刃最完整，余势随即收细。重击蓄势更紧、出手加速更明显，主刃接触后留少量向前推出的尾焰，再收回亮度，节奏有快慢与力量转折。

刃尾脱离的每只蝴蝶沿不同弧度离开：靠前的先顺攻击方向滑出再上扬，靠后的做一次短回勾后漂离，少量从卡后绕向侧方。各蝶振翅、减速点和寿命错开，轨迹与尾光连续。它们补充余势，实际命中仍由本次主刃接触承担。

## 状态与血梅香

[彼岸蝶舞](../ParamitaPapilioState/视觉需求.md)在攻击期间继续环绕。真实重击命中施加血梅香时，再衔接目标的[卡面标记](../BloodBlossomCardState/视觉需求.md)；标记出现与主刀光接触有清楚先后。火附魔结束后的后续攻击回到常态表现。

## 当前原生实现与静帧

普攻为较短的上弓火弧，重击在6至14帧收紧火光，14至20帧加速推出较直的枪焰；两者保留第20帧接触。主刃分别采用朱红外火、橙色内火和细金白刃线三层，沿同一条路径显露，接触后沿原路径收细、退去，不整体横向缩回。四只余火蝶从该段刀光的不同尾迹位置离开，保留各自曲线、振翅和短迹。

控制器的PreviewTarget1至PreviewTarget5只用于源美术勾选。默认仍是三号卡位单体；31种非空集合共用一套三层主刃，通过30个原生相对形态适配，空选时整套表现清空。合并范围采用单弓弧与组方向，避免在上下排间折成波浪；局部接触亮点跟随弧线与各选中卡牌的交点。刃口、火片及余火蝶的尺寸不因人数扩大。真实目标列表、卡位、伤害和附加血梅香仍由外部业务提供，不能用勾选框决定命中。

`target_sweep_art.py`维护范围、UV和原生形态，`hutao_enhanced_sweep_art.py`维护胡桃的节奏、局部接触与尾蝶。原生部件保留VFXColor RGBA和UV：U为路径进度，V为横截面，头尾显隐与厚度使用源材质遮罩；FBX不携带Blender节点图，正式接入需实现对应材质。16份当前部件FBX已原生回读，主刃各有三份网格和30个非默认目标形态；两份工程各32种勾选组合、原生驱动、尺寸恒定、接触20帧、首末清空与空选对照已检查。参考布局、镜头及原先控制参数保留；本次不发布Unity、不新增视频，下表已有视频为旧版。
