# 胡桃 · 安神秘法平面横扫

## 整体效果

保留原作炽热魂灵的可辨轮廓、面部与暖色火光，按用户指定改为以胡桃为原点、平行于屏幕的一次横扫。魂灵主体与橙金火带沿同一挥扫弧线掠出，形成一次覆盖实际敌方全体的完整扫面。

胡桃实际卡牌位置是唯一旋转支点。主魂灵只有一份，扫面连续，局部火花分别呼应各个真实目标；施放者、魂灵与整道火带的空间关系始终读得清。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 魂灵主体 | 参考原作浅色魂体、面部和柔软轮廓，亮部克制，外缘有暖色火光 |
| 聚起与带动火光 | 在胡桃附近建立魂灵与挥扫方向，短促收束后加速 |
| 连续横扫火带 | 与魂灵相接的一道弧形火光，前沿清楚，后沿与端部渐薄 |
| 接触火花 | 同一主扫面带出的局部暖色火片、火星，位置对应实际目标 |
| 蝴蝶与余焰 | 少量沿扫面尾部飞离的火蝶，轨迹有弧度与速度变化，主体后依次收完 |

## 以胡桃为原点的一次横扫

旋转平面与屏幕平行，旋转轴朝向观察者。先在胡桃附近短暂聚起魂灵和火光，接着魂灵被带向侧方，沿画面内的弧线快速横扫敌方区域，再借余势收住。起势较紧，扫出加速，接触附近力量最强，尾部明显减速与拉薄。

按胡桃实际位置和本轮全部敌方目标的合并边界调整扫面的内外半径、弧长与覆盖宽度。上下错排、两端与不连续卡位都处于同一连续扫面内；目标减少时收窄覆盖，魂体本身维持合理尺寸。

主魂灵、火带与刀光共同读作一次完整横扫。群体主伤害当前只有一段，接触高潮覆盖全部实际目标，受击与数字沿同一真实时点衔接。扫面的行进感由起势与余势承担，保持既定的全体统一接触。

## 收尾、回血与二命

主魂灵沿横扫方向继续很短余势，火带随之拉细并散开，蝴蝶各沿短弧飞离。火光最后收尽，不遗留额外持续魂灵。

低血量增伤沿用同一套魂灵和横扫结构。命中后胡桃实际回血沿公共治疗粒子与数值显示，按本次实际治疗合并呈现。二命施加的[血梅香](../BloodBlossomCardState/视觉需求.md)随后在各个实际目标处建立，主横扫保持同一次。
