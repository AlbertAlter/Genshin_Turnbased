# 胡桃 · 血梅香卡面标记

## 整体效果

在实际附有血梅香的敌人卡面范围显示原作式花形印记，以红橙花形、亮部花瓣和轻微火光保持辨识度。准确花瓣轮廓与纹样制作时核对原作敌人身上的血梅香，保留专属标记识别点。

首版原生标记造型已制作；原作准确花形仍待专门核对，当前为自行设计的五瓣暖红梅形，不声称已取得原作标记贴图。公共显示组件和正式配表尚未接线，原有状态栏继续显示自己的信息。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 血梅香花形 | 原作式花瓣与中心结构，缩小后仍能读清，暖红与橙金亮部有层次 |
| 施加勾光 | 沿花形逐渐显出的短火光，衔接实际重击或二命爆发接触 |
| 维持微光 | 花瓣边缘轻微明暗变化，少量细火点，亮度与密度稳定 |
| 退出余火 | 花形沿瓣缘变薄、断开，最后少量火点消散 |

## 出现、维持与消失

真实血梅香建立后，先有一个短促暖光接触，再显出花瓣和中心；形成过程简短，卡面仍能看清。位置与尺寸保持可调整，主要落在卡面中下部或原作参考适合的区域。

持续时花形稳定存在，只有克制的边缘流光和少量火点错开闪动。刷新持续时间保持当前展示，不反复播放完整施加，也不按回合数让标记机械闪烁。

真实状态结束后，花瓣从亮部向边缘逐渐松散，余火稍后收尽。每个目标的印记跟随自己的真实状态维持和退出。

## 与触发、二命爆发的关系

[血梅香伤害触发](../BloodBlossomTrigger/视觉需求.md)在目标处另做一次有蝴蝶粒子的绽放；本标记在状态仍有效时继续维持。触发光短暂增强后恢复原亮度。

二命爆发向实际命中的敌人施加血梅香，各敌人的标记分别建立，复用相同造型。主爆发仍为一次整组横扫，个人标记与各次伤害触发保留自己的中心与生命周期。
