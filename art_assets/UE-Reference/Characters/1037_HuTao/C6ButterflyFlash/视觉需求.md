# 胡桃 · 六命蝶光

## 整体效果

六命实际免死保护触发时，在胡桃自身卡牌附近出现一次短促而清楚的蝶光。先由暖红细光勾起蝶形，再以橙金蝶翼与少量火蝶向周围展开，随后迅速变薄、散尽，表达危急时刻被蝶光护住。

当前项目六命在伤害扣血前保护胡桃并触发后续增益，播放点对应这一次实际免死生效。蝶光围绕仍在场的胡桃展示，卡面保持连续，不制造倒下后重新入场或新增一次治疗。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 中心蝶光 | 卡牌附近一瞬可辨的暖金蝶形轮廓，明亮但保留卡绘细节 |
| 护持翼光 | 从蝶光展开的短弧，略有包围感，边缘柔和，体量适中 |
| 离散火蝶 | 少量双翼可辨的火蝶，从不同边缘掠出，轨迹错开 |
| 余辉 | 蝶翼先收细，少量火点稍后淡去，完整结束 |

## 出现、展开与消散

危急触发时先有短促聚光，随后蝶翼清楚展开，向外推开一圈很薄的暖光。火蝶在展开后各自离开：部分回勾上扬，部分从卡后绕向侧边，少量沿斜弧缓慢漂离。各蝶振翅和加减速有差异，尾光跟随真实曲线。

最亮时刻只维持短暂辨识，随后主蝶形拉薄、余蝶散开。整段一次完成，后续抗性与暴击增益沿公共状态显示；仍有效的[彼岸蝶舞](../ParamitaPapilioState/视觉需求.md)继续自身循环。冷却期间普通低血量受击只沿实际结果显示，不反复播放蝶光。
