# 胡桃 · 血梅香蝴蝶绽放

## 整体效果

血梅香实际造成伤害时，在该目标的印记附近形成一次橙红花光绽放，随后多只可辨的火蝶从花瓣和中心向不同方向展开。中心火光短而集中，主体识别来自花形与蝴蝶的动态层次。

每个实际血梅香触发保留自己的目标中心。多名敌人分别触发时，各自出现本项绽放，主攻击的整组刀光与这些独立状态触发分别组织。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 花心聚光 | 贴近血梅香位置迅速聚起的暖红亮点，随后短促绽开 |
| 花瓣火光 | 与标记相呼应的橙红瓣形，先完整再拉薄，层次清楚 |
| 蝴蝶粒子 | 有蝶身、双翼和振翅，亮边与半透明火翼可辨，不以普通光点代替 |
| 蝶尾短迹 | 贴合各蝶真实曲线的细火丝，长度、明暗和断续错开 |
| 末端余火 | 蝶形淡去后少量细火点继续漂离，快速收尽 |

## 绽放与每只蝴蝶的特色轨迹

花心先收紧、短促发亮，瓣形向外展开；蝴蝶随后错开离开花心与不同花瓣，主接触明确在花光绽放的一刻，蝴蝶飞行承担后续余势。

每只蝶都要有可辨的、连续的运动轨迹，采用不同的轨迹关系并错开变化：

- 部分蝶先向侧上方加速掠出，沿一条弯曲S线滑行，在外侧减速振翅后渐淡。
- 部分蝶离开花瓣后先做小回勾，绕过花心侧面，再斜向上扬，近处短暂变大、远离后逐渐变小。
- 部分蝶沿偏心螺旋上升，绕卡面边缘从前侧转到后侧，螺距与半径逐渐展开，随后沿切线离开。
- 少量较慢的蝶从下侧向外滑落，轻轻抬起后折向侧方，与快速外掠的主体形成先后层次。

同一轨迹类型内，每只蝶仍有不同起点、出射角、弯曲程度、深度、振翅相位、停留位置和消失时机；运动中平滑加减速，转向与蝶身朝向、尾迹保持一致。短暂停留也保留轻微振翅和漂移。完整演出呈现“集中绽放—错落飞散—各自收尾”，避免所有蝴蝶沿直线等速放射或整组同步绕圈。

## 接触与收尾

蝴蝶数量、振翅次数与轨迹回环只影响视觉，当前每次实际状态伤害保持自己的一个接触。中心花光先变薄，蝴蝶继续飞离，较慢的少量余火最后淡去。

[卡面血梅香](../BloodBlossomCardState/视觉需求.md)在真实状态仍存在时保持原位，绽放高潮结束后恢复维持亮度。后续再次触发是新的绽放，不重新施加状态或重播整段主攻击。二命增伤沿用本套表现。
