# 温迪 · 风眼、扩散与高天之歌

## 风眼持续状态

风眼围绕真实持有者卡牌，以青绿、浅青白的薄风带组织前后空间。外侧风带各自平滑变速并适当放缩，变化幅度接近但相位不同；中间有向中心加速吸入、逐渐收窄淡去的细气流与短尾丝。全部使用气流造型，不把风元素图标当粒子。

风带有粗细、明暗与柔和端部，正常画幅下保留可读宽度，同时看得清持有者卡面。起手从轻风和吸气逐渐建立外围风带；持续段不中断、不逐圈重新淡入；正常移除时主体与残余气流先后散尽，从当前相位继续退出。

## 单次扩散风暴

从风眼当前空间关系向外推出一次扩大风暴，前缘较集中，后缘逐渐稀薄，最终完整消失。单次扩散与持续风眼分离，扩散触发不重播持续状态的建立。范围取实际目标整组，不逐卡复制完整风暴。

发生火、水、冰、雷元素转化时，保留约一半青绿风效，另一半显示对应元素色；未转化时保持青绿。色彩转换不能遮掉风带的薄厚层次与卡前／卡后遮挡。

## 高天之歌

以战斗背景为地面，在实际目标合并范围下形成一个完整风场。地面有低量青绿阵纹，卷曲风带和细风线沿屏幕法线朝观察者掀起；不改成逐张卡牌竖向柱体。

可被击飞的卡牌在风场接触时立即获得向外冲量，较早到顶，随后加速落回；围绕竖轴横向翻过完整一面，露出真实卡背，角速度随落地收势。免疫击飞的卡牌保持原位，静态卡位与背景布局不变。整体风场先有聚起，接触时最清楚，尾风渐淡收净。

## 视觉部件

| 部件 | 用途与表现 |
|---|---|
| 外围风弧 | 围绕持有者或随一次风暴向外展开，独立变速、放缩，端部与横向柔和渐隐 |
| 卷曲风带 | 在一片整体范围内形成短而有厚度变化的卷风，保留真实前后空间 |
| 细风丝与吸气尾迹 | 少量细长、收尖、相位错开的气流，不使用界面图标 |
| 地面阵纹 | 位于背景地面、卡牌后方的圆环、短刻线与卷曲饰线 |
| 上掀风线 | 沿屏幕法线推进、略向外散开，强化短促冲量与上升动线 |
