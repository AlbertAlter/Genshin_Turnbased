# 迪奥娜 · 猫爪冻冻弹道

## 整体效果

制作可辨认的冰蓝猫爪弹体、沿途细冰雾与命中碎冰。猫爪造型参考原作，掌部与趾部在正常战斗画幅下仍清楚，蓝白亮部、半透明冰蓝次层与柔和外缘有主次，飞行时保留猫爪识别轮廓。

弹道沿用已有[公共弧线弹道需求](../../../../../codex_files/UI/公共弹道需求.md)。这里只补猫爪本身的视觉、尾迹和接触，不另设计一套迪奥娜专属飞行规则。公共弹道目前仍是待制作需求，引用不代表已经有可运行实现。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 冻冻猫爪 | 原作猫爪轮廓，清楚的掌趾结构，冰蓝半透明主体与蓝白局部高光 |
| 发射寒气 | 施放者卡牌附近短促凝起的小片冰气，送出各枚猫爪 |
| 飞行尾迹 | 随实际弧线转向的薄冰雾、细亮痕和少量冰屑，头部清楚、后端渐隐 |
| 接触冰光 | 猫爪到达目标时的短促冰蓝亮光与少量碎冰、冷雾 |
| 尾效 | 猫爪主体在接触后散开，余雾与细碎冰点稍后收尽 |

## 五枚猫爪与实际目标

当前项目一次战技有五枚猫爪，各枚沿实际分配的目标飞行，允许多枚命中同一敌人。每枚从施放者附近发出，准确抵达自己的真实目标，不因视觉弧度重新换人。

公共弹道负责每发有限的侧偏、上拱或景深差异，先略有区别地展开，再平滑抵达目标；不逐帧抖动、不绕无意义的大圈。不同卡距和上下错排都保持自然速度与朝向，尾迹紧随已经走过的弧线。

发射分组与抵达节拍沿实际行动安排；同发与连发按各自实际时点表现，不因五枚外观相同便把它们合为一枚大猫爪，也不随意增加发射延迟。

## 接触与护盾衔接

每枚猫爪的冰光与这枚真实命中接触对应。连续命中同一目标时可短暂交叠细尾雾，各次接触仍分得清，不能堆成遮住整张卡牌的白团。接触后猫爪主体自然碎散，余冰与冷雾收尽，不在目标上常驻完整爪形。

猫爪飞行与我方护盾分别呈现。五枚猫爪结束后，护盾沿现有公共表现建立，不把飞行弹体变成护盾模型，也不根据视觉上看见几枚命中擅自补减护盾。产能沿公共资源显示。

## 天赋命座

已确认全部沿用公共表现。护盾量、猫爪伤害、AP、减攻、回能、治疗和精通等变化保留同一套猫爪；不因倍率或等级变化额外增加弹体、接触或专属强化动画。
