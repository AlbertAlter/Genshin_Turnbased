# 莫娜 · 水中幻愿卡面虚影

## 整体构图

将水中幻愿的虚影做在所选敌方卡位的卡面范围内，保留原作虚影的水形、星光与流动感。以半透明的蓝色水影、局部水纹和少量星点组成主体，不使用普通水元素图标代替，也不增加完整角色模型或另一张人物立绘。

主体集中在卡面中央偏下与两侧，亮点勾出虚影识别轮廓，水体内部较淡，能看见卡绘。给脸部、生命数字、状态栏、元素栏和卡底图标留白。卡前有少量薄水光，较大的水影和回旋纹理保留适当后层，不用一张高不透明度蓝色贴片盖满卡牌。

卡面只是显示范围。虚影始终留在本次创建的场地卡位，原卡牌死亡、退场或该位置暂时为空时，只要虚影仍存在，就继续在原卡面范围显示，不改挂到莫娜或另一个敌人身上。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 水影主体 | 透明蓝水构成的虚幻形体，边缘清楚、内部保留层次，呼应原作 |
| 星光亮芯 | 少量清楚的蓝白星点与短促星芒，不持续过曝 |
| 回旋水纹 | 在卡面范围内缓慢回流的薄水带和细涟漪，有轻微厚薄变化 |
| 水滴与细碎光点 | 独立错落生灭，数量克制，辅助说明水影仍在维持 |
| 凝形与消散薄水 | 用于起退场的短水流、细水珠与余光 |

## 起手出现

原卡位先聚起一小片水纹，蓝白星点在水纹中亮起，薄水流逐渐勾出虚影。主体成形后略有一次舒展，水纹和细滴接入稳定循环，不直接打开完整静止图案。

## 持续循环与周期攻击

水影内部有缓慢回流，外缘轻微起伏，星点与水珠错开相位、寿命和亮度。速度自然变化，循环首尾连续，不每圈消失再出现，也不逐圈增加水量或亮度。

周期攻击时，主体短暂聚亮并推出一圈较薄的水纹，实际受击位置出现短促水光。主体继续维持，攻击结束后回到平时明暗，不重新播放召唤，也不在每一次周期攻击时提前爆碎。

## 结束与爆裂衔接

真正触发到期爆裂时，由这份虚影的当前姿态衔接[独立水爆](../PhantomExplosion/视觉需求.md)：水形短促收紧、亮芯提亮，随后向外破开。原位置不同时保留这份完整虚影与一份新复制的爆裂主体。

没有实际爆裂的普通清理，使用水形变薄、星光减弱、水珠散尽的柔和退出，不冒充一次爆炸或额外命中。

## 天赋虚影与独立实例

已确认天赋产生的虚影共用本套素材。每一份仍有独立的起手、维持、退出和爆裂，不合并成一份计时，不因一份结束而同步撤去其他虚影。

同一卡位出现多份时，可用克制的前后层次、细微位置偏移及不同循环相位区分，保持每份星光亮芯可辨。避免所有虚影完全同相位叠加成白块，也不擅自改成一个带层数的替代标记。天赋虚影的较轻表现可调局部光强与水滴密度，主体结构保持一致。
