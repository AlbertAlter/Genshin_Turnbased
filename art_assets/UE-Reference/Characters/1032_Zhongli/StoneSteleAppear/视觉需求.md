# 钟离 · 地心岩脊短暂显现

## 整体效果与位置

战技在本次选定的敌方场地位置出现一枚岩脊，保留原作岩脊的方正石柱、棱面、雕纹与金色岩光。主体由深棕岩体、较亮的赭金受光面和清楚的金色纹路构成，造型厚重、轮廓简洁，具体柱顶和柱面细节对照原作地心。

柱体顶部直接平顶，不另加独立的外伸盖子。底座与柱身使用同向的截面，底座各边与柱身对应边对齐，不旋成内切、错位的菱形台；底部只保留很薄、几乎不外突的收脚。卡底图标同样遵守这一结构。

一轮施放只在本次选定的位置显现这一枚柱体。可选位置为空时也在原场地位置出现，不改放到钟离或临近敌人身上。岩脊处于对应场地的卡后／地面层，底部扎在地面，保持卡绘与生命数字可读。

按用户要求，完整岩脊仅短暂出现，随后消失。持续存在的实际岩脊改由该场地的卡底图标显示，不在整个状态期间保留大柱模型。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 岩脊主体 | 原作方正石柱、清楚棱面与柱面雕纹，深棕岩体和赭金亮面有体积 |
| 地面凝岩 | 选定位置短促亮起的岩纹与少量细碎岩屑，说明柱体建立 |
| 上升岩光 | 随岩脊显形／立起的金色细光，沿棱面与纹路组织 |
| 短促余尘 | 岩脊成形后少量沉落的岩屑和柔薄尘气，不堆成厚烟 |
| 视觉退出 | 主体随岩光逐渐淡出，余屑和细光收尽，衔接小图标维持 |

## 出现与短暂停留

选定地面先凝起短促岩光，岩脊按原作的立起动势迅速成形。底部与地面接触清楚，柱身纹路稍后亮起，再进入很短的稳定展示；起势、立起、收势有力度和缓急，不做等速缩放的一块长方体。

岩脊在场地短暂站稳后退出大模型显示。金色纹光减弱，主体随岩光淡去，尘和细碎余光稍后收尽。这个退出表示展示交接，不表现成受击摧毁或一次额外爆炸。

战技原有的全敌接触按这一轮真实命中组织；岩脊立起和淡去不再附送额外一次伤害。柱体出现的位置与战技本轮全体伤害覆盖分别清楚，不能因为只选一格就把全体伤害改成单格。

## 卡底状态与后续共鸣

大模型退出后，真实岩脊所在卡位以彩色岩脊卡底图标继续显示。状态仍在而卡位暂空时，图标仍保留；正常到期、替换或移除时，按真实生命周期退出，不能因大模型播完而提前隐藏图标。

后续共鸣从实际岩造物所在位置接上既有[公共岩共鸣](../../../general/GeoResonance/视觉需求.md)，不每次重新播放整根岩脊立起。小图标继续保持，实际状态的存在与大模型是否可见分别表达。

一命允许不同场地同时存在两根岩脊时，各自位置独立保留一个图标。创建新岩脊只播放本次位置的显现，其他仍有效的岩脊图标继续维持；同格刷新或超限替换沿各自实际状态变化处理。

## 本次实机参考观察

已实际查看地心动图228帧／6.84秒中的24张标时截帧，可见高而方正的石柱与沿柱面分布的金色纹光。当前按本项目追加要求使用直接平顶、同向截面和极薄收脚，纹样自行制作。占用格与空格各有短暂显现实例，卡后深度保留；大柱退出仅表示交接卡底图标，不表示真实岩脊被击破。
