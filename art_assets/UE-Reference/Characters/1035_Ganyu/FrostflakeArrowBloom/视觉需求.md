# 甘雨 · 霜华矢与霜华绽放

## 整体效果

特殊重击命中参考原作霜华矢：冰蓝箭矢迅速抵达选定位置，先形成清楚的箭矢接触，随后按原作霜华绽放展开第二段范围冰光。保留原作箭形、霜华轮廓、冰晶／冰花展开与碎冰收尾，具体形态和节奏对照实机。

初次箭矢与后续霜华绽放各有清楚接触，不合成一团普通冰爆炸，也不漏掉原箭的一次命中。整体冰蓝、雪白亮部与较深蓝色冰体有层次。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 霜华矢主体 | 原作式的冰蓝箭形与凝冰亮芯，飞行方向清楚 |
| 短寒气尾迹 | 随箭矢走过的方向拉开，后端渐隐，规模克制 |
| 箭矢接触 | 主落点短促冰光、碎冰与薄霜，对应第一段命中 |
| 霜华绽放 | 原作霜华的范围冰晶、冰花与冷光，展开有明确层次 |
| 碎冰与余雪 | 较大冰片先散开，细雪和寒雾稍后收尽 |

## 飞行、箭矢接触与范围绽放

箭矢从甘雨实际发射位置迅速飞向本次选定场地，朝向与尾迹一致。先形成主落点的箭矢接触，再展开原作式霜华绽放；两段的先后与短促停顿清楚可辨，具体间隔制作时对照原作，并配合本项目实际接触。

绽放以原选定场地为中心，覆盖实际中心及相邻受击范围。中心暂空或原目标已经倒下时，不把爆心擅自移到另一名敌人身上；仍按实际场地与本轮受击结果表现。

一次范围绽放共用一套主体，不为每名被波及敌人各复制一遍整段霜华。局部冰片尺寸与冷光密度保持合理，覆盖扩大主要改变分布与边界。主体接触后迅速拉薄，避免长时间盖住卡绘与数字。

## 共用与增益

普通二段射击和六命即时霜华矢共用本套发射、主接触及绽放，六命只跳过蓄力等待。暴击、减冰抗、回能、等级和伤害增益不增加箭数或绽放段数，沿公共显示衔接。
