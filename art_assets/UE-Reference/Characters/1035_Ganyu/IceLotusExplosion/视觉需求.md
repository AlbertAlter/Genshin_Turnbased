# 甘雨 · 冰莲卡底状态与绽放爆炸

## 状态展示

山泽麟迹的持续冰莲在本次选定敌方场地使用[彩色冰莲卡底图标](../../../../UI/CardBottomStatus/IceLotus.png)显示。图案沿原作冰莲与官方技能字形，浅冰蓝、雪白及较深蓝阴影保持层次，不另加一朵常驻大模型盖在敌人卡面上。

图标绑定真实场地状态，位置暂空或原敌人退场时，只要冰莲仍有效就继续显示。当前冰莲只能存在一朵；重新召唤时旧图标随实际替换退出，新图标在新场地建立。战技使用次数增加不代表同时留下两朵。

## 爆炸整体效果

冰莲实际自然结束时，参考原作山泽麟迹的冰莲绽放与冰元素爆散。以该朵冰莲原场地为中心，短促聚亮，冰花／冰片迅速展开，蓝白冷光、碎冰与寒雾随后收尽。

本项目冰莲绽放对敌方全体造成一段伤害，范围与接触沿实际结果组织；爆心仍在冰莲原位置，不因目标人数、距离或空位改变成另一个任意中心。

| 部件 | 视觉要求 |
|---|---|
| 冰莲短促显形 | 爆裂前一小段原作莲形与聚亮，可辨花瓣，随后进入绽放 |
| 绽放冰花 | 原作冰莲展开的冰蓝、雪白花形与明亮边缘 |
| 范围冷光与碎冰 | 由原场地向本轮实际敌方范围展开，前后层次清楚 |
| 薄寒雾与余雪 | 主体收尽后残留很短的冷雾与细雪，逐渐消散 |

## 接触、收尾与替换

冰莲聚亮后迅速绽开，在一次明确高潮中配合该段全体接触。整组敌人共用一个爆心与一次绽放，不按敌人人数重复多次完整冰爆。亮芯面积克制，碎冰大小与速度错开。

主体展开后变薄、碎化，冰片和余雪各自收尽，卡底图标随真实状态结束退出。短促莲形仅属于这次爆炸的起势，不在爆炸后留下常驻模型。

重施替换、普通清理或取消没有实际绽放攻击时，只移除相应状态展示，不补一次爆炸或产能表现。召唤与绽放的实际回能沿公共资源显示。
