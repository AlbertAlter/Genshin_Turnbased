# 达达利亚 · 近战爆发「尽灭水光」

## 整体效果

参考原作近战爆发的纯水武装挥斩与大范围水光，按用户要求，在敌方全体实际位置斩出一道巨大刀光。整个敌方卡组共用一次完整的大斩击，刀光连接成整体，宽阔、有弧度与锋利边缘。

刀光以明亮蓝白刃沿、半透明水蓝主体和较淡的外层水雾分层。前沿清楚、有厚薄与收尖，后方水带与飞散水珠表达挥斩余势，保留原作水刃的力量感与流动质感。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 纯水聚刃起势 | 短促集中、沿挥斩方向蓄起的水流与水刃亮光 |
| 全体巨大刀光 | 覆盖真实敌方卡位的一道连续水刃／斩弧，刃沿锋利、主体有厚薄 |
| 斩击水幕与拖尾 | 顺挥斩方向展开，前沿最清楚，后方逐渐拉薄、衰减 |
| 目标接触水花 | 与主斩同段的局部薄水片和水珠，数量克制，不为每张卡重复整道刀光 |
| 收势余光 | 斩弧末端、水纹和细滴顺势收尽，结束干净 |

## 蓄势、巨斩与统一接触

先以短促聚水形成蓄势，随后巨大刀光快速斩过整个实际敌方区域。整体轮廓、挥斩方向、起落节奏和水形收束以原作近战爆发为准；覆盖全体敌人位置是本项目指定构图。

巨斩在一次明确的高潮中覆盖本轮全部实际敌人，本项目全体主伤害只有一段统一接触。可用锋利刃沿的运动制造速度感，但不能将这次全体命中改成从左到右逐个延迟受击，也不因一至五人的人数变化变成一至五次大斩。

卡位上下错排时，斩弧与水幕覆盖实际卡牌合并区域，保证上、下排都被斩势触及。扩大覆盖主要调整弧长、水幕分布和边界，水珠与局部刀光厚度独立保持合理尺度。亮芯面积克制，高潮后迅速变薄，不用全屏不透明蓝白色盖住目标。

整道主刀光按本段真实目标合并范围一次定位和展宽，共用同一个挥斩方向与连续尾迹。各目标只补局部水花；后续独立断流引爆仍保留各自中心，主斩保持一次完整挥击。

## 断流引爆与收尾

大刀光接触在前，随后各个实际断流中心衔接[同一套引爆效果](../RiptideDetonation/视觉需求.md)。没有断流的敌人只有主斩接触，不凭空出现断流引爆；多名敌人各自触发时保留各自中心，不把全部引爆合为一个场中央爆炸。

实际被消耗的中心标记随自己的引爆退出；被相邻水爆波及但标记仍在的敌人继续显示断流。主斩的水幕和尾光独立收尽，不因引爆数量增加便重播整道巨斩。

## 天赋命座共用表现

天赋带来的断流延长和近战暴击施加标记，复用本次卡面断流；四命额外断流触发复用本次共用引爆。一命冷却、二命回能、六命结束近战后重置冷却均沿用公共显示，三命、五命等级变化保留原结构，不增加刀光或引爆段数。
