# 达达利亚 · 远程爆发「魔弹一闪」

## 整体效果

远程爆发参考原作，以纯水凝成的明亮箭体、迅疾释放的水流与大范围接触水花组织完整演出。保留原作水箭的识别轮廓、蓄起到放出的缓急，以及释放后展开的水形，具体路径与造型对照实机。

提炼水箭和水流本身的动势，不额外增加人物模型、拉弓骨骼表演或镜头切换。箭体有清楚蓝白亮芯和半透明水蓝外层，尾迹与实际运动方向一致，前后端逐渐收细。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 聚水起势 | 施放者附近短促收拢的水流与亮光，逐渐集中到箭体 |
| 纯水箭主体 | 原作风格的锋利箭形、透明水体和局部蓝白高光，正常画幅可辨 |
| 释放水流与尾迹 | 随箭释放展开的水流、薄水带与短尾迹，有速度变化和方向 |
| 范围接触水花 | 实际敌方目标区域的清楚水光、水片和水珠，与箭的释放形成一段高潮 |
| 余水收尾 | 较淡水纹、零散水滴和逐渐消退的短余光 |

## 释放与群体接触

聚水短而有蓄势，箭体成形后迅速放出，尾迹随运动自然拉开。目标侧的水形展开围绕本轮实际敌方全体范围组织；一至五人、上下错排与不连续卡位都保持一套完整爆发构图，不为每名敌人各发一套完整爆发。

本项目远程爆发有一段全体主接触，水箭高潮与这一轮真实命中统一。箭的水珠、破开的薄水片与后续标记建立不追加伤害段数。原作的具体展开方向、形态和节拍由实机参考约束，避免凭空改成多轮弹幕。

## 断流建立与收尾

命中后，在实际获得断流的敌人卡面接上[断流标记](../RiptideCardState/视觉需求.md)，原爆发的箭体与范围水花逐渐散去，标记清楚留下。

远程爆发施加断流不等于立即引爆断流，收尾不自行补一次全场共用引爆。天赋延长标记、二命等回能及冷却变化沿已确认的标记与公共显示处理，不额外增加整段爆发。
