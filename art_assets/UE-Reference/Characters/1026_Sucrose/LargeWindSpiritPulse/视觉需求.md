# 砂糖 · 大型风灵敌方全体一次攻击

## 整体效果

爆发状态实际触发时，在本轮敌方全体实际目标的合并区域中，出现原作大型风灵的一次攻击：清楚的大型蝶翼状风灵短暂凝形，完成一次有力度的展开、扇翼与风压上涌，接触覆盖整组敌人，随后风翼和旋流自然散去。

每次触发是一套完整但短促的攻击动画，不把原作整段多次周期攻击一口气播放，也不在每张敌人卡上放一只同样大的风灵。砂糖自身的[持续环绕](../LargeWindSpiritState/视觉需求.md)在此期间保持连贯。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 大型风灵内芯与翼形 | 参考原作的青白亮芯、对称而有舒展动势的蝶翼状风光，轮廓可辨 |
| 蓄起旋流 | 敌方目标区域中心附近收拢、托起的透明风流，建立攻击起势 |
| 扇翼风压与上升风流 | 翼形展开后推出一次薄风波，接触时向上卷起，强弱集中 |
| 转化附加部件 | 火、水、雷、冰四种对应的局部色光、短小元素流与接触余光 |
| 风翼碎光与尾风 | 主体完成后逐渐分散的淡风丝、细亮片和收尽的余光 |

## 一次攻击的过程

在本轮目标区域短促聚起青绿风流，大型风灵从中凝形。中心内芯先亮，风翼随后舒展，完成一次有起伏、有加速的扇翼动作，推出风压并掀起上升气流。风灵主体、风压前沿与目标接触的高潮有清楚先后，不能只是放大再缩小一张平面蝶形贴图。

风灵以整组卡位的中心与边界组织大小和分布，兼容一至五名实际敌人及上下错排。范围扩大主要拉开风翼和风流覆盖，局部亮片与细丝尺寸保持可读，不把所有微粒一并放大。主体尽量处于卡后和卡位之间，较薄的前侧风流参与遮挡，避免整个敌方卡组被青白光盖住。

每轮风压在一次清楚的接触时刻覆盖本轮真实目标。卡牌是否击飞随本次实际结果配合，风灵扇翼本身不强制改变每张卡牌的姿态；装饰风丝数量与翼片数量不表示攻击次数。

## 元素转化

没有元素转化时，使用完整的青绿风灵攻击。已经转化为火、水、雷或冰时，风灵主体仍保留青绿翼形，在内芯和推出的局部元素流中加入相应色彩；对应附加接触使用该元素的少量火星、水光、细电弧或碎冰，不能将整只风灵替换成另一种元素的爆炸。

基础风伤与实际发生的转化附加伤害共同组成这一轮动画，后者沿实际接触节奏作补充，不重复生成另一只大型风灵、不再次完整扇翼。首次在这一轮发生转化时，转化色从风压接触后自然接入，对应后续附加接触；未产生转化附加攻击时不凭视觉自行补上。

转化以本次风灵已确定的元素为准，后续不反复改色。已确认六命的对应元素增伤沿用公共状态显示，不额外加一次攻击或专属强化动效。

## 收尾与下一次触发

风翼完成一次攻击后拉薄、化开，薄风弧继续卷出少量余势，亮芯快速减弱，细风丝和碎光稍后散尽。敌方位置恢复清楚，不留下与砂糖自身状态重复的常驻大型风灵。

下一次真实触发再完成一轮独立的扇翼攻击。每轮不重新抛烧瓶、不重播砂糖本人整套施放，不因状态延长而把单轮动作变慢或多播放一轮未触发的攻击。
