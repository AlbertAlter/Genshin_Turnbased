# 砂糖 · 大型风灵自身环绕状态

## 整体构图

爆发状态存在期间，以砂糖自己的卡牌为唯一中心，用几条轻盈的青绿风带、少量蝶翼状风光和细小亮点形成环绕。风流真正从卡前经过、绕到卡后，再回到前方，具有景深与遮挡，不只是贴在卡面上画一个平转的圆。

主要分布在卡牌两侧、底部和卡后，正面保留较淡且较薄的风丝，避开脸部、技能信息、元素栏、状态栏和生命数字。风翼状亮片只作少量识别点，不在自身卡旁常驻一只遮挡卡绘的巨大风灵。

这是用户指定的爆发持续表现。自身环绕与[敌方全体的触发攻击](../LargeWindSpiritPulse/视觉需求.md)彼此独立：环绕用于说明状态仍然存在，敌方只在实际触发时出现一次攻击。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 主环绕风带 | 青绿半透明风带，内侧偏浅、边缘柔和，卡前卡后可辨 |
| 次级细风丝 | 比主风带更细、更淡，稍有滞后地绕行，增强轻盈感 |
| 蝶翼状风光 | 少量淡青白风翼亮片，形状呼应原作大型风灵，沿风路舒展 |
| 细亮点 | 数量克制、独立生灭，沿绕行方向漂移并自然淡去 |
| 转化微光 | 状态已发生元素转化时，局部出现对应元素的细小色光，保留青绿风流主体 |

## 起手出现

砂糖卡牌附近先聚起淡青光，主风带从卡后拉出、经过两侧与卡前，逐渐围成完整环路。次级细丝和少量风翼亮片随后加入，经过一次克制的提亮后稳定下来。

起手只建立自身状态表现，不在敌方提前播放一次攻击，也不因敌人有多张卡牌而重复建立环绕。

## 持续循环

主风带、细丝和亮片各有错开的绕行相位、速度与生灭节奏，运动平滑、有轻微缓急变化，保持同一个主要绕行方向。粒子之间有距离疏密，不整齐排成等间隔队列。风带宽窄、亮度与轻微上下起伏连续变化，不每轮熄灭再重新出现。

循环可以持续任意时长，并自然兼容爆发持续时间延长。长度变化只延长维持段，不把整个动画拉慢，也不增加一套叠加环绕。

发生元素转化后，让少量局部微光或细丝平滑带上相应的火、水、雷、冰色彩，主风带仍保持可辨的青绿风元素外观。转化从当前循环相位接入，不重新起手；尚未转化时保持原风色，不以附近任意元素自行变色。

## 与触发攻击配合

敌方大型风灵攻击时，自身环绕继续运行，可有一次很轻的亮度呼应，随后回到平时状态。环绕主体不离开砂糖去追击敌人，也不因一次触发结束而消失或从零重播。

## 消失收尾

从当前循环相位停止补入新亮点，主风带沿绕行方向逐渐拉细、散开，次级细丝与风翼亮片陆续化为微光，最后收尽卡前卡后的余光。退出不必等完整一圈，也不依赖正在播放的敌方攻击尾效来重新开始循环。

## 已确认的天赋与命座表现

二命延长状态时自然延长循环；两个天赋的精通增益、六命的转化元素增伤沿用公共状态展示。一命的战技可用次数和四命的战技冷却变化沿用公共充能、冷却显示，不另做专属增益动效，不因数值提高额外扇翼或增加一轮攻击。

## 本次实机参考观察

已实际查看爆发154帧／7.7秒中的24张标时截帧，确认薄青绿风翼、细丝、间歇扇翼和上升气流；原作是在敌方附近，本页本人卡牌环绕为用户指定适配。当前自身风带、翼形微光和亮点各自错相，另有循环中接入转化微光与敌方单次攻击同时存在的示例；转化不重启环绕，原风色主体保留。
