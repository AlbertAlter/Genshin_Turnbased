# 可莉 · 轰轰火花持续状态

## 整体观感

爆发表现为状态持有者周围一组持续存在的红橙色花形火花／发射体，伴随错落的小亮点和短促攻击光轨。保留原作花形轮廓、中心亮核和金橙发射光的辨识度，轻巧而活跃，不能只用一场大型爆炸代替整个爆发，也不能把持续火花做成蹦蹦炸弹在空中轮流出现。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 花形火花／发射体 | 红橙色花形边缘与明亮中心，大小适中，在持有者周围有前后深度，持续可见 |
| 持续小火星 | 稀疏金橙亮点，围绕主体错开出现、漂动与熄灭，不持续积累 |
| 攻击发射光轨 | 从本次花形发射位置指向实际目标的短促亮线／火花，方向清楚，发射与命中有可读先后 |
| 目标接触火光 | 在实际命中处短促爆亮，可沿用公共轻量爆炸的火团与火星层次，规模不遮住常驻主体 |
| 退出碎光 | 花形结构逐渐变暗、解体成少量火星，最后的火星比主体稍晚消失 |

## 起手出现

持有者周围先聚起小范围金橙亮点，数个花形火花错开显现、展开并亮起中心。位置分布围绕持有者的实际卡牌，有近有远，前后能被卡牌自然遮挡；形成完整持续状态后回落到稳定亮度，不用过曝火团遮住出现过程。

## 持续循环与攻击

花形火花在持有者周围轻微漂浮、转动与错落明灭，主体保持稳定可读。小火星有独立生灭和轻微速度变化，循环衔接不闪断，不每轮重新展开一次所有花形结构，也不逐轮变得更亮或更多。

发生本次实际攻击时，对应花形中心短促增亮并向实际敌方目标发出明亮光轨，接触处出现合理小爆炸，随后回到持续状态的亮度。攻击只是叠在常驻显示上的一次动作，不把整个状态收掉再重新出现；空闲循环也不会为了热闹自行不断轰炸。发射与命中仍保留原作活泼、清楚的节奏。

## 消失收尾

状态结束时停止新的发射与新火星出现，已经发出的短暂攻击先收完。花形主体从当前漂浮相位直接变暗，轮廓碎成小亮点，余火星散开后全部消失。退出可在循环中的任意时刻发生，不要求回到初始位置，也不无条件追加一次大爆炸。
