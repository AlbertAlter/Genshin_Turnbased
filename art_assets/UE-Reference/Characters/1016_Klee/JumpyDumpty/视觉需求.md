# 可莉 · 蹦蹦炸弹与诡雷

## 整体观感

战技以一枚有清楚实体的大型蹦蹦炸弹连续抛掷、弹跳，配合每次实际命中的爆炸；最后炸弹本体真正爆开消失，并从实际分散位置抛出小型诡雷。蹦蹦炸弹和诡雷都需要完整、自然的抛物线，不能用沿卡位滑动、切换位置或循环上下浮动代替。

大型炸弹保留原作红色圆鼓外壳、浅色顶部、耳状突出部分、腰部环带与表情细节，有可辨的体积和明暗。诡雷明显更小，浅色小球体配红橙色花瓣／叶片状顶饰，与大型炸弹区分；火焰与爆炸的层次沿用之前的公共火系效果。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 蹦蹦炸弹实体 | 可辨的大型圆鼓炸弹，翻滚、落下和反弹时保持体积，不能在火光里始终看不见外壳 |
| 弹跳火花与短尾迹 | 火星跟随实际空中路径，落下前向后上方拖曳，弹起后随新方向改变 |
| 每次命中的爆炸 | 在本次炸弹实际接触点出现短促亮核、翻卷火团和碎火星，可沿用公共轻量／适当强度的爆炸，范围随实际受击范围 |
| 最后一次本体爆散 | 最后一跳结束时，外壳轮廓被爆开的火光打散，碎块／碎焰外抛，完整模型从此消失 |
| 诡雷实体与抛出火花 | 小型浅色球体与红橙花瓣顶饰，从实际分出位置沿不同抛物线飞散，少量火星随动 |
| 末尾余焰与轻烟 | 仅为命中与最后本体爆散的短暂收尾，不形成持续火场 |

## 蹦蹦炸弹的实际弹射

第一次从可莉卡牌一侧抛向本次实际目标。每一段都能看出向上抛起、上升减速、顶点附近稍缓和随后的加速下落；水平方向与竖直起落共同形成自然抛物线，而不是把同一段上浮动画叠在恒速平移上。

到达本次接触点后，炸弹有短促接触和反弹感，再从这个真实接触位置向下一次实际落点弹起。首次、第二跳、第三跳的方向与位移跟随本次实际弹射目标，新的弹道从上一段结束处连续接上，不预先固定成直线等距三连，也不在中途瞬移到下个卡位。每一段的起跳高度、翻滚和节奏与本次飞行距离相称。

每次实际命中都在正确接触时刻、接触位置出现合理爆炸。前面的命中爆炸短促，能看清同一枚炸弹从火光中继续弹出；不能第一跳就把本体永久炸没，又在别处重新生成另一枚。空中经过某张卡牌上方，不自动增加一次爆炸或命中。

## 最后爆炸与本体消失

最后一次接触时，命中爆炸与本体爆散组成同一次结束：先出现强亮接触核，炸弹外壳随即解体成飞散碎焰／少量碎块，随后余焰散开。完整炸弹模型必须在这次爆炸中真正消失，不能只让一层公共爆炸罩在它外面，等火光散去后还看见完整炸弹；也不能只把完整模型慢慢缩小或淡出冒充爆炸。

最后本体爆散是最后一次命中的视觉收尾，不再额外追加一轮无对应命中的爆炸。

## 诡雷的抛物线与落地

诡雷从蹦蹦炸弹实际分散的位置飞出。各枚有清楚、略有区别的初始方向、弧高与落点，球体和顶饰随路径轻微翻转；运动带重力感，先上抛再下落，不像烟花光点一样匀速向外漂。

诡雷的来源位置跟随这次实际弹射结束的炸弹位置，不从固定场景中心或预设圆周生成。每枚诡雷飞到自己的实际落点，接触地面后**直接消失**，不在地上继续摆放、弹跳或等待自动爆炸，也不额外制作一轮落地爆炸。若某次落点本身有对应的实际命中，按该次命中表现接触爆炸，诡雷模型仍在落地时结束，不把纯粹的落地又算成一次额外命中。
