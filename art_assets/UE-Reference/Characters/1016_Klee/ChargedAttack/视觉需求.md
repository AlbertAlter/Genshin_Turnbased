# 可莉 · 整体四叶印重击

## 整体构图

重击直接在敌方三张目标卡牌的整体区域上显示**一个整体四叶印**。印记按这三张卡牌的合并范围展开，中心位于整体区域中间，四瓣结构横跨并联系这三张卡牌；上方保留**一套**原作红橙色四叶花形发射器，与整体印记构成同一个重击效果。

三张卡牌共用同一个印记、发射器和施放节奏，不在每张卡上各放一个四叶印或一套发射器。印记直接在目标区域出现，不从可莉卡牌上先生成再搬过去。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 整体四叶印 | 一个大而可辨的四叶形印记，橙金色细亮线与适量明亮填充，覆盖三张目标卡牌的合并区域，保留卡面可读性 |
| 上方花形发射器 | 一套悬在整体印记上方的红橙色四叶花形结构，花瓣为可辨的成对弧形轮廓，中心更亮，有轻微体积与角度 |
| 发射亮线与光核 | 从上方发射器指向整体印记中心的短促黄白光轨，中心瞬间增亮，空间关系明确 |
| 重击冲击火光 | 从整体印记的中心和四瓣边缘舒展的一次橙金冲击、碎火星和短火纹，三张卡牌同时处于这一击的视觉范围 |
| 退场余光 | 四叶轮廓与发射器在完成冲击后收窄、碎成小亮点并消散，短暂余光稍晚结束 |

## 出现、发射与收尾

目标区域的整体四叶轮廓先短促亮起，上方花形发射器随之显现并聚起黄白亮核。两者有明确上下关系：上方是发射结构，下方是覆盖三张卡牌的整体印记，不只是孤立的四叶草图标。

发射器短促发亮，亮线连向印记中心，随即整枚四叶印一起爆亮并向外释放一次重击火光。节奏是短促聚起、迅速发射、一次有分量的冲击；不是三张卡牌依次各播一遍，也不因目标有三个而追加三次施放。

命中后，发射光轨先消失，四叶印与花形发射器解体成少量四叶形碎光及普通火星，随后全部散尽。不能保留一个静态大印记挡在卡面，也不能用普通圆形爆炸遮住最关键的四叶形识别点。
