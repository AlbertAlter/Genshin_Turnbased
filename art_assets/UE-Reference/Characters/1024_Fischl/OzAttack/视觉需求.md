# 菲谢尔 · 奥兹共用触发攻击

## 整体观感

奥兹的常规射击、技能回应、天赋追加和命座协同攻击，共用一组**聚雷、短电矢、单目标落雷、命中电弧与余电**的基本部件，按本次攻击需要组合。保持原作利落的紫白雷光和夜鸦气质，强弱、方向、范围与接触次数清楚，避免每种来源各换一套无关造型。

常规射击由奥兹所在位置发出，短促地击向实际目标；需要落雷的追加攻击则从实际目标上方贯下。两种方式共用紫白亮芯、紫罗兰外晕、细分叉与目标端电弧，既有一致性，也保留发射方向的区别。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 聚雷呼应 | 喙前、眼部或羽缘的一次小幅提亮，少量细电丝迅速聚拢 |
| 短电矢 | 尖锐、细长的紫白电束，粗细略有起伏，外层薄紫光，带少量短分叉 |
| 单目标落雷 | 从目标上方迅速贯下的紫白主干，有明确接触点、短分支与断续余电 |
| 范围放电薄弧 | 召唤或范围回应时，从实际起点短促展开的薄紫电弧与少量散羽 |
| 命中亮核与电弧 | 目标端短促亮起的小电核、局部曲折电丝与少量细光，保持卡面可读 |
| 消散尾电 | 已走路径上逐渐收窄、断续熄灭的细电丝，端部连续渐隐 |

## 常规射击与协同攻击

悬浮中的奥兹朝实际目标略转头，喙前聚起一小点紫白电光，紧接着沿目标方向快速射出一束电矢。发射有很短的蓄势和迅速贯通，头、颈与羽翼有克制的发力呼应，身体仍保持悬停。

电矢来自奥兹当前实际位置，目标就在其下方卡位时，路径自然短而向下；攻击邻近目标时，路径向相应方向倾斜。主路径清楚，细折转和短分叉增加电流感；不为了拉长演出绕场一圈，也不把每次射击都做成粗大的全屏雷柱。

同一次行动内连续两发或多发攻击，各自有发射、抵达与接触，目标可以不同。显示沿已确定的目标与顺序，不在发射时再挑选一个敌人；剩余电丝仍在收尾时，下一发能够接续，主接触不会糊成一团。

命座协同可以沿用这套短电矢，按本次实际强度调整聚雷、粗细与接触力度。某次追加攻击发生时若没有持续奥兹主体，发射端仅保留本次来源位置的一小点鸦眼般紫光呼应，目标端仍使用共用接触效果，不凭空增加一只长期悬浮的夜鸦。

## 技能、天赋与范围回应

召唤奥兹的技能先以短促聚雷和薄电弧建立主体位置，范围内的实际受击卡牌在各自接触位置出现同风格的紫白电核。整片放电有一个起势，各目标的局部接触清楚，范围扩大主要体现在覆盖和电弧分布，奥兹本体大小保持合适。

重击引发奥兹回应时，奥兹局部提亮、张翼发力，从所在位置短促放电，按本次实际范围组织接触。原重击的箭矢和这次追加放电有先后与区别，不能让一发追加电矢重复代表整次原重击。

反应引发的追加雷击采用目标上方的一道短促落雷：主干迅速贯下，在相应目标形成清楚亮核，局部电弧稍晚收住。奥兹只作克制的提亮呼应，持续主体维持，不必每次飞到目标头顶或重新显形。落雷可与[爆发](../MidnightPhantasmagoria/视觉需求.md)共用基本形态，强度按这次实际攻击区分。

已有奥兹参与爆发的额外范围放电，也可沿用这里的薄弧与局部接触，先在本次原位置完成自己的响应，再接绕场动作。属性增益和回能等没有攻击hit的变化，只保留对应界面的实际反馈，不额外补电矢或落雷。

## 接触、次数与高频衔接

每个实际hit到来时，电矢或落雷抵达对应卡牌，紫白亮核迅速闪起，向周围散出短小不规则电丝。主干很快变细、断开并淡去，接触点和短电弧随后收尽。尖锐、短促、有力量，但亮度峰值只持续很短，卡面不会长时间发白。

一次真实hit对应一次清楚接触；同刻命中的多个实际目标可共用起势，但每个目标都有自己的接触。装饰电丝、羽片与分叉不增加攻击次数，增伤也不自动增加发射数量。

高频触发时，奥兹的振翅与持续明暗连续，各次头部呼应可以紧凑接续。电矢和接触余电各自收尾，亮度、分叉与羽片不会不断累积。普通攻击结束后，奥兹回到[持续悬浮](../OzState/视觉需求.md)，不重复起手或退场。
