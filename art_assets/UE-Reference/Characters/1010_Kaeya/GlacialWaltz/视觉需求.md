# 凯亚 · 凛冽轮舞

## 整体观感

三枚蓝白寒冰之棱围绕一个真实持有者持续顺时针旋转，六命示例为四枚。冰棱有收尖、切面、透亮外壳与乳白冰芯，寒雾和稀疏霜屑略落后于主体。环绕具有卡前与卡后深度，保持卡面可读，不以几条完整光圈代替冰棱主体。

## 视觉部件

| 部件 | 造型与运动 |
|---|---|
| 寒冰之棱 | 不完全对称的细长冰体，蓝色暗面、较亮棱边、透明冰壳与内部裂纹分层可辨 |
| 霜气 | 端部与侧缘柔和的薄寒雾，沿当前轨道落后，大小、浓淡和相位错开 |
| 冰冷尾迹 | 冰棱身后短而细的冷光，贴合当前运动，不连接成过亮的整圆 |
| 霜屑 | 少量小冰晶，独立错落，正常退出时略向外、向上散开 |

## 建立、维持与退出

建立时先显现轻霜气，随后冰棱逐枚凝出体积与棱光，尾迹、细霜屑稍晚补入。主体逐渐清楚，不瞬间切入整套循环；这一段是持续状态的建立，不额外添加一次全场攻击闪光。

维持期间始终保留清楚的冰棱与短冷光，轨道持续向前，不在每圈重新淡入。三枚与四枚的单体尺寸相同，数量变化不拉大整组卡位或改动静态参考布局。

正常退出从当下环绕位置继续。冰棱先略收窄并化散，短尾迹随后变薄；寒雾略展开，霜屑继续沿余势散开，稍晚收尽。退出无需等待整圈，也不把建立倒放成唯一退场。

## 单次离轨触发

沿用独立的单次冰棱离轨与目标接触效果：从当下轨道相位顺旋转方向甩出，冰雾和霜屑沿同一路径跟随，接触后短促碎冰散开。该动作期间，持续状态保持自身相位，不重新建立或退出。
