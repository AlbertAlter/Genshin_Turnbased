# 芭芭拉 · 闪耀奇迹大招

## 整体观感

一次明亮、轻快、有舞台感的水元素治疗绽放。原作识别点是芭芭拉身边突然亮起的彩色星星、清透气泡和浅蓝白闪光，夹少量虹彩；水色是主体，黄色、浅粉紫等星光作点缀。柔边、光感与层次沿用之前特效的风格，高潮明显比持续水环亮，仍能看清卡牌。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 起势水光与绽放亮部 | 蓝白色短促聚光与一次舒展的水光，负责由蓄势到高潮的主节奏，不形成常驻光球 |
| 彩色主体星星 | 清楚的星形轮廓，蓝白为主、少量黄色和浅粉紫点缀；大小、远近及旋转错开，是主要识别点 |
| 透明气泡 | 透明薄边、局部明亮高光，少量虹彩，随星光散开并略向上漂动，保持通透 |
| 治疗呼应水纹 | 我方受治疗卡牌周围较淡的蓝白水纹和小星光，与主绽放同刻呼应，范围与亮度较克制 |
| 细碎余光 | 比主体星星更细、更淡的零星亮点，主光回落后继续漂散，形成最后的收尾 |

组合后应先看见芭芭拉周围的一次星光水色绽放，再看到队伍卡牌的轻微呼应与余光，整体只出现一次高潮。

## 起势

芭芭拉卡牌周围先聚起小范围的蓝白水光，数枚小星星和气泡随弧线靠拢并亮起，形成短促的蓄势。光点有前后距离与大小变化，不排成整齐一圈，也不把角色整张卡盖白。

## 绽放与治疗展开

以芭芭拉卡牌为中心，明亮水光与星星向外舒展开，形成一次清楚的绽放。较大的彩色星星负责识别轮廓，小气泡、细水光和微弱虹彩补充层次；外扩先快后缓，星星边缘柔亮，主体形状可辨，不做满屏同样大小的星形贴片。

在我方受治疗卡牌周围同时出现较克制的蓝白星光与水纹呼应，让人能看出这是一次队伍治疗；主视觉仍集中在芭芭拉，其他卡牌不会各自重复一整套同等亮度的大招。保持现有战斗视角，以卡牌周围的效果表达原作的偶像舞台感。

## 收尾

主闪光迅速回落，外扩星星带少量余光继续漂散，气泡缓慢上浮并变淡，最后零星亮点散尽。大小、速度与消失时刻错开，保留一点轻盈的余韵；完整播放后不留下持续领域或第二个常驻水环。若战技水环正在显示，仍保持原来的环绕节奏，大招的绽放与它可以同时看清。
