# 琴 · 风压剑横向冲击与双卡翻面

## 整体观感

琴的战技表现为**从屏幕右侧向左侧扫过两个目标的一次风压冲击**。短促聚风后，一道青绿、浅青白的风压前沿快速推出，后方带着细长气流与轻薄卷风，连续掠过两张目标卡牌。冲击利落、有方向和力量，接触后迅速散开。

两张卡牌受到这一次冲击，分别绕自身竖轴从右向左完整翻转**360°**，最后以正面回到原卡位。风压是横向扫过的主体，翻面是卡牌受冲击后的动作；画面中能分清两者。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 短促聚风 | 目标范围右侧少量细风丝向一个局部汇拢，浅青白亮度短暂增强，随即释放 |
| 风压前沿 | 一道略带弧度、有薄厚层次的风压面，中心方向明确，前缘浅青白、外侧青绿透明，快速从右向左推进 |
| 后随气流 | 沿已经扫过的方向拉出的数条柔边风带与细风丝，长短、宽窄和相位错开，尾端自然收细 |
| 接触卷风 | 风压与卡牌接触时短暂舒展的局部卷曲气流，顺着右向左的主方向掠过卡边，强化推动感 |
| 双卡翻面 | 两张完整卡牌各自从右向左转过一整圈，过程中可见卡框、侧边和真实卡背，最后回正 |
| 消散余风 | 扫过范围左侧后逐渐断开、收窄的薄风丝和极少量微光，全部自然消失 |

## 起势与一次横向冲击

聚风集中在本次两张目标所占范围的右侧，起势短，不长时间停留蓄力。细风丝略向中心收拢后，风压前沿迅速向左推出，速度从压缩到释放有明显变化；不能整段匀速平移。

前沿轻薄通透，用略弯曲的风压弧、内部薄气流及前后错落的尾丝构成体积，最亮处集中在迎风的前缘与接触附近，两侧和尾端连续渐隐。风压经过后保留一瞬可读的轨迹，再快速变薄散开。

一次冲击沿同一方向连续经过右侧目标、再扫过左侧目标。两处接触间隔紧凑，能读出风的推进方向；不为每张卡各放一股独立风暴，也不往返扫动。风压扫过两张卡后只向左继续短距离，随即收尾，不需要横穿整个战场。

风效为琴本次战技单独设计：采用横向喷发的风压、后随气流和接触卷风。温迪战技的地面阵纹、朝观察者上涌的风场与宽风带构图不用于本项；琴的蒲公英环绕状态也不随这次战技额外出现。

## 两张卡牌从右向左翻转360°

右侧卡牌在风压接触时首先受到冲量，左侧卡牌随风压抵达紧接着响应，两张卡的动作有短暂交叠。各卡从起转时就具有明显角速度，随后逐渐减速，完整经过**正面、侧边、卡背、另一侧边、正面**，连续完成一整圈并自然回正。

翻转轴是卡牌自身的竖直中轴，正对战斗画面观看时方向为从右向左。翻面时整张卡牌稍向观察者抬离原平面，随深度带出克制的透视放大；前段较早达到离屏最高点，之后逐渐加速落回。旋转与抬离具有惯性，起跳果断，后续运动逐渐交给余势。

卡面、卡框、侧边和真实卡背属于同一张完整卡牌，遮挡与朝向连贯。翻转结束后两张卡均恢复原来的位置、朝向和大小；其他卡牌保持原姿态。

风压接触与各自起转紧密相连，尾风在翻面初段仍可掠过卡边，但不长时间包住卡牌遮挡正反面。一股风依次扫过两张卡是同一次冲击的空间过程，不因有两个接触位置而额外增加一轮攻击演出。

## 收尾与画面层次

主体风压从左侧离开目标范围后迅速变薄，后随风丝沿右向左的惯性继续少许，再错落消散。主风先收完，卡牌余下的惯性翻面和落回自然结束，不要求风持续吹满整个翻转时长。

风效主要集中在两张目标的合并范围，纵向厚度足够覆盖其接触区域，保留上下错排时的覆盖。卡前可见少量清楚的前沿与细风丝，卡后部分由卡牌自然遮住；卡面中央不被大块高亮青绿色遮住。冲击长度、纵向覆盖、风带粗细、尾丝长度与亮度分别调整，覆盖变大时仍保持薄而有力。
