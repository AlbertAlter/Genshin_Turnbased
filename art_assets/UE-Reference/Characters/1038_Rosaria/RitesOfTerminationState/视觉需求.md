# 罗莎莉亚 · 终命的圣礼持续冰枪

## 整体效果

[爆发扎下](../RitesOfTerminationCast/视觉需求.md)的那一根原作式冰枪，继续立在本次所选中间卡牌对应的位置。冰枪本体是持续主体，表面有克制的冰蓝冷光、少量细霜与冰晶微光，周围只留很薄的寒气，保持枪形和卡面清楚。

每次爆发建立的领域各自维持自己的冰枪。多份领域可以共存，其位置、出现时机、当前循环与退出互相独立。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 留场冰枪 | 直接衔接本次爆发插下的原作式枪体，枪头、枪身及冰晶切面可辨 |
| 表面冷光 | 沿冰体细部流动的低强度冰蓝微光，亮暗层次稳定 |
| 根部薄霜 | 接近落点的少量霜气，密度低，主要提示冰冷和接地 |
| 细碎冰光 | 少量错开出现、缓慢漂离的细晶亮点 |
| 退出碎霜 | 冰枪失去凝聚、变薄与碎化时的短余光，接着收尽 |

## 起手与持续循环

起手承接爆发的冰枪扎入与落地余光：枪体先稳定，落地的强光、碎冰逐渐减弱，进入表面冷光、薄霜和细微冰晶的循环。枪体保持在原落点，不在衔接时重新插下一根。

循环以稳定枪形为主，表面冷光缓慢流动，根部霜气小幅聚散，细晶各自错开生灭。主体亮度和密度稳定；二命延长时自然多维持一回合，视觉循环长度不换算成状态回合数。

[触发冰雾](../RitesOfTerminationMist/视觉需求.md)是独立的单次释放。释放期间原枪继续留场，表面亮度可短暂呼应，随后回到当前循环相位，状态续时和数值变化保持展示连续。

## 中间卡位、空场地与多份领域

冰枪的根部始终跟随这份领域实际记录的锚点，中间卡牌倒下、离场或换入其他单位后，只要场地状态仍存在，原位冰枪继续显示，表示该处仍有领域。

领域记住本次选中的三格，后续触发使用这些原位置；冰枪不因人数变化重新寻找新的中间敌人。多次爆发形成的冰枪各自按真实领域保留，重叠时控制冷光和薄霜亮度，维持独立存在与各自触发关系。

## 消失收尾

真实领域结束时，冰枪从当前循环相位退出：表面冷光先收弱，冰体边缘逐渐松散成细碎霜光，根部薄霜随后散开，最后清空该份主体与余光。消失保持原位置。

正常到期的消失不增加一次插枪、爆炸或伤害触发；其他仍有效的领域继续维持自身冰枪。天赋暴击、AP、回能与六命减物抗沿公共显示。
