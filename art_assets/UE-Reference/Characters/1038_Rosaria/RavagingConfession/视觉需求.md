# 罗莎莉亚 · 噬罪的告解刀光

## 整体效果

战技使用符合刺击、挥砍动作的冰色刀光，保留原作短促、锋利、果断的枪势。第一段以集中、锐利的刺势光痕迅速切入，第二段以更完整的挥砍弧光收束，冰白亮刃、淡蓝半透明主体与少量碎冰有清楚层次。

本项按用户修正使用有形状、方向与完整运动的刀光。卡牌沿用现有动作和站位，主刃的推进、展开与尾迹承担速度感。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 第一段刺势刀光 | 轮廓集中、前锋收尖，带短而清楚的冰色切入轨迹 |
| 第二段挥砍刀光 | 更有弧度的冰白刃沿与淡蓝扫面，刀光曲线随挥砍方向展开 |
| 紧随主刃的寒光尾迹 | 跟随已走过的路径拉薄，端部与侧边连续渐隐 |
| 局部接触 | 实际受击处的短促冰屑、寒光与细霜，方向和主刀光一致 |
| 收势余光 | 第二段后少量细碎冰光顺势漂离，迅速收尽 |

## 两段节奏与实际三人范围

先短促收势，第一道刺势刀光迅速切入并形成第一段接触；随后连贯转入第二道挥砍刀光，第二段的弧度、覆盖和发力更明确。两段有清楚的起落与短促转换，准确方向、曲线与间隔制作时对照原作。

每一段各用一道主刀光，按这一段真实受击目标的合并范围统一组织弧长、朝向、展开宽度与覆盖。当前战技为相邻三人、两段伤害：第一段整组共用一道刺势主刃，第二段整组共用一道挥砍主刃，各目标只补局部接触。

上下错排或实际目标不足三人时，主刃随实际范围调整。刀光厚度与碎冰尺寸保持合理，范围扩大主要改变扫面；同段各目标按真实接触时点响应，保持完整的一次挥击。

## 运动、收尾与增益

刀光短促蓄起、迅速加速，接触时亮刃最完整，随后拉薄、收尖。尾迹略落后于主刃，冰屑顺运动方向短距离散开。前一段余光弱于后一段主体，两段结束后卡面恢复清楚。

天赋暴击、一命普攻AP、四命战技回能及等级变化沿公共显示，同一套刀光保留两段结构。六命的减物抗来自爆发命中，沿对应实际状态显示。
