# 罗莎莉亚 · 终命的圣礼刀光与插枪

## 整体效果

爆发明确分为先后两段：先扫出一道覆盖本次实际相邻三人范围的冰色刀光，再在所选中间卡牌对应的位置，将按原作造型制作的一根冰枪扎入地面。刀光接触与冰枪落地各有自己的高潮，完整衔接本项目的两段伤害。

冰枪保留原作可辨的完整枪头、枪身、冰晶切面与冰蓝层次，准确轮廓、比例和细部制作时对照实机。枪体实体清楚，落地后自然成为[持续冰枪](../RitesOfTerminationState/视觉需求.md)。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 先行主刀光 | 一道连贯的冰白刃沿与淡蓝挥扫面，前缘锐利，尾缘逐渐变薄 |
| 挥扫尾迹 | 紧随主刃的短寒光，保留方向与余势 |
| 原作式冰枪 | 完整枪形和冰晶体积，亮刃、较深冰蓝主体与透明层次可辨 |
| 冰枪扎入动作 | 枪体沿明确方向加速下落／扎入，枪尖、枪身与落点关系清楚 |
| 扎入接触 | 以中间位置为中心的一次短促冰爆、碎冰与薄霜，覆盖本次真实受击区域 |
| 收尾与留场 | 刀光和落地余光收尽，已插下的同一根冰枪继续留在原位 |

## 第一段：一道覆盖整组的刀光

短促起势后，主刀光迅速扫过本轮实际目标区域，形成第一段接触。三名目标共用这一道连续主刃，刀光的朝向、弧长与扫面统一覆盖真实目标合并边界，兼容上下错排，各目标只补局部冰光。

第一段结束后保留少量快速变薄的尾迹，视觉重心随即转到中间位置凝形、扎入的冰枪。两段次序清楚，刀光余光与插枪起势可以自然交叠。

## 第二段：在中间卡牌处扎下一根冰枪

冰枪落点取本次实际选中位置中间的卡位，对应当前领域的真实锚点。落点不是整片敌方区域的任意几何中心；实际目标不足三人时，继续使用本次真实领域记录的锚点。

枪体在该位置上方清楚显形并加速扎下，落地时枪尖接触地面，主枪身有极短的受阻感，随后稳定留场。第二段接触以这一落点为中心，冰光与碎冰共同覆盖本轮实际三格。

整组只出现这一根主冰枪。枪体锚定中间卡位对应位置，根部在该卡位的地面层；可将主要枪身置于卡后，保留枪形轮廓以及卡绘、血条和状态信息的可读性。

## 与持续状态的衔接

扎入后仍是同一根冰枪，落地余光逐渐变成稳定的薄霜与微弱冷光，连贯进入持续状态。后续伤害触发使用[冰雾](../RitesOfTerminationMist/视觉需求.md)，不重播刀光或插枪。

二命只延长新领域的持续时间。暴击分享、回能、减物抗及等级变化沿公共显示，爆发两段和每次一根冰枪的结构保持一致。
