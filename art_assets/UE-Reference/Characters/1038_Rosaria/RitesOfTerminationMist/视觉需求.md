# 罗莎莉亚 · 终命的圣礼触发冰雾

## 整体效果

领域实际触发伤害时，从原有冰枪附近释放一次冰雾。冰白与淡蓝的寒雾先在枪身、根部略作聚集，再向这份领域记录的实际三格铺开、翻卷，接触后逐渐变薄、漂散。

本次触发以有层次的冰雾为主体。持续冰枪保持原位，雾的释放与回落表达这一次寒气伤害。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 枪旁聚雾 | 枪身与根部附近短促变浓的薄寒气，衔接当前持续状态 |
| 主冰雾 | 同一片覆盖本次实际三格的淡蓝、冰白雾层，前后层次与透视空隙清楚 |
| 翻卷雾丝 | 顺外推方向形成的柔软卷曲，有快慢与高低差，边缘连续渐隐 |
| 局部寒霜接触 | 实际受击位置的短促薄霜和少量细晶，融入这一片主雾 |
| 漂散尾雾 | 雾体外推后拉薄、分散，余下细丝逐渐淡尽 |

## 聚起、释放与接触

原冰枪在持续姿态下短促增强冷光，枪旁寒气聚起，主雾随即向记录范围释放。初段有明显推出的加速度，外层雾丝稍晚跟上；接触后速度降低，薄雾沿原方向翻卷、漂离。

同一段实际伤害的目标共用这一片主冰雾，覆盖取这份领域施放时记住的三格，兼容空位、换入单位和上下错排。局部接触只落在真实受击者处，空场地仍可被雾覆盖。

雾体前后有薄厚与高低变化，中心与边缘存在自然透视空隙；细雾错开聚散，避免一整块等密度蓝白面横移。范围改变主要调整分布与覆盖，局部雾丝和冰晶尺寸保持合理。

## 收尾与多份领域

接触后主雾逐渐变薄，外缘细丝继续短距离滑散，少量细晶最后淡去。冰枪回到原来的冷光和薄霜循环，下一次真实领域触发时再释放新一轮冰雾。

多份领域分别从各自枪体与记录范围触发，可以存在时间或空间上的交叠；保留真实触发次数，控制重叠雾层亮度。每次冰雾对应实际状态伤害的一次接触，装饰翻卷与细晶数量不增加命中。

二命只延长领域存续，增加期间按实际规则发生的触发；六命减物抗沿公共状态显示，保留同一套冰雾。
