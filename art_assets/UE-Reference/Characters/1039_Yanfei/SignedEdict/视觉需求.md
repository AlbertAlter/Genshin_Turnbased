# 烟绯 · 丹书立约

## 整体效果

参考原作丹书立约的法术纹样与烈焰，在实际相邻三人区域形成一次完整火焰接触。火光有明确起势、展开与收尾，橙红火体、金黄亮纹与较深暗面保留法术轮廓，具体造型制作时核对原作。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 起手法光 | 在施放者或原作相应位置聚起的短促暖色光纹 |
| 主法术纹样 | 原作式法印／律令火光的清楚轮廓，亮纹与暗部有层次 |
| 整组烈焰 | 覆盖实际三人范围的一轮火焰展开，主体和外缘可辨 |
| 局部火花 | 随同一次接触落在实际目标附近，尺寸与数量克制 |
| 收束余火 | 主体迅速拉薄，散火和细光稍后淡尽 |

## 起势、三人接触与补印

短促起势后，主法术纹样与烈焰快速展开，接触高潮覆盖本轮真实相邻目标。整组共用一轮法术主体，实际目标不足三人时收窄覆盖；扩大范围主要改变分布与边界，局部火星尺寸保持合理。

当前战技主伤害为一次接触，后续取得最大丹火印与能量沿实际结果衔接。丹火印只通过[卡底展示](../ScarletSealBottomStatus/视觉需求.md)更新，补满时更新为实际3枚或六命4枚，火光尾效保持连续。

## 收尾与增益

接触后纹样由亮变薄，主焰沿原方向分散，细碎余火最后收尽。技能等级与增伤沿公共显示，同一套主结构保持稳定。
