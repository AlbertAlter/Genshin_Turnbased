# 烟绯 · 凭此结契施放

## 整体效果

参考原作凭此结契的法术纹样和烈火展开，对实际敌方全体形成一次完整爆发。主体覆盖本轮全体范围，保持烟绯特有的印纹与法术识别点，主亮部集中于纹样和接触，卡面仍然清楚。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 爆发聚光 | 短促收紧的暖金、橙红法光，建立主纹样和展开方向 |
| 原作法术纹样 | 与普通火团区分的印纹和清楚轮廓，细部对照原作 |
| 全体烈焰 | 一轮覆盖实际敌人范围的完整爆发，中心、主体与外缘有层次 |
| 接触火片 | 同轮爆发在实际目标处的局部火花与短促火片 |
| 收尾余辉 | 纹样先变薄，主焰与余火随后收尽，衔接自身持续状态 |

## 一次全体接触

起势法光聚起后，烈焰迅速展开，整组实际敌人在同一个主要接触中响应。按本轮真实卡位的合并范围组织覆盖，兼容一至五人、上下错排与不连续位置，各目标只补局部接触。

主爆发只播放一轮，尾焰继续散去时保持同一演出。当前一段全体伤害完成后，真实丹火印补满与[灼灼](../BrillianceState/视觉需求.md)建立自然衔接；两者分别承担计数提示与持续气息。

## 四命护盾与其余增益

四命实际获得的火元素护盾沿用公共护盾建立、维持、受击与退出，以火元素色与真实盾值显示。护盾与灼灼、丹火印卡底图标共存，保留各自生命周期；不额外重播本次爆发。

三命、五命等级和其他数值变化沿公共显示。丹火印按实际补满至3枚或六命4枚，主爆发保持同一结构。

## 本次实际参考观察

2026-11-28在内存完整解码了上方凭此结契动图，47帧、1.88秒，查看覆盖全过程的24张时间抽帧，原GIF未保存。可见暖光聚起后，约0.56～0.88秒出现一轮环状烈火和纵向暖金法术文字，余火随后退落。人物周围原作丹火印不复制到本项目卡面，其数量继续只在卡底显示。本段没有完整覆盖灼灼自然到期，不能据此确认退出动作。

源工程采用自行制作的折线律令纹、火焰薄片与体积火球，没有提取或精确复制原作模型／纹理。程序化火焰的流动和侵蚀在Blender材质中，独立FBX只保留复用几何与RGBA，尚需后续正式材质适配。
