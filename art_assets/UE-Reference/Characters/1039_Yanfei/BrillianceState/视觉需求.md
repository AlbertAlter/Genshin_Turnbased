# 烟绯 · 灼灼持续状态

## 整体效果

爆发后在烟绯自身卡牌附近维持克制的暖金／火色气息，参考原作灼灼的法术气质，形成起手建立、持续循环和消失三阶段。主体围绕卡后与边缘，保留卡面、生命数字和卡底丹火印的可读性。

灼灼与丹火印分别展示：灼灼提示自身仍处于强化，丹火印数量只由[卡底图标](../ScarletSealBottomStatus/视觉需求.md)及右下数字承担。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 起手暖光 | 从爆发余辉收束到自身的短暖光，逐渐建立持续轮廓 |
| 法术气息 | 参考原作的暖金纹光与轻薄火色气息，具体符形制作时核对 |
| 细碎火光 | 少量错开漂移的光屑，沿卡后、边缘缓慢流动 |
| 退出余辉 | 主气息变薄，光屑沿原方向漂离，最后淡尽 |

## 起手、循环与退出

起手承接凭此结契的余辉，自身暖光逐渐收束，气息与少量细光错开出现，进入连续循环。持续时各条纹光、薄火和细屑具有不同相位与平滑速度变化，亮度与密度稳定。

实际取得丹火印时由卡底数字更新，灼灼继续当前循环相位。重击只短暂叠加单次攻击，随后回到持续亮度；普通数值变化与回合计数清零保持展示连续。

状态真实结束后，气息先松散、拉薄，细碎火光稍后收尽。当前项目切换后台后灼灼仍有效，展示依实际宿主和可见卡牌维持，不因换人提前结束真实状态。

## AP与天赋命座

实际AP累计和每20AP取得丹火印沿现有业务处理，在行动及其后续或换人结清后更新图标，持续光效不模拟产印周期，也不以光粒子数量表示AP。

天赋增伤、一命减AP、二命暴击及等级变化沿公共显示。四命护盾使用公共火盾，六命只让丹火印支持第四枚，三种展示彼此独立。
