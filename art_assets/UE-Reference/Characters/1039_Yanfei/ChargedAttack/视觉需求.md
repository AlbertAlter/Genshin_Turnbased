# 烟绯 · 重击烈焰法印

## 整体效果

参考原作重击召唤烈焰法印的形态，在本次相邻三名敌人的范围上方形成一枚完整法印，随加速下落压向目标区域，落点展开清楚的印纹、火焰与一次接触。法印有可辨造型、体积和橙红／金黄层次。

同一段群体重击共用这一枚主法印与一片落印火光，实际三人只补局部接触。范围按真实目标合并边界调整，保持一轮完整下压的观感。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 凝形法印 | 原作式印体与纹样，轮廓、受光面和暗面分开 |
| 下压主体 | 一枚完整法印的加速下落，方向、重心和尾焰一致 |
| 落印火纹 | 随同一次接触向真实范围展开，轮廓清楚，尾部逐渐变薄 |
| 接触火花 | 目标处短促火片与火星，受力方向与下压一致 |
| 尾效余火 | 印体接触后消散，少量余火随火纹依次收尽 |

## 丹火印与力量感

起手按本次真实消耗的丹火印数量衔接，0～4枚共用同一套主法印。消耗越多，可适度强化轮廓完整度、亮边、火光层次与接触冲量，保持实际命中次数和三人范围一致。六命第四枚只增加已有层级的表现能力，不额外落下第四枚攻击印章。

落印前短促蓄势，下落明显加速，接触一刻主印与火纹最完整，随后有清楚收势。重击消费完成后，卡底丹火印数字随真实计数更新；余火按本次已消费数量保持连贯，不在计数清零后丢掉这次攻击的视觉层级。

## 真实范围与追加攻击

上下错排、目标不足三人时，按本轮真实目标合并范围展开落印。主法印保持合理体量，覆盖主要由印纹与火焰分布调整，各目标接触沿同一段实际hit组织。

[法兽灼眼](../BlazingEye/视觉需求.md)实际触发时，在重击接触之后衔接一次独立火焰闪爆；主落印已经完成，追加效果保持自己的接触。
