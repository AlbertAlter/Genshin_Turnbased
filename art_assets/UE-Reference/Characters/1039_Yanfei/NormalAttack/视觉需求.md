# 烟绯 · 普攻火球

## 整体效果

从烟绯实际发射位置送出一枚原作式火球，带橙红火体、较亮火芯与短促尾焰，抵达本次单体目标后形成一次清楚接触，随后消散。保留烟绯的法术气质，火球轮廓与火纹制作时对照原作。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 起手聚火 | 在施放者附近短促聚起火光，向本次攻击方向收束 |
| 火球主体 | 可辨的橙红火体、明亮内核和流动外焰，亮度有层次 |
| 飞行尾迹 | 紧跟弹体，端部渐薄，细火星错开脱离 |
| 命中火光 | 目标处短促绽开的局部火花与薄火片，规模克制 |
| 消散余火 | 主火体接触后收尽，细碎余火稍后淡去 |

## 发射、飞行与接触

起手聚光后火球加速离开发射点，沿[公共弹道需求](../../../../../codex_files/UI/公共弹道需求.md)的可控起终点与平滑弯曲运动飞向实际目标。尾迹方向、火球朝向与路径一致，接触附近主火体最清楚，随后快速碎散。

当前普攻为单体一段，主体一枚火球与一次接触相配。尾焰、火星的数量不增加命中。实际命中后获得的丹火印由[卡底图标](../ScarletSealBottomStatus/视觉需求.md)与右下数字更新，不在自身卡牌周围生成悬浮印记。
