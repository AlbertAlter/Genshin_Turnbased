# 草丘丘萨满 · 草元素领域

## 整体观感

在我方整片场地建立一片持续的黄绿色草元素区域。主要识别点是低处通透的草绿色气息、柔和的黄绿亮部和错落漂动的小叶片，参考原作草萨满领域的地表颜色与飘叶。整体轻薄、缓慢而有生长感，保持卡面、血条和卡底图标清楚可读，不形成遮住整队的绿色浓雾或高墙。

领域和荆棘是两个不同的视觉对象：荆棘使用单独的卡底彩色图标；本项领域不再在每张卡牌周围长出实体藤墙，不把录像中同时存在的荆棘误当成领域组成部分。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 地表草元素气息 | 一片浅绿至黄绿的半透明低层气息，整体连贯、局部深浅不一，边缘连续渐隐，不是一块均匀绿色矩形或实心圆盘 |
| 区域内的细流与微光 | 稀疏、细小的黄绿流动亮部，在低处缓缓舒展并淡去，提示领域仍然存在，不画复杂法阵或不断爆亮的冲击环 |
| 漂动叶片 | 少量可辨的小叶片，浅黄绿亮面与较深绿色背面相间，缓慢卷起、翻转、漂散，尺寸、相位和寿命错开，不排成整齐圆环 |
| 退出余光 | 领域主体退去后留下极少量变淡的叶片与细亮点，接着全部散尽，不留下实体植物 |

地表区域负责说明范围，叶片负责识别草元素与运动。放大覆盖范围时主要改变区域分布和叶片疏密，叶片本身仍保持小巧。

## 起手出现

在实际受影响的我方场地内先浮起较淡的绿色气息，再向整片区域舒展开，少量黄绿叶片随后错落卷起。范围建立有短暂的由弱到强过程，完成后回落到克制的持续亮度，不突然打开一整片不透明色块。

使用当前战斗视角表达领域建立，不额外加入草萨满人物模型、挥杖动作或镜头特写；不从施放者身上飞出一群叶子轰击我方。

## 持续循环

领域主体一直可读，低层气息缓慢流动，明暗轻微呼吸，小叶片各自漂动、翻转并淡去，再由其他位置自然补入。循环首尾衔接，不每轮重新扩张一次整个领域，不逐轮增加绿色浓度、亮度或叶片数量。

草元素施加发生时，区域内可以短促、柔和地变亮一次，少量已有叶片随之提亮，再回到原来的持续节奏。这里表现的是元素领域，不增加砸击、爆炸、武器刀光或伤害冲击，也不为热闹而在空闲循环中反复制造攻击高潮。

## 消失收尾

从当前循环相位直接退出：先停止补入新的叶片和细流，低层气息逐渐变薄，范围边缘随之散开并退去；已有叶片继续沿原方向漂动、淡出，最后少量余光收完。不要整块突然切掉，也不要把全部叶片吸成一个中心光球再爆炸。

起手、维持和消失组成完整持续效果。元素施加、数值刷新或同一领域继续存在时不重新播放起手。

## 场地空间与层次

领域以我方实际场地的整体边界组织成一片，兼容四张卡牌上下错排；不把每张卡各做一套互相重叠的同等大小圆形领域。范围依场地而存在，空卡位仍属于该区域，不因一个单位离开就只剩几张卡底的小光圈。

低层气息和主要亮部处于卡后、背景地面附近，不把“地表”理解为屏幕底边。少量叶片可以经过卡前，其余被卡牌自然遮住，不能所有叶片永远盖在整队上方。领域保持自身的范围与中心，不环绕草萨满，也不随单个角色移动。
