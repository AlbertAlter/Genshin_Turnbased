# 爆弹丘丘人 · 投掷火史莱姆

## 整体观感

直接从爆弹丘丘人卡牌附近抛出一只小型火史莱姆，沿自然抛物线飞向本次目标区域。保留原作圆鼓、略有弹性的史莱姆躯体和眼睛；点燃时为明亮的橙红色，带少量火苗，熄火时躯体暗下来，仍能辨认是同一只史莱姆。

**不制作待投掷动作。** 不展示挖掘、点火、举持、原地蓄势或等待中的史莱姆；效果从史莱姆实际飞出开始。点燃分支命中时接已有公共爆炸，熄火分支使用明显较弱的物理爆散。

## 视觉部件

| 部件 | 视觉要求 |
|---|---|
| 火史莱姆实体 | 一只小型圆鼓凝胶躯体，眼睛和轮廓可辨，轻微形变与翻转体现柔软体积，不替换成普通炸弹或纯火球 |
| 点燃表面与飞行火星 | 橙红躯体带较亮的黄橙局部与少量贴体火苗，火星沿已走过的弧线短暂脱离、熄灭，不形成粗长火柱 |
| 熄火外观与短迹 | 同一躯体减弱亮度，表面不再维持燃烧火苗；飞行只留很轻的短迹，不包裹新的水、冰或雷特效 |
| 点燃命中爆炸 | 沿用已有公共轻量爆炸的亮核、翻卷火团、火星和短暂余烟，中心与史莱姆接触位置一致 |
| 熄火命中爆散 | 躯体在接触处散成少量暗橙褐碎片，配克制的灰白冲击、尘点和轻烟；亮度、范围与余势明显弱于点燃分支，不出现大型火团 |

点燃与熄火共享可辨的史莱姆形体、投掷路线和接触节奏，以表面燃烧及末端爆散的区别表达当前结果。

## 直接投出与抛物线

史莱姆从施放者卡牌前侧附近直接飞出，上抛时竖直速度逐渐减慢，到达顶点后加速下落，水平位移与竖直起落共同形成一次自然抛物线。躯体可以轻微拉伸、压缩和翻转，但保持史莱姆轮廓，不反复弹跳，不在半空停下来等待。

点燃时火苗与稀疏火星向运动后方拖曳，随弧线方向变化；熄火时去掉持续燃烧外观，不能为了填满画面再补一条同等明亮的火尾。两种分支都只有一只史莱姆从源位置飞到本次实际落点，中途不瞬移、不分裂成多个弹体。

## 点燃命中与公共爆炸

到达本次目标区域时，史莱姆与接触亮部同时衔接到已有公共轻量爆炸。爆炸围绕相邻目标的整体区域展开，形成一次共同的冲击；不是向两张卡牌各投一只史莱姆，也不是逐卡重复两次爆炸。只有一个实际目标时，效果自然收在该目标附近。

史莱姆完整躯体在接触爆炸中结束，不能等火光散去后仍看到完整模型。爆炸后火星与轻烟收完，不留下持续火场，不再次落地引爆，也不因装饰火星触碰别的卡牌而追加一次爆炸。

## 熄火命中与收尾

熄火分支从投出时就使用暗下来的史莱姆外观，落点与飞行方式沿用同一次投掷。接触时只做一次较弱的物理爆散，碎片短促外散并下落，尘点与轻烟很快散尽，不接点燃分支的公共火焰爆炸。

无论哪一种分支，接触都结束完整史莱姆实体；没有落地等待、自主跳动或延迟第二次爆炸。原作录像中的挖掘、举持、点火、受击掉落和现场元素攻击只作参考背景，不纳入本项目这项投掷效果。
