# 冰丘丘萨满：单根破屏冰刺

按用户要求，在实际目标卡面对应的屏幕平面上，快速长出**一根主冰刺**。根部留在该平面，尖端沿屏幕法线朝观察者伸出，形成从屏幕里刺出的纵深感；不是从画面下边缘向上升，也不是从屏幕上方落下。冰刺保留少量斜向棱面，让正面视角仍能辨认尖端、长度和体积。

## 视觉部件

| 部件 | 造型与运动 |
|---|---|
| 主冰刺 | 根部较粗、向尖端收细的不规则冰晶，半透明浅冰蓝主体、蓝白亮棱和少量内部裂纹；只有一根清楚的主体，不做成一簇地刺或冰花 |
| 根部结冰与破出 | 目标位置先出现短促冷光与一小片结霜，紧接着根部破出少量碎冰；范围围绕单体接触点，不铺成群体冲击波 |
| 命中冷光 | 冰刺快速长出的高潮出现一次紧实蓝白接触闪光，向外散开少量细冰片与薄寒雾；不以整张卡白闪掩盖主冰刺 |
| 碎冰收尾 | 主体短暂可读后裂开，碎片沿外侧略微散出并下坠、变淡，寒雾随后散尽；不让完整冰刺长期挡住卡面 |

## 完整过程

先在目标位置凝起克制的霜光，主冰刺由根到尖快速生长，根部始终固定，避免整根成品从远处滑入。长出的冲击与命中冷光同时达到高潮，随后主体碎裂、薄雾收完。装饰碎冰不形成第二根主刺，也不追加第二次打击。

冰刺只在这次实际单体目标处出现，适配真实卡位和尺寸。主体可以短暂遮住卡绘局部，但不长期盖住人物、血条或状态栏。后续冻结地面沿用[公共冰元素地面](../../../general/ElementalGround/视觉需求.md)，放在卡牌后方持续；主冰刺收尾不撤去仍有效的地面，地面的周期触发也不重长一根大冰刺。
