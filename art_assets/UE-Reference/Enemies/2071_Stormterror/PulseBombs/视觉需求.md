# 风魔龙 · 风弹齐射

## 更大的原作脉冲风弹

按用户要求参考[原作Pulse Bombs](https://genshin-impact.fandom.com/wiki/File:Dvalin_Pulse_Bombs.gif)制作较大的风弹。主体应有清楚的球形／团状能量轮廓、内部旋动和包裹流线，保留原片的明暗与颜色关系，不简单用一颗细小通用风球放大发光来替代主体。

已核对原片的[发射前](../References/PulseBombs_01600ms.png)、[飞行远景](../References/PulseBombs_03200ms.png)和[弹体近景](../References/PulseBombs_04800ms.png)静帧。主体为青蓝聚亮核心，内有短同心亮环，外侧白青色弯弧旋流包着半透明蓝色弹体，具有明显体积。静帧只证明相应造型，连续运动仍对照在线动图。

风弹的可见体量明显大于前面风史莱姆的小风弹，在正常战斗画幅仍能看清主体与旋流。尺寸与覆盖范围分别处理：风弹自身保持清楚体量，接触扩散按真实三个相邻目标的位置组织，不随卡距拉长成一根粗管。

| 部件 | 视觉职责 |
|---|---|
| 风弹主体 | 原作脉冲弹的聚亮核心、外层半透明流动与明确轮廓；飞行中有自身旋动 |
| 发射短光 | 在施放者实际卡牌附近短促聚亮，衔接弹体离开，不盖住自身整张卡 |
| 飞行拖尾 | 跟随实际路径，近端集中、远端变细变淡，朝向与弹体运动一致 |
| 接触风爆 | 主体抵达后一次撑散成风压与碎流，覆盖该枚弹体的真实受击区域，各目标补局部接触 |

项目只发射两枚，每枚各有一次三目标范围接触。两枚沿实际发射和命中顺序组织，目标组可能不同，不能预先写死为同一处。原作演示中的成对弹体与演出数量仅作造型参考，不据此把项目两枚改成四枚或增加hit。

两枚均从实际施放者发出，终点取各自真实目标范围；飞行后接触，尾迹自然收完，不残留持续风场。
