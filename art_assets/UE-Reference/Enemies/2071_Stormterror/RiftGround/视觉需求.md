# 风魔龙 · 终天闭幕曲与风涌裂隙

## 原作特殊裂隙地面

按用户要求参考[原作Caelestinum Finale Termini](https://genshin-impact.fandom.com/wiki/File:Dvalin_Caelestinum_Finale_Termini.gif)制作特殊裂隙地面。保留原作被侵蚀平台的裂纹布局、裂缝内的能量亮部与向上逸散的细流；颜色和纹理以原片为准，不把现有冰、雷等地面简单换成风元素色。

已核对[起势](../References/RiftGround_06000ms.png)、[侵蚀落地](../References/RiftGround_12000ms.png)与[裂隙地面](../References/RiftGround_15000ms.png)静帧。裂缝呈清楚的蓝白发光分叉，宽窄变化较大，地表有薄蓝能量和局部向上逸流；保留原平台的裂纹质感，背景主体仍然可见。静帧不作为完整运动验收。

沿用[公共元素地面](../../../general/ElementalGround/视觉需求.md)的整片地面组织方式。所有卡牌后方是一片连续的裂隙纹理和动态流动，按实际有状态的位置显露；相邻区域的裂纹、光流能接上，重叠不叠亮。地面覆盖与裂纹粗细、流光数量分开调，正常战斗画幅仍看得出裂隙结构。

| 部件 | 视觉职责 |
|---|---|
| 初次侵蚀铺展 | 原作能量落向地面的气势适配成一轮区域建立，裂纹从浅到清楚地蔓开，最后进入稳定地面 |
| 裂隙主体 | 不规则分叉裂缝，有主次宽度、断续亮边与透明留白，表现地面裂开而非铺满发光色块 |
| 裂缝能量 | 沿裂缝缓慢流动、轻微明暗起伏，有克制的向上逸流；持续阶段首尾连贯 |
| 周期接触 | 只在本次实际受击位置短促涌出风流与局部亮部，随后恢复持续状态 |
| 撤去余光 | 停止补入流动，裂缝光逐渐收暗、细流散尽，从任意循环相位都能自然退出 |

## 施放、维持与触发

出现时建立本轮实际场地区域，不重做平台、战斗背景或我方卡位。中段可任意延长，层数刷新与周期伤害不重播起手，不逐回合叠出第二层地面。

施放阶段只表示裂隙建立，项目没有这一刻的直接伤害；原作落向平台的能量雨不额外制造伤害命中。后续伤害每次只补本次实际目标的短接触，不再次铺开全场裂纹。层数提高时维持可读的地面，不随着数值无限叠亮或扩大到界面外。

场地暂时无人时，实际裂隙仍在则地面继续存在；换人不重铺。隐藏辅助结算状态共享这一片地面，不再产生第二套裂纹。状态范围减少只撤去对应区域，其余区域继续原循环。
