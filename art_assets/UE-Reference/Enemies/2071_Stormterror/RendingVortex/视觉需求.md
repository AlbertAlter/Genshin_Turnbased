# 风魔龙 · 巨型风弹

## 公共蓄力与原作巨型风弹

按用户要求，蓄力阶段沿用公共蓄力的向卡面中心收束动线，持续期间保持，释放时结束聚能，被破盾打断时自然消散。本项不另做一套风魔龙专用蓄力循环。

释放参考[原作Omega Bomb／Rending Vortex](https://genshin-impact.fandom.com/wiki/File:Dvalin_Omega_Bomb.gif)。已核对[聚能远景](../References/RendingVortex_03600ms.png)、[弹体与旋流](../References/RendingVortex_05600ms.png)和[爆开](../References/RendingVortex_07200ms.png)静帧，保留青蓝能量核、白青弯月状绕流、外层深蓝透明包裹和少量片状碎光；连续运动与衔接仍参考在线动图。

巨型风弹从施放者实际卡牌附近推出，带清楚的核心、厚实旋动外层和包裹流线；可见体量和力量感大于风弹齐射，同时仍保留主体明暗与流动细节。

| 部件 | 视觉职责 |
|---|---|
| 巨型弹体 | 以原作巨型风弹的颜色、核心和外围旋流为准，具有自身旋动和清楚体积，避免只有巨大模糊光团 |
| 离手风流 | 蓄力收束结束后，聚起的能量顺势形成弹体离开，施放者附近风流快速收窄散去 |
| 飞行尾迹 | 顺实际施放者到目标区域的路径拖出，主体与尾迹速度一致，端部渐隐 |
| 群体接触与风压 | 抵达真实全体范围后一次爆开，外层风压先清楚展开，目标各补局部风流与碎光 |
| 收尾余流 | 大弹体消失后，风压和尾迹按方向散尽，恢复原战斗画面 |

当前是一次全体命中，多张卡共用一枚主弹体及一次整体爆开。按实际全体卡位的合并范围调整接触覆盖，不逐卡各放一枚巨型弹，也不从可见旋流圈数推算额外伤害。

本次不复制原作完整飞走、重新出现等龙体表演；施放者使用公共卡牌动作，发射位置和目标范围沿真实战斗布局。公共蓄力的正式播放接线与本项新弹体播放分别记录，不能以现有网页蓄力示意冒充已接Unity。
