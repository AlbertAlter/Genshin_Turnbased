# 风魔龙 · 低空掠袭

## 冲锋与横向划痕

按用户要求，沿用[公共向右冲出与回场动作](../../../general/CardRushThrough/视觉需求.md)。施放者整张卡牌向右快速冲锋，穿过本次实际单体目标附近后继续出屏，再从自己原卡位左侧快速淡入归位。移动在屏幕平面内，目标位置与上下错排由实际卡位决定。

只在本次实际受击目标处出现一道横向划痕。划痕有锐利、稍亮的前沿，主体快速横拉，尾端变细、渐隐；接触时辅以少量短促的物理撞击亮部与碎屑，整体读作卡牌冲过时掠中目标。未选中的沿途卡牌正常保留，不增加受击。

| 部件 | 视觉职责 |
|---|---|
| 整卡冲锋 | 卡绘、卡框共同移动，保持清楚的向右冲势；回场只归位 |
| 横向主划痕 | 在目标附近完成一次短促横划，首尾柔化，具有前沿与尾迹变化 |
| 局部撞击 | 对应这一次真实命中，轻碎屑迅速散去；受击与跳字跟随接触 |

一次冲锋只表现一次单体物理命中，划痕、速度线与回场均不增加攻击次数。主体归位后恢复原姿态与透明度，附属速度线收尽，不改原始卡位布局。
