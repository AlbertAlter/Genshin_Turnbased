# 风魔龙 · 撕咬横扫

## 冲锋与一轮全体横向划痕

按用户“与技能1差不多”的要求，与[低空掠袭](../FlyBy/视觉需求.md)共用冲锋及横向划痕构成，沿用[公共向右冲出与回场](../../../general/CardRushThrough/视觉需求.md)。此招覆盖当前实际全体目标，按其卡位组织冲锋路线与横扫范围，回场不重复攻击。

主划痕是一轮连续横扫，范围随本次目标的合并边界调整；主体首尾收细、尾部渐隐，保留明显的横向速度。各受击卡只补本次接触附近的短碎屑和撞击亮部，不逐卡复制一套完整大横扫。

| 部件 | 视觉职责 |
|---|---|
| 整卡冲锋 | 与技能1共用移动与回场，扩大实际经过的目标范围 |
| 连续横扫划痕 | 沿同一挥扫方向展开，照顾上下错排目标，保持一次完整横扫轮廓 |
| 逐目标局部接触 | 对应本轮每个实际受击目标，和自身受击／跳字衔接，空位不补虚构接触 |

本招是一轮全体物理命中，覆盖人数与可见划痕长度不增加攻击段数。接触组织服从同一轮实际命中的目标身份，结束后划痕、碎屑与速度线一起收完。
