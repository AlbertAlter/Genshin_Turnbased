# 深渊使徒：水之新生

参考原作Dark Descent的力量聚起、周身水色爆发与新生护盾状态。起势围绕真实使徒卡牌聚起较深蓝水光，正式开启时向实际我方范围释放一轮宽阔水色冲击，卡面附近保留更紧实的护盾／水光包裹，随后回落到清楚可辨的持续状态。

视觉部件为聚起的深蓝能量、开盾主水浪与亮边、护盾状态表层、水丝和少量余珠。主爆发有一次明确高潮，群体各卡补局部接触；持续部分靠卡牌边缘的水流纹理和克制微光表达，保留人物中心、盾条与文字，不重复开启爆发。

护盾稳定后沿真实状态维持，续时或盾量变化不反复起手。真正破盾时按该次真实破盾与死亡顺序衔接短水裂、退场，碎散与死亡各有自己的尾效，不能因为状态正常清理而再发动一次全体水爆。

冻结冰层、实际冻结缩短与解冻保护沿原独立系统显示，本项只负责水之新生外观，不额外改变冰层时间或生成新的冻结抵抗状态。
