# 丘丘岩盔王 · 强化拳击岩爆

## 拳击与追加岩爆

技能1保留两次单体拳击的接触。强化状态下，**每一拳实际命中后，紧接一次岩元素爆发**，从该拳命中的目标位置向周围短促炸开，覆盖这次追加伤害的目标及实际相邻位置。

动作层次为“第一拳接触 → 第一轮岩爆 → 第二拳接触 → 第二轮岩爆”。两次拳击与两次追加岩爆各有清楚的接触重点，不把两轮岩爆合成最后一次大爆炸，也不在同一轮的每张邻位卡牌上各复制一团完整爆炸。

## 岩爆的视觉部件

| 部件 | 造型与运动 |
|---|---|
| 岩金爆发亮部 | 拳击落点附近的一小团暖金、琥珀色亮部，短促向外撑开，中心明亮但不长时间过曝 |
| 贴地岩光 | 从同一中心向左右实际受影响区域推出的短岩光，带不规则折线与棱面感，边缘快速收淡 |
| 岩屑与尘土 | 少量棕黄岩屑随爆发外散，轻薄尘土稍后散开消退，保持目标卡绘与数字可读 |

爆发主体在目标卡后地面层展开，接触点可有少量短促亮部与碎屑经过卡前，血条、盾条和文字保持清楚。范围按每拳实际落点与追加目标组织，不能始终固定在岩盔王自己脚下。

## 结束与复用

每次岩爆迅速衰减、岩屑散尽，形成短而有力的一次追加接触。未强化时保留正常拳击；不额外显示这轮岩爆。动画只消费实际已发生的追加效果，不用视觉上的命中自行增加伤害。

原作造型参考入口为[拳击原作动图](https://genshin-impact.fandom.com/wiki/File:Geo_Lawachurl_Punches.gif)，链接与核对边界统一记在[岩爆冲击参考来源](../GroundRupture/References/sources.json)。本项目两拳各接一次邻位岩爆的节奏，以当前设计为准。

通用要求见[特效制作规范](../../../../../codex_files/UI/特效制作规范.md)。原生素材已制作，尚未接线。
