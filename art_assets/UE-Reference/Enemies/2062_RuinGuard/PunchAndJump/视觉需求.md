# 遗迹守卫 · 拳击跳砸

## 顺序与范围

按技能描述，先对同一实际目标做两次拳击接触，之后才进行一次范围跳砸。前两次是先轻后重的物理击打，使用短促旋转扫击光、少量浅褐尘屑，不增加遗迹守卫人物模型。第二拳收势后衔接落下，不能把三次伤害同时混成一个爆炸。

跳砸沿用[冰史莱姆公共卡牌下落重砸](../../2023_LargeCryoSlime/JumpingSlam/视觉需求.md)：卡牌在原位消失，从实际目标的**屏幕内上方**出现并落下，配合下落伸展、触地压缩与恢复，再回原卡位。不是朝镜头深处砸入，也不补一段可见的起跳飞行。

落下前，目标底部的柔软阴影逐渐加深、收紧；接触时展开一次尘土与冲击，覆盖主目标及本次实际相邻目标。落点以主目标为中心，范围由真实目标卡位展开，不因两拳只有单体而把最后一次也做成单体。

## 视觉部件

| 部件 | 外观与运动 |
|---|---|
| 两次拳击接触 | 两道短促、有前后差别的灰白扫击弧与浅褐碎屑，保持物理质感，不染元素色 |
| 下落卡牌 | 完整边框及卡绘一同下落，保持朝向观众，落地后恢复原姿态 |
| 落点阴影 | 软边椭圆，落下前加深收紧，触地后扩散淡出 |
| 范围落地冲击 | 主目标处较重的尘土与碎屑，低矮冲击向实际相邻卡位展开，一次清楚的共同接触 |

两拳、范围落地各有自己的接触时点，范围中多名受击者不重复播放多次完整下砸。最后余尘收完，不留下常驻地裂。

原作入口：[能力页](https://genshin-impact.fandom.com/wiki/Ruin_Guard#Abilities)、[拳击跳砸动图](https://genshin-impact.fandom.com/wiki/File:Ruin_Guard_Punch_and_Jump_Combo.gif)。本轮确认条目与媒体地址，未下载或播放动图；卡牌动作使用项目既有重砸适配。来源见[记录](../References/sources.json)。原生模型已制作，尚未接线。通用规则见[特效制作规范](../../../../../codex_files/UI/特效制作规范.md)。
