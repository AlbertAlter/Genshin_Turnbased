# 遗迹守卫 · 六枚制导飞弹

## 飞弹主体

单独制作可复用的遗迹机械导弹模型：深褐、灰铜的短粗机械外壳，清楚的弹头、分段弹身与少量稳定翼，尾部是暖橙黄色喷焰。外壳保留硬朗体积，正常画幅下能够辨认飞弹，不以一个火球或纯发光点代替。

沿原作背部发射飞弹的识别特征，在实际施法卡牌上部附近使用明确的发射点。卡面保持原卡位，不临时画出一整台背部发射架。

## 视觉部件

| 部件 | 外观与运动 |
|---|---|
| 导弹模型 | 暗色机械主体、分段外壳与稳定翼，连续跟随飞行方向转向 |
| 发射短光 | 每发离开发射点时一次短促暖光与少量烟气，之后转入尾焰 |
| 尾焰及尾烟 | 亮芯、橙黄外焰与薄灰烟分层；尾烟沿已走过的轨迹渐淡，不画成僵直粗线 |
| 命中爆裂 | 目标处短促橙黄冲击、机械碎片及少量烟尘，外扩后快速消退；表现物理弹体，不额外赋予火元素 |

## 六发与公共弹道

六枚飞弹按本次实际逐发结果依次发射，每发抵达各自真实目标；同一目标可以连续被多发选中。不要为了均匀好看而改成全体均分，也不在视觉中另抽一次目标。

飞行使用[公共弧线弹道需求](../../../../../codex_files/UI/公共弹道需求.md)：发射后适度散开，再沿平滑弧线抵达对应终点，允许各发弧度略有区别；模型朝向、尾焰和尾烟跟随同一条路径。不是六条生硬直线，也不加不必要的大圈盘旋。发射与接触服从本次既定节奏，不能因随机曲线较长而延误真实命中。

每枚只有一次实际接触，六发不是单次命中外加五枚纯装饰，也不拆成六次完整蓄力。最后一发的碎片、烟尘收完后结束，不留持续火地面。

原作入口：[能力页](https://genshin-impact.fandom.com/wiki/Ruin_Guard#Abilities)、[飞弹动图](https://genshin-impact.fandom.com/wiki/File:Ruin_Guard_Missiles.gif)。本轮确认媒体地址，未下载或播放完整动图；模型细节制作时仍需查看原作画面，本文不把文字概述当作逐帧造型确认。来源见[记录](../References/sources.json)。原生模型已制作，公共弹道实现方式仍沿既有需求，尚未接线。通用规则见[特效制作规范](../../../../../codex_files/UI/特效制作规范.md)。
