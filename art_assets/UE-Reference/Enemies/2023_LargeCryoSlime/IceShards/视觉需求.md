# 大型冰史莱姆 · 冰片连射

## 整体观感

从大型冰史莱姆卡牌前侧射出一轮蓝白冰片，分向本次相邻的三个目标。冰片以尖锐、薄而有厚度的晶片为主体，冰蓝透明面、较亮的白色棱边与少量细碎晶屑共同形成寒冷、利落的观感。

本项是一轮覆盖多个目标的攻击，三路冰片在同一次发射中展开并共同接触；名称中的“连射”不表现为对每人反复追加多轮攻击。

## 视觉部件

| 部件 | 造型与运动 |
|---|---|
| 发射冷光 | 施放者卡牌前侧短促聚起蓝白亮部与少量细晶，随冰片射出收束 |
| 冰片主体 | 有明确尖端和晶面的细长冰片，轮廓锐利，厚薄有变化，中央较透、棱边较亮 |
| 飞行短迹 | 窄长、迅速变淡的蓝白冰光，少量细晶沿路径短暂脱落 |
| 接触碎晶与薄霜 | 目标处冰片碎开，碎晶短促外散，配很薄的冷雾和霜光，随后散尽 |

## 范围与运动

三路冰片从同一个施放者出发，呈略微展开的扇形，各自对准实际目标卡牌。路线随目标上下错排调整，飞行轨迹与冰片朝向保持一致。不同路程的视觉节奏配合成同一轮接触，先看清锐利冰片，再看到碎裂和余雾。

接触时各目标附近分别出现小范围碎晶与冷光。晶片大小和方向略有差异，外散后快速淡去，避免同一贴片机械复制。余雾轻薄，保持卡面、盾条和说明可读。
