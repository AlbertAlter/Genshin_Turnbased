# 古岩龙蜥：爪击与回旋刀光

按用户要求，技能2爪击、技能4回旋只配对应命中刀光与局部接触，不另制作爪体、尾巴模型或完整龙体表演。刀光为有硬朗棱面感的岩色弧面、短亮刃缘及少量细岩屑，主体半透明，尾部连续收窄。

爪击保留同一真实单体的两次接触，两次刃光有方向与长度变化，前次快速收势后接下一次；不把一次爪刃中的多根亮线当成多hit。回旋是一道覆盖实际全体合并范围的主扫弧，各目标补局部接触，不逐卡复制整套回旋。

岩屑随接触外散、下落并淡去，刀光余辉更早收弱。范围服从当次实际目标，保留卡绘与信息栏；不因古岩龙蜥当前火水雷冰形态而把这些仍为岩伤的刀光自动换成附魔元素。
