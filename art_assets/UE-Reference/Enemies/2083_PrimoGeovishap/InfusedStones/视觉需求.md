# 古岩龙蜥：元素灌注岩石

技能1参考原作四种灌注岩石各自的爆发形态。共同起势为带岩石棱面和对应元素纹路的小型岩核，在该次实际目标区域短促聚亮后释放；火、水、冰、雷分别制作末端效果，不用一套同形圆爆简单换色代替。

| 变体 | 主要造型、运动与接触 |
|---|---|
| 火 | 一次较紧实的火焰爆开，局部岩壳碎片和火星外散；落点衔接暗红熔岩纹、流动热光和轻余烬，持续部分沿公共火地面组织 |
| 水 | 接触位置短促涌起的小型水柱、溅水与泡沫，连续七次喷发，各自位于这一轮实际目标，不补成每处七次 |
| 冰 | 从合并范围中心向外推进的冰晶环脊，短尖晶由内向外生出、裂开，三轮接触清楚，最后一轮更重 |
| 雷 | 原作X形向外爆开的电流分支与紫色亮边，沿真实相邻范围组织三轮，分叉和余电渐隐，不以电弧数量增加命中 |

视觉部件保留岩核／岩壳、各元素主爆发、局部接触、余粒。共同范围位于卡后地面层，少量水花、冰屑或电光可短促经过卡前，卡绘和信息栏清楚。范围大小和碎屑／水滴粒径分别控制，不靠放大整组粒子填满目标。

火版的持续熔岩区沿[公共元素地面](../../../general/ElementalGround/视觉需求.md)按真实状态维持，主爆炸结束后不撤去仍有效地面。水版七次、冰版三次、雷版三次均服从项目真实接触，不导入原作额外等待、随机位置或隐藏碰撞伤害。其他三版不因此留下新的持续地面。
