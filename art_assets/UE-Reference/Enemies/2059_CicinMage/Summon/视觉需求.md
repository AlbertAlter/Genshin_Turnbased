# 雷萤术士：召唤雷萤出现

两只实际召唤成功的雷萤共用[公共聚合显现](../../../general/SummonAppearance/视觉需求.md)，主色选择雷色。各自的新卡位聚起稀疏紫色亮粒和极短余电，雷萤卡牌在短促高潮中显露，余电随后收尽；不为两只雷萤各演一遍完整术士施法。

出现结束后雷萤保持自己的真实卡位与显示。召唤出现、后续逐只冲袭和术士环绕分别组织；一次攻击不重播召唤，不把一次召唤当作雷萤已执行攻击。
