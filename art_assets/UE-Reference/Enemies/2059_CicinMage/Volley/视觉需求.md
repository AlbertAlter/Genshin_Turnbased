# 雷萤术士 · 雷萤冲袭与攻击动画表钩子需求

## 依次出手的表现

施放雷萤冲袭时，**本次实际参与的所有在场雷萤卡牌，各做一次最低一级、有动作的普通攻击运动，依次执行**。每只雷萤短促前倾，在接触重点表现自己的这一次攻击，然后快速回正；前一只完成基本动作后，下一只再起手，不能全部同时摆动，也不能只有术士自己动。

雷萤保持自己的卡位和卡面，不为了照搬原作而瞬移到术士面前排队，不把卡牌整张投到目标身上。最低一级运动沿用公共普通攻击前倾，幅度和节奏复用该预设；不新增一套雷萤专用位移算法。

所有雷萤沿本次已经选定的同一目标攻击，各次接触的受击、雷色命中与跳字按真实顺序出现。雷萤全部出手后，术士保留原有的一次跟击。参与数量由本次真实结果决定，不按固定两只或三只补齐；没有实际参与雷萤时不生成虚假的攻击动作。

## 攻击动画表钩子需求

按本项指定，这段接口需求也保留在UE需求目录，供后续动画表接线使用：

- 入口为`Charts/UI/ActionTimeLine/AttackAnimations.xlsx`中`SE_CicinMage_Volley_Cicins`的`AnimationHook`，当前仅登记需求，不填写尚未注册的钩子名。
- “最低一级有动作”对应当前公共`SelfAnimation=2`攻击前倾；`1`是无动作。只使用现有前倾及其正常最小档表现，不改成突进、重击释放或施法光环。
- 以每条真实结果中的实际雷萤来源实例绑定卡牌。多个参与者共用同一个效果编号／执行编号时，每只仍各出手一次，不能去重后只剩第一只；也不能在每只雷萤的结果中再次遍历全部参与者，造成重复动作。
- 顺序沿实际参与列表与结果时序，当前业务按雷萤槽位排列。每只的前倾、接触和回正各完成一次，再接下一只；术士的`SE_CicinMage_Volley_Mage`跟击在其后保留一次，不在每只雷萤出手时重复术士动作。
- 钩子只处理攻击动画与命中时序，不调用雷萤的普通技能、不额外创建行动或execution、不重选目标、不再结算伤害。重播、取消或对象失效时清理各自动作偏移，恢复当前有效卡牌的正常姿态。

当前该动画表的雷萤效果行显式为自身无动作，以上是后续补齐钩子的需求，不能把这份文档当成已经实现。
