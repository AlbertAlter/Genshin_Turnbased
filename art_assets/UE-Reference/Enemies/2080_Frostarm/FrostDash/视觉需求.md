# 丘丘霜铠王：冰霜冲刺

卡牌路线沿岩盔王的[公共向右冲出与回场](../../../general/CardRushThrough/视觉需求.md)，用霜铠王当前实际卡面完成冲出、回场和恢复。原作的冰色冲势、碎冰与短冷雾用于补充接触，不将主卡牌留在原地只播放一道速度线。

视觉部件为整张卡牌冲锋、前端短冰锋、向后渐隐的薄冷雾、短促冰粒和各目标局部接触光。主冰锋随冲势扫过本次真实我方范围，冰片沿已走过的方向略作外散，快速消失；前后层次保留卡面与数字可读性。

本项目此招为**全体一次命中**，冲锋路线可以横穿目标区域，但主冰锋按这一次共同接触组织，不因为经过多张卡而制造新的分段命中。卡牌出屏后从自己原位左侧快速淡入归位，回场不补接触。

原作路径上的延迟爆炸冰晶只供冰体材质参考，当前不额外留下冰地雷、不引入延迟爆炸或新的持续地面。尾雾与碎冰在本次冲锋结束后收完。
