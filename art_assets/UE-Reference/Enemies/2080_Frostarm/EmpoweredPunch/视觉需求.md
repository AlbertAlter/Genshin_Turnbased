# 丘丘霜铠王：拳击与追加冰爆

动作及层次沿[岩盔王两拳各接元素爆发](../../2057_Stonehide/EmpoweredPunch/视觉需求.md)。保留“第一拳接触 → 第一轮冰爆 → 第二拳接触 → 第二轮冰爆”的清楚顺序；未处于霜铠时只表现两次普通拳击。

原作冰元素造型参考霜铠王强化拳击和砸地产生的锐冰：浅蓝半透明晶体、蓝白亮棱、短促冷雾。每次追加冰爆从该拳实际目标处向其及实际相邻位置扩开，主裂光和短冰晶在卡后地面层，局部碎冰和接触光可经过卡前；不是从霜铠王自己脚下对空放一次。

视觉部件为短促拳击碰撞、贴地冰色裂光、少量快速生出的短晶棱、外散碎冰和薄寒雾。每轮主冰爆按实际追加范围组织一套，各目标补轻接触；主晶体高低与角度错落，爆开后立即收完，不长期遮住人物，也不把每根碎晶变成额外打击。

两轮可以保留很短的余雾交叠，但不能拖成一个长冰雾领域，不把岩盔王三轮地裂大招照搬为这两次拳后效果。
