# 丘丘霜铠王：霜铠附身

整体沿岩盔王强化时“明确进入强化外观、持续保持、失铠退出”的组织方式，冰晶形体参考原作霜铠王。以真实卡绘为主体，在卡牌两侧和边缘附近形成少量硬朗蓝白晶棱、局部冰色亮边与薄寒雾，表现冰铠已经附身；不另外生成一个完整的人形模型盖住卡面。

视觉部件为建立时聚起的冷雾、短促亮起的冰晶轮廓、持续的小幅霜粒与边缘微光，以及结束时的碎冰／淡雾。附身时冷光先聚集，晶棱由弱到清楚；随后稳定维持，霜粒错落漂移、亮度不累积，卡绘中心与信息栏保持通透。普通刷新不重新爆闪整张卡。

真实失铠时，晶棱短促碎开或松散，余光、寒雾收完，回到当前正常外观。普通清理、死亡或会话退出沿相应收尾，不补一次伤害或破盾反击。护盾条继续表示真实盾量，晶棱的数量和亮度不代替盾条，也不额外生成第二份护盾。
