# 丘丘霜铠王：跳跃砸击与冻结地面

完整卡牌动作沿[公共跳起重砸与落点阴影](../../2023_LargeCryoSlime/JumpingSlam/视觉需求.md)。霜铠王从原位消失，在本次实际我方合并范围的屏幕内上方出现，快速压落到该组中心附近，触地短促形变后返回自己的原卡位。下落前地面阴影由浅虚变深、收紧；方向在屏幕平面内向下，不是沿屏幕法线撞向观察者。

接触造型结合岩盔王的地面爆裂组织和霜铠王原作的落地冷气：一片冰色地裂／霜纹、少量锐利短冰晶、横向爆开的冷雾、外散碎冰。在该次共同接触里迅速达到一次高潮，随后晶体碎开、寒雾退弱；真实各目标只补局部受击接触，不逐卡复制霜铠王本体或整片落地爆炸。

这次主攻击只有一次全体接触，不复制岩盔王三轮地裂。落地后衔接[公共冰元素地面](../../../general/ElementalGround/视觉需求.md)，按本次真正获得地面状态的卡位维持；主爆裂收尾不撤去地面，周期伤害只出现短冰粒／寒雾接触，不再砸一次或重铺整片地面。
