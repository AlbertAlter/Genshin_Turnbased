# 冰萤术士：雾中召唤

出现效果与纯水及雷萤统一，复用[公共聚合显现](../../../general/SummonAppearance/视觉需求.md)，选择冰元素主色、轻薄冷雾和少量细冰粒。两只实际召唤成功的冰萤卡牌在各自新卡位显露，余光收完；原有卡位与已存在冰萤不重播出现。

召唤起势和卡牌显露分清，术士只进行一次施放表现，不为两只冰萤重复完整施法。原作三只冰萤的数量不搬进本项目，出现只按真实成功结果。
