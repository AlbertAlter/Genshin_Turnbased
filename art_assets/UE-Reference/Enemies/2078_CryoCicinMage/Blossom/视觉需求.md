# 冰萤术士：冰晶绽放

整体延续雷萤术士的短促施放与接触组织，元素材质换成冰霜。术士侧有一次简短聚冷起势，随后在实际我方目标的合并区域由地面层绽出一轮短冰晶和冰色冷光，各目标补局部碎冰接触。范围是一片共同绽放，不为每张卡各放一套大冰花。

视觉部件为低薄霜光、短促破出的尖冰晶、命中冷光、细碎冰片与薄寒雾。晶体主体蓝白、半透明且有棱面，起势后迅速达到一次接触高潮，再碎开、收淡。只有一次主攻击，不追加三轮环绕，不留下新的持续冰地面。
