# 冰萤术士：流萤护盾与冰霜环绕

沿[雷萤术士的无圆罩环绕](../../2059_CicinMage/ElectroSurround/视觉需求.md)组织，换成卡牌周围的冰色冷流、短碎冰与细薄霜光。保持卡前／卡后穿行和中心透空，血条、盾条及状态信息清楚；不重新画完整球形圆罩。

## 阶段与部件

| 阶段 | 可见内容 |
|---|---|
| 起盾蓄力 | 局部冷雾、冰色亮粒先聚起，沿公共蓄力动线维持；盾条读取真实初始盾，不额外绘制假条 |
| 正式环绕出现 | 成功转为正式盾后，冰流与少量碎冰建立稳定环绕，亮度可短促加强后回落 |
| 持续 | 冷流与碎冰在不同高度、相位错落穿行，整体密度稳定；不机械转动一圈等距冰块，不随着经过时间越叠越亮 |
| 消失 | 状态结束后停止补入，已有冷流收细、冰粒淡去；从任意循环位置都能退出 |

实际蓄力提前被破除时只清理准备效果，不播放“转正式盾”的高潮。正式环绕仍存在时，周期攻击保持自身循环，不反复起盾。

## 三次冰霜触发

沿雷萤“一次触发拆成三次接触”的组织方式，但目标保持本项目的三次全体。每次在该轮实际我方合并范围出现短促冰流扩开和薄碎冰接触，各卡局部补冷光；三轮清楚衔接，整体快收。持续环绕只在术士自身，受击角色不获得一份新环绕。
