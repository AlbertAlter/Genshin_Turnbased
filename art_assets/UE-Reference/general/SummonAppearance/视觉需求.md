# 公共召唤出现：聚合显现

按用户要求，将纯水幻形召唤时聚起能量、显出召唤物的观感提炼为一套公共出现效果。可见起点在本次真正召唤成功的卡位，粒子与薄雾先聚拢，真实召唤物卡牌在其中显露，最后余光散尽。主体是新出现的卡牌，不在旁边常驻第二份生物模型。

## 公共视觉部件

| 部件 | 造型与运动 |
|---|---|
| 聚合粒子 | 少量柔亮细粒从卡位附近向中心收拢，近中心自然消失；轨迹略有弧度，先后、长短有变化，不拼元素图标 |
| 局部能量与薄雾 | 卡面附近一团透空、柔边的能量与薄雾，短暂撑起后退弱；范围收在本卡，不盖满整个战场 |
| 卡牌显露 | 与聚合高潮衔接，完整卡牌由弱到清楚，卡面和卡框协调出现；显露后自然保持正常卡牌外观 |
| 收尾余光 | 少量外散光点、细屑或薄雾逐步消失，露出清楚卡绘及独立信息栏，不残留持续召唤光柱 |

公共阶段为“聚合起势 → 卡牌显露 → 余光收尾”。同批多只使用同一套结构，各自位于真实新卡位，允许细节错落；不把它们逐只强行排成漫长队列。没有成功召唤的位置不播放出现效果。

## 元素与材质变体

| 召唤物 | 公共主色与少量材质细节 |
|---|---|
| 水幻形 | 水元素青蓝、少量水珠和薄水雾，作为本套基准 |
| 草史莱姆 | 草元素色，少量细孢子；保持相同聚合、显露节奏 |
| 雷萤／冰萤 | 分别用雷／冰元素色，少量余电／细冰粒，不改变公共出现结构 |
| 岩柱 | 岩元素色，少量硬朗岩片与薄尘；柱形由真实卡绘及短暂造型细节呈现 |
| 火种 | 火元素色，少量火舌和余烬；出现完成后交回火种自身的持续表现 |

主色、密度和少量材质细节可选择，卡距与大小变化时沿真实卡位适配。水版的水滴、原作水球落地及平台流程不作为所有变体的必需部分。公共显露与岩柱、火种等自身持续外观各有一次明确衔接，不叠放两套重复卡牌入场。

出现结束不改变召唤物的站位、属性、盾量或存活时间。取消、换绑或会话退出时停止余光，不把旧召唤的迟到显露套给同一位置的新占位者。
