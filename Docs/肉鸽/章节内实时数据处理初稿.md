# 章节内实时数据处理初稿

> 状态：初稿，后续可随角色、背包、养成和节点流程继续调整。

## 一、基本原则

章节进行期间，由一份统一的章节运行数据作为角色、背包、武器、圣遗物、编队和节点进度的唯一数据来源。

- UI 只读取和展示数据，不直接修改数据对象。
- 战斗对象只是在战斗场景中的临时实例，不直接作为章节数据保存。
- 存档快照由章节运行数据生成，不把 GameObject、MonoBehaviour、Controller 或计算后的角色面板写入存档。
- 所有奖励、养成、装备、消耗和节点操作均通过统一接口执行，操作完整成功后再更新存档。

## 二、数据划分

### 1. 持续成长数据

在章节之间继承，包括：

- 已拥有角色及其等级、经验、突破、命座和技能等级；
- 背包中的材料、货币、消耗品和任务道具；
- 所有武器实例及其等级、经验、突破和精炼；
- 所有圣遗物实例及其星级、部位、等级、主属性和副属性；
- 当前装备关系和编队；
- 需要跨章节继承的抽卡、商店或其他玩法状态。

### 2. 当前章节数据

只服务于正在进行的章节，包括：

- 当前章节、路线图、所在节点、已完成节点和已选择路线；
- 每个已拥有角色的当前生命和当前能量；
- 已生成但尚未完成的奖励、事件或结算流程；
- 本局随机种子、随机步数以及已经展示给玩家的随机结果。

章节开始时，所有已拥有角色恢复至满生命、满能量。章节中获得的新角色同样以满生命、满能量加入。章节结束后，角色成长、装备和背包继续继承，上一章的路线、节点、待处理流程和角色当前生命/能量不继承到下一章。

## 三、角色与装备关系

- 角色数据只记录其当前装备的武器实例 ID 和各部位圣遗物实例 ID。
- 武器和圣遗物实例统一由背包持有；已装备的实例仍属于背包，不额外复制一份。
- 同一件装备不能同时装备给多个角色。
- 装备中的武器或圣遗物不能直接出售或作为强化材料。
- 角色最终面板由角色成长数据、装备实例和配表实时计算，不保存已经计算完成的面板数值。

角色等级或装备变化导致最大生命改变时，暂定采用以下规则：

- 调整前为满生命，则调整后仍保持满生命；
- 调整前不是满生命，则保持原绝对生命值，并限制在新的最大生命以内；
- 当前能量保持原值，并限制在新的能量上限以内。

## 四、章节内操作流程

角色升级、装备更换、物品消耗、商店购买、奖励领取和事件结算等操作应作为一次完整事务处理：

1. 检查角色、物品、货币、装备和当前节点流程是否满足条件；
2. 在候选数据上一次性完成扣除、增加、装备或进度修改；
3. 检查数量范围、实例唯一性、装备关系和待处理流程是否有效；
4. 写入临时存档；
5. 保存成功后替换当前章节运行数据，并通知 UI 刷新。

如果保存失败，本次操作不能只完成一半。随机结果已经生成但保存失败时，应保留同一份候选结果供重新保存，不得再次随机。

## 五、节点与奖励流程

节点流程暂定为：

```text
选择路线
→ 保存所选节点
→ 执行战斗、事件、商店或其他节点内容
→ 更新角色、背包和章节状态
→ 生成并保存待处理奖励
→ 玩家完成奖励选择
→ 奖励进入背包并清除待处理状态
→ 标记节点完成
→ 返回路线界面
```

已经展示给玩家的奖励、武器、圣遗物或事件结果必须保存完整结果，不能只保存随机种子后重新生成。随机生成的武器和圣遗物应在生成时取得稳定的实例 ID。

## 六、战斗数据交接

进入战斗前，根据章节运行数据生成一次战斗输入，内容包括出战角色、成长数据、装备以及当前生命和能量。创建战斗角色并完成属性和装备初始化后，再写入章节中保存的当前生命和能量。

战斗胜利后，只将参战角色最终的生命和能量回写到章节运行数据，然后保存战斗胜利恢复点。未参战角色保持原状态。战斗失败或战斗中退出时不回写战斗结果，仍从战前快照恢复。

## 七、当前代码衔接

- 现有 `RoguelikeSaveService` 继续负责临时存档、战前存档、胜利存档和章节入口档，不负责直接管理 UI 或战斗对象。
- `RoguelikeProgressSnapshot` 后续需要补充背包、装备实例、编队、角色当前生命/能量和完整待处理流程。
- 需要新增章节运行数据持有者，以及快照构建和恢复流程。
- 现有 `CharacterProfile` 可继续作为战斗构筑输入，但不应同时承担背包和装备实例的唯一数据来源。
- 新增字段后需要提升存档版本，并补充相应校验与测试。

## 八、待确认事项

- 材料、货币和消耗品的分类及堆叠上限；
- 是否允许保存多套编队；
- 角色死亡后在节点外是否允许换下、复活或继续参与非战斗操作；
- 武器和圣遗物强化经验、锁定、出售及批量消耗规则；
- 事件内部是否需要保存多个步骤；
- 章节结束到下一章开始之间可以进行哪些养成和编队操作。
